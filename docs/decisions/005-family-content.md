# 005：家族入口与精选内容

状态：采用；日期：2026-10-26。

用户要求重点解释开放模型，Qwen 覆盖一代到 3.8 及 ASR、VL、Omni 等分支，加入 Kimi 和 GLM，闭源模型简要介绍。若每个参数规格和版本都进入地图，会重新造成零碎与拥挤。

因此使用已有 `featured` 字段控制首页模型／家族投影。具体代际保留 `kind: model`，通过家族页的连续代际表、详解与搜索访问；不改变模型页与共享概念的组件契约，不新增另一套内容格式。

家族入口表达系列脉络，版本页限定结构与训练依据。各模态分支按实际发布记录整理，不按版本号自动生成。公开报告、权重、代码、数据和 API 分别标清，模型卡许可优先于代码仓库许可。

地图缩小时只显示更大的模型名称，放大后显示用途与年份；复用 G6 布局与缩放事件，不新增图形框架。正文对照表共用排版和键盘滚动，避免手机整页横向溢出。

取舍：具体版本不会全部直接出现在全图，但仍有完整正文与可分享 URL；维护者需明确选择家族还是单模型作为首页入口。图谱连线继续要求有依据，精选字段不生成虚构继承。
