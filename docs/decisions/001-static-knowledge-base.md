# ADR 001：静态知识库与共享图谱

状态：已采用，2026-10-26。

需求是可理解的知识地图、学习路线和案例，而不是在线执行训练。选择 Astro/Starlight 承担正文与搜索，React 承担需要交互的部分。

使用 Markdown/YAML 作为唯一编辑源，经核心契约校验后输出静态数据。没有数据库和运行时内容服务，贡献者可以通过普通 PR 审核知识变更。

三种地图复用一个渲染器，布局引擎只是地图内部实现。这样改变展示方式不需要维护另一套知识数据、选中逻辑或学习进度。

代价是内容更新需要重新构建，且本地进度不会自动跨设备同步。首版通过导出/导入支持备份；未来增加账户同步时只替换存储适配层。
