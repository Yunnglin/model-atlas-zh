# ADR 004：模型地图与连续学习

日期：2026-10-26。状态：接受；替代 ADR 003 的导航树交互。

## 问题

按结构、训练、评测不断展开单个知识点，导致学习被点击切碎。共享概念交织，也让模型的整体工作方式难以看清。

## 决策

首页仅展示模型关系；点击后进入一个模型的连续学习页。章节由已有 Markdown 编译得出，采用普通滚动与目录定位。共享概念通过临时阅读区引用，关闭后保留模型位置。

沿用 G6，使用现成 Dagre 布局；删除旧导航出现记录和同级收放规则。真实技术关系保留来源，不把阅读顺序或模型年份误写成继承。

图形独立登记元数据，模型指南只引用图形并指定章节。共用图形组件支持官方图片、放大查看、外部交互工具和已验证嵌入；初始示例使用官方 Whisper PNG 和外部 HF Viewer 链接。

公共正文加载、内部链接和排版由模型页与概念阅读区复用。功能互不导入，由 app 组合；core 保持与界面和浏览器无关。

## 取舍

连续阅读会使单个模型页更长，因此提供目录与会话位置恢复。主图信息更少，因此跨概念关系放在正文与按需关系说明中。有正文但缺关系的模型单列待补充入口，不制造边。

第三方交互图的界面和可用性由外部维护，未验证嵌入时使用外链和本地原图。先做一个深入的 Whisper 示例验证组件与阅读流程，再按相同契约扩充其他模型。
