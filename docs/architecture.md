# 架构说明

## 产品边界

首页只回答“模型之间有什么关系”，进入模型后连续阅读结构、数据与训练、评测、应用和错例。共享概念临时查阅，不把学习过程拆成逐个展开的小卡片。模态仍是内容属性，不作为导航入口。当前交付本地内容版，83 篇正文共用同一阅读实现；Qwen、Kimi、GLM 通过家族总览与版本详解组织。

不恢复学习路线、自测、进度、常驻闭环、地图模式和全局维度切换。网站不运行训练或评测。技术选择沿用 Node 24、固定 pnpm、TypeScript、Astro/Starlight、React、G6 和 Zustand，不新增后台或应用框架。

## 模块与依赖方向

| 模块                 | 职责                                                        | 允许依赖                        |
| -------------------- | ----------------------------------------------------------- | ------------------------------- |
| `core`               | 知识与图形契约、关系查询、模型地图投影、跨记录校验          | core、Zod                       |
| `build`              | 读取 Astro 集合、编译章节元数据、检查本地图片、输出静态数据 | core、内容框架、构建时文件接口  |
| `features/atlas`     | 模型地图、辅助搜索、模型及概念选择契约、URL 编解码、G6 适配 | core、platform、公共 UI、图形库 |
| `features/learning`  | 模型连续正文、目录、架构图放置、模型阅读恢复                | core、platform、公共组件        |
| `features/reading`   | 共享概念阅读区、概念内返回、关系解释和资料                  | core、platform、公共组件        |
| `components/reading` | 共用正文加载 hook、正文排版、内部知识链接分派               | core、platform、React           |
| `components/figures` | 共用原图、放大查看、来源、交互资源及加载失败回退            | core、React                     |
| `platform`           | 浏览器历史、静态正文缓存与分章、会话阅读位置                | 浏览器接口、Zod                 |
| `app`                | 数据加载、页面组合、Zustand 订阅与 URL 同步                 | 功能入口、platform、core        |
| `pages`              | 首页、静态数据、Starlight 正文与阅读片段                    | app、build、内容框架            |

功能之间通过 app 的回调组合，互不导入。公共组件不依赖 feature，不自行读取 Markdown/YAML。core 不包含浏览器、React、Astro、G6、DOM 或坐标类型。dependency-cruiser 强制依赖方向与无循环导入。

## 一份内容，多个阅读入口

每个知识点只有一篇 Markdown，稳定 ID、别名、短用途、年份和来源在文档头维护。模型与共享概念使用相同知识契约；模型家族和具体版本不能混写。当前 Transformer 作为共同架构起点，也能进入连续阅读。

数据流：Markdown/YAML → Astro Collections → 结构与引用校验 → 只读统一知识数据 → 静态文章、地图数据与阅读片段。数据版本为 3，移除旧 `navigation` 字段，新增 `figures`、`guides` 和编译章节元数据。

构建产物：

- `data/atlas.json`：摘要、关系、章节目录与图形元数据，不包含全文 HTML。
- Starlight 独立正文：全文搜索、普通链接和降级阅读。
- `readers/<id>/`：同一 Markdown 编译的按需片段，不进入全文搜索结果。
- `figures/`：经许可复用的本地图形与许可文件，不依赖外站热链。

正文内部链接在构建时检查目标是否存在，再统一添加部署子路径。章节标题与锚点直接取 Astro 编译结果，不维护第二套模型正文。浏览器适配层把片段按一级章节分组，保留列表、段落、子标题和公式。普通概念阅读与模型正文共用加载、缓存、取消和重试；对照表在两种阅读入口共用横向滚动样式，浏览器适配层使表格可被键盘聚焦；切换文章后旧响应不写入新页面。

## 模型关系地图

`core/projections/model-map` 只接收 `featured` 的模型和 Transformer。`featured` 表示首页策展范围，不是开放程度或质量分数。家族页进入地图，具体版本保留 `kind: model` 但 `featured: false`，因此仍可进入连续阅读与搜索。采用、改进、对比等关系来自有来源的记录；学习前置不转换成模型继承。经过“编码器＋解码器”连接的结构关联保留两段证据。图中实线表示结构关联，虚线表示对比，不使用历史继承箭头；连线依据可按需查看原始方向、解释和来源。

有正文但尚未维护模型关系的条目，放在“关系待补充”入口，仍可直接学习。不能为了连成漂亮的树伪造关系。未精选的 Jev、OmniJev 仍保留独立正文与搜索，不为其伪造关系。无关系不代表它们一定与 Transformer 无关。

`features/atlas/layouts/model-graph` 封装 G6 的 HTML 节点、Dagre 布局、取景和销毁。卡片文字使用 `textContent`；节点是原生按钮，装饰 canvas 不进入焦点。画布在有实际空间时才初始化，G6 延迟加载；尺寸更新串行处理，卸载后取消后续更新并销毁。

地图不再有逐知识点展开状态。打开模型时保留同一个隐藏的画布实例，返回后保留平移与缩放；浏览器刷新不承诺保留相机。全图缩小时隐藏年份和短用途、放大标题，放大后恢复卡片细节。手机保留可读缩放，允许平移或主动适配全图。

## 连续学习与共享概念

模型页完整展示章节，目录只负责定位。正文内部已有知识链接通过公共 `ArticleBody` 分派：模型进入对应学习页，概念进入临时阅读区；修饰键打开链接仍遵循浏览器原生行为。

共享概念可继续查其他概念，返回会缩短概念路径；同一概念再次出现时截断循环。阅读区的关系列表保留采用、前置、比较、评测与应用的解释和引用。桌面是右侧阅读区，手机为原生模态 dialog。

模型背景不会随概念切换而卸载，关闭阅读区仍在原位置。模型切换或返回地图前保存会话位置，重新打开与刷新后恢复。会话记录不属于学习进度，存储不可用时仍可阅读。图片提供真实尺寸，避免懒加载造成正文位置跳动。

## 架构图复用

图形在 `figures.yaml` 独立登记，包含模型、版本范围、来源、核对日期、替代文本、说明、生成依据；本地图片还记录路径、真实尺寸、许可与署名。`model-guides.yaml` 只指定“哪个图出现在模型的哪个现有章节”，不复制章节正文。

`ArchitectureFigure` 统一提供原图预览、键盘可滚动的放大弹窗、缩放、来源和失败回退。Whisper 与 SAM 复用官方 PNG，原文件和各自许可保存在本地，不重新绘制模型结构；来源与文件摘要见 [资产记录](assets.md)。

交互资源支持两种声明：

- `external-only`：仅提供新页入口，默认不请求第三方脚本；当前 HF Viewer 使用此方式，尚未验证嵌入。
- `verified`：维护者实际确认许可、嵌入 URL、版本对应、可用性、手机和失败行为后才能标注；组件提供用户主动加载的 iframe 和原图/来源回退。没有已验证实例时不宣称兼容性已通过。

生成依据区分官方原图、教学简化、配置或追踪生成、实际执行追踪。缩放、SVG 格式或自动布局都不能证明模型结构正确，仍需对照论文、官方实现或指定模型的运行证据。

## 状态与 URL

Zustand 只管理 `{model?, concepts: []}`。URL 使用 `?model=whisper&concept=next-token`，多个 `concept` 保留查阅路径。模型跳转清空概念路径，关闭阅读区只清空概念；返回地图清空选择。URL 支持刷新和前进后退，未知 ID 被丢弃，无变化不新增历史项。

旧的重复 `node` 链接迁移到模型与概念，`reader=closed` 不重开旧概念；`open`、模态、地图模式等旧参数不再保留。`sessionStorage` 分别保存模型和概念的滚动/公式状态，读取时校验，失效记录忽略。

## 工程验收

内容检查包括重复 ID、关系/引用、前置知识循环、六步案例、图形与模型匹配、章节放置和本地图片存在。严格类型、ESLint、Prettier 与依赖边界纳入 `pnpm check`。Vitest 检查内容、模型投影、URL、选择状态和正文适配。

Playwright 检查地图到模型、连续章节、嵌套概念返回、相机与滚动恢复、异步旧响应、失败重试、图片回退、架构图弹窗、存储不可用、键盘、axe、公式、全文搜索和所有静态内容路径；同一组检查在 GitHub Pages 子路径复跑。真实截图与限制记在根目录 `design-qa.md`。

当前以开放权重重点模型、家族演进和五类教学案例为内容范围；闭源型号仅作简要对照。所有模型的训练复现、第三方交互嵌入、140 节点目标和公开部署不属于已验证交付。
