# 精选内容范围

核对日期：2026-10-28。当前本地版包含模型／版本节点，以及共同基础、训练、评测、应用和 5 类案例。参考资料统一登记在 `src/content/data/sources.yaml`。这是一批精选解释，不宣称覆盖所有模型与全部训练细节。

## 选什么、讲多深

以有影响力、对理解技术路线有帮助的开放权重模型为主。每个精选模型连续讲问题、结构、训练、评测、应用错例和面试比较；解释先用大白话，再给术语与资料。没有明显教学价值的冷门型号不为凑数量收录。

家族页用表格串起代际；重要结构变化另有详解，同一内容只维护一次。参数量、量化格式、框架适配和 Base／Instruct 在对应页归并。首页展示重要代际与分支；首页展示的模型／版本节点各有独立正文，逐篇事实与图示审校仍在进行。

开放权重、开放代码、公开报告、公开训练数据、API 服务分别说明。闭源模型深入讲解公开机制和验证方法：Claude、GPT-4o、Gemini 1.5 不推测未公开结构或配方。早期 GPT-2 仍是开放结构学习材料。

## Kimi 与 GLM

Kimi：早期闭源服务背景，K1.5 报告、K2／Instruct-0905／Thinking、K2.5、K2.6、K2.7 Code、K3；同时整理 VL、Audio、Linear。重点解释 MoE、MLA、KDA、AttnRes 与工具轨迹各自解决的问题。

GLM：原始 GLM、GLM-130B、ChatGLM 三代、GLM-4 开放型号、4.5／4.6／4.7、5／5.1／5.2／5.3 与 5.3-Flash；视觉、ASR、TTS、OCR、Image 生成分支另列。5.3 沿用 5.2 基础做后训练，Flash 是新基础与不同结构，不能合写为简单量化。

## 其他主线与应用闭环

- NLP：BERT、GPT-2、T5、Llama 3.1、DeepSeek-V3、V3-0324、初版 R1 和 R1-0528；分词、位置、KV Cache、MoE、SFT、RLHF、RLVR、DPO、GRPO、蒸馏等共用概念。
- CV：ViT、Swin、CLIP、SAM、Stable Diffusion、DiT。SAM 复用官方架构图，并明确原图中的文字提示概念与公开 API 能力的区别。
- Audio：wav2vec 2.0、HuBERT、Conformer、Whisper、EnCodec、VALL-E、F5-TTS；识别、语音表示与生成分开解释。
- 多模态：LLaVA 及上述 Qwen、Kimi、GLM 分支；模型名字不代替输入输出能力说明。
- 五类案例：文档问答、视觉问答、语音识别、语音生成、全模态助手，均包含数据 → 训练 → 评测 → 应用 → 错例分析 → 数据改进。

案例是可复现方案与官方工具入口，未执行实际训练或评测，不编造成绩、提升比例或硬件表现。架构图包含官方原图与明确标注的原创教学简图，来源、版本和许可见[资产记录](assets.md)。Qwen 补深范围见[阅读与核对记录](qwen-depth.md)，全库逐页检查见[模型通读记录](reviews/model-depth-review.md)。

## 维护方式

事实回到论文、官方实现与模型卡，课程和面试库只用于查漏补缺。年份表示页面指定版本或家族起点，不是所有技术第一次出现的证明。关系有来源和含义，比较关系不冒充继承。新增版本必须核对权重是否真的发布、公开范围和许可证，而不是从宣传标题推断。

构建检查内部链接、引用与案例完整性；单测约束精选解释的主要章节，交互测试检查家族到版本／概念的跳转和原位返回。未来继续扩充时按主题核对，不以 140 个节点作为凑数目标。

## 训练技术扩充目标

训练方法与模型正文相互链接，共用术语文章，避免在每个模型页面重复维护。覆盖 SFT、LoRA／QLoRA、RLHF／RLVR、PPO／GRPO／GSPO、DPO／KTO 及其他有影响力的 RL 算法、蒸馏、量化及其工程与评测。奖励来源、优化算法、参数更新方式、精度格式分别解释，避免把这些不同维度列成互斥方法。

每个主题介绍用途、前置概念、通俗原理、具体例子、公式或流程、数据与训练设置、效果和成本评测、常见失败与面试追问。优先引用原论文与官方实现；知乎文章帮助寻找好例子，但互动数量不是正确性证明。已写内容与后续目标分开，未实际运行的案例不标为复现。
