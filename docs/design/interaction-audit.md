# 分支收放交互审查

2026-10-26，当前本地 demo。用户反馈展开后节点交织，主次不清。此报告只依据本次实际浏览器截图，不以自动化检查通过代替体验判断。

## 观察步骤

1. 展开 Whisper：13 个可见节点。展开和正文操作已分开，但结构、训练、评测、案例仍散落在同一网络中，无法一眼区分学习层级。[实际截图](audit-expanded-whisper.png)
2. 继续展开下一 token：16 个可见节点。GPT、Whisper、SFT 和前置注意力同时连向共享概念，长连线跨越其他模型；上方新节点部分超出视口。[实际截图](audit-expanded-next-token.png)

两张截图均为当前浏览器实际渲染，1440 × 1024 CSS 视口，图片同尺寸。临时视口在审查结束后恢复。

## 发现

- P1：展开等同于显示所有直接邻居，没有区分发展主线、学习前置、采用方法、评测和对比。知识正确不代表导航清楚。
- P1：为了让已有节点完全不动，新概念只能在空位生长，不能形成紧凑的父子分组；第二层展开会产生更多跨区连线。
- P2：部分连线与关系标签穿过其他节点的文字区域，新节点还可能在首屏之外，必须主动适配全图。
- 可见性风险：缩小全图会进一步压低中文标题和操作按钮的可读尺寸。截图不能证明完整键盘或读屏表现；现有浏览器测试覆盖了当前行为，但不代表改进方案已实现。

## 建议方向（待讨论）

主干改为可折叠的学习导航树，主画布只显示导航父子线。其他真实关系放入节点详情中的“采用方法、评测、对比”等明确列表，按需查看。

模型展开后先出现结构、训练、评测、应用等知识维度，再选择内容，不再一次吐出所有邻居。默认同级只深入一条分支，祖先与同级标题保留。共享概念允许出现多个导航引用，正文和知识记录仍只有一份；不为保证屏幕上只有一个点而横穿整张图连线。

允许成熟树布局为新内容重新排布空间，固定当前操作节点的位置并平滑过渡，不再要求所有旧节点完全不动。树枝表达学习组织，不冒充模型的历史继承。

AntV G6 的 CompactBox 和内置 collapse-expand 可以作为下一版验证对象，当前没有迁移框架，也没有把此建议标注为已验收。
