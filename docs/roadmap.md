# 实施范围与下一阶段

## 第一阶段：可运行设计小样

已提供 30 个真实知识节点与独立正文、三种地图布局、四个观察维度与全貌入口、两条岗位路线、8 道自测、一个六阶段语音助手教学案例。正文包含大白话解释、例子、比较、局限和追问；注意力、下一 token 预测、LoRA、错误率提供可展开公式。

已经建立内容契约、引用校验、模块依赖检查、浏览器记录适配、静态数据和文章输出、自动测试以及手动 Pages 发布工作流。设计验收记录见根目录 `design-qa.md`。

下一步先比较技术树、演进泳道、关联探索的学习体验，确定默认展示和可接受的节点密度。当前没有创建公开 GitHub 仓库、触发线上 CI 或发布网站。

## 第二阶段：精选内容库

目标仍为约 140 个精选节点、约 30 个核心详解、两条持续完善的岗位路线、五类实践案例以及 4–6 个原理演示。数量是范围预算，不靠拆分重复概念凑数。

| 领域       | 待扩充的主要问题                                                         |
| ---------- | ------------------------------------------------------------------------ |
| NLP        | 分词、位置编码、注意力变体、Dense/MoE、代表性开放模型、推理与工具使用    |
| CV         | 图像表示、识别与分割、对比学习、扩散与视觉生成、图文理解及任务评测       |
| Audio      | 声音表示、CTC/编码器解码器、ASR、TTS、语音翻译、音频语言模型、流式与延迟 |
| Omni       | 模态连接与对齐、输入输出能力、音视频理解、语音对话、跨模态一致性         |
| 数据与训练 | 数据配比与去重、训练目标、SFT、偏好学习、RLHF/RLVR、优化与资源取舍       |
| 评测与应用 | 协议、污染与泄漏、能力切片、人工与自动判断、概率校准、上线错误与回归     |

五类案例拟覆盖文字助手、视觉问答、语音识别、语音生成或翻译、多模态交互。每类都写数据、训练、评测、应用、错误分析、下一轮数据与回归；只有保留完整版本和运行产物的记录才标注为已复现。

原理演示优先考虑注意力、因果掩码与下一 token、图文对齐、语音编码与解码、偏好/可验证奖励、校准与阈值。沿用现有功能边界，按实际演示建立模块。

课程和面试库用于查漏补缺，事实回到论文、官方代码与模型卡。每批内容通过内容检查和相关测试后合入。默认设计确定后再创建用户 GitHub 仓库，并检查实际 Actions、Pages 配置与线上链接。
