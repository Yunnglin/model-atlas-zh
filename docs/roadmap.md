# 实施范围与下一阶段

## 当前阶段：树形导航与 Whisper 分支 demo

2026-10-26：用户确认继续“树形主干＋详情关联”的方案。全邻居网络展开及固定所有旧坐标的方案被替代。

实施范围：

1. 采用 G6 CompactBox 和原生收放，一个画布、一个状态入口；移除旧的 React Flow 和自制增量排布。
2. 主干从 Transformer 的结构路线展开，不按模态浏览。首版深入 Whisper，分成结构、训练、评测、应用，其他文章仍可搜索阅读。
3. 同级默认只展开一个分支，保持当前路径及同级标题；主画布仅绘制导航父子线。
4. 共享概念允许多个导航引用，正文只有一份。采用、比较和前置关系进入详情，解释与一手来源保留。
5. 使用成熟布局重新分配空间、对齐当前操作节点；空间不足时平移或适度缩放。检查短窗口和手机控件可见性。
6. 验证 URL 恢复、快速切换、折叠后无节点残留、正文返回与滚动恢复、失败重试、键盘和 GitHub Pages 子路径。
7. 保存真实浏览器截图并更新设计检查结果，交付本地 demo；暂不发布。

验收路径：根下三种结构路线 → 编码器＋解码器 → Whisper → 训练 → 下一 token 预测 → 阅读正文并返回 → 切换评测，训练子项收起 → 查看关联资料而不增加画布连线 → 收起全部。

首页不保留学习路线、自测、进度、常驻闭环、地图模式或全局维度切换。已有正文与题目、路线素材继续维护和校验。

## 第二阶段：精选内容库

内容规模仍以约 140 个精选节点、约 30 个核心详解、五类实践案例和 4–6 个原理演示作为范围预算，不靠拆分重复概念凑数。岗位路线与独立自测暂缓，是否恢复依据后续实际使用需求决定。

| 领域       | 待扩充的主要问题                                                         |
| ---------- | ------------------------------------------------------------------------ |
| NLP        | 分词、位置编码、注意力变体、Dense/MoE、代表性开放模型、推理与工具使用    |
| CV         | 图像表示、识别与分割、对比学习、扩散与视觉生成、图文理解及任务评测       |
| Audio      | 声音表示、CTC/编码器解码器、ASR、TTS、语音翻译、音频语言模型、流式与延迟 |
| Omni       | 模态连接与对齐、输入输出能力、音视频理解、语音对话、跨模态一致性         |
| 数据与训练 | 数据配比与去重、训练目标、SFT、偏好学习、RLHF/RLVR、优化与资源取舍       |
| 评测与应用 | 协议、污染与泄漏、能力切片、人工与自动判断、概率校准、上线错误与回归     |

五类案例拟覆盖文字助手、视觉问答、语音识别、语音生成或翻译、多模态交互。每类都写数据、训练、评测、应用、错误分析、下一轮数据与回归；只有保留完整版本和运行产物的记录才标注为已复现。

原理演示优先考虑注意力、因果掩码与下一 token、图文对齐、语音编码与解码、偏好/可验证奖励、校准与阈值。沿用现有功能边界，按实际演示建立模块。

课程和面试库用于查漏补缺，事实回到论文、官方代码与模型卡。每批内容通过内容检查和相关测试后合入。用户体验当前 demo 后再安排内容扩充和 GitHub 公开发布，检查实际 Actions、Pages 配置与线上链接。
