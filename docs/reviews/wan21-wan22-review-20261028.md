# Wan2.1 与 Wan2.2 核查

核查日期：2026-10-28。核查当前两篇文章的模型卡、VAE 压缩、主要训练路线、以下列明的评测数字及教学图；本轮未逐句审核其他事实、未重读知乎文章，也未实际运行模型。

## Wan2.1

- [Wan 技术报告](https://arxiv.org/html/2503.20314)第 4.1 节：VAE 输入 `1+T` 帧时输出 `1+T/4` 个时间位置，空间各压缩 8 倍，潜在通道为 16；正文以 `81×480×832` 的输入补充形状和数值量算例。
- 报告第 4.6–4.7 节及表 2、4：核对 Wan-Bench 各候选模型 1,035 个样本和 VBench 分数；新增 1.3B 与 14B 的大动作、空间位置两个维度，说明大动作指标根据光流幅度计算。
- 用 Chromium 打开 `public/figures/wan21/overview.svg`，图展示文生视频的文本条件、噪声、DiT 多次更新和 VAE 解码，方向正常。它是简化教学图，不包含完整训练过程或模型细节。

## Wan2.2

- [官方仓库](https://github.com/Wan-Video/Wan2.2)介绍：A14B 用高噪声与低噪声两个专家，合计约 27B、每步约 14B；TI2V-5B 是独立稠密模型，VAE 压缩比例为时间 4 倍、空间 16 倍，分块后空间合计 32 倍。仓库中的专家切换文字存在表述疑点，正文不采用具体阈值或推断其数值。
- 仓库的推理示例写明 TI2V-5B 的 720P 配置为 `1280×704`，采用 CPU 卸载等选项时示例需要至少 24 GB GPU 显存；T2V-A14B 单卡示例列出至少 80 GB。正文按对应型号说明，没有把示例要求当作所有工具链的统一最低值。
- 用 Chromium 打开 `public/figures/wan22/overview.svg`，确认其表示两个专家按阶段处理同一状态，TI2V 为独立路线。图并未展开专家内部结构或采样器，正文说明了这一点。
