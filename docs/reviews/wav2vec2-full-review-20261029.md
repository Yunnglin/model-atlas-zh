# wav2vec 2.0 审阅

审阅日期：2026-10-29。通读 `src/content/docs/audio/wav2vec2.md`，对照论文 v3、模型卡、历史资料和配图；未运行模型或复现评测。时间线 ID 为 `wav2vec2`。

## 结构与模型卡

- [论文第 2–4 节](https://arxiv.org/html/2006.11477)及 [Base 960h 模型卡](https://huggingface.co/facebook/wav2vec2-base-960h)：Base 95M、12 层、8 头，Large 317M、24 层、16 头；具体检查点许可为 Apache 2.0。
- 7 层卷积的步长乘积为 320，16 kHz 输入对应约每 20ms 一个特征步，卷积边界会影响实际数量；上下文网络处理遮盖后的连续特征，量化器使用未遮盖特征。每个目标与同一语句其他遮盖位置的 100 个干扰项比较；两组各 320 个码本条目可形成 102400 种理论组合。
- 比较分数 0.8、0.7、0.2 和“今天下午开会”为教学例子，码本不是人工定义音素，也不等同权重量化。

## 训练

- 论文第 3.2、4.2 节：对比目标与码本多样性损失共同训练，Gumbel softmax 和直通估计器用于可学习的离散选择。识别微调添加线性层和 CTC，不使用预训练量化目标分支。
- 第 4.3 节：前 10000 次微调更新只训练输出层，随后更新 Transformer，特征卷积编码器保持冻结；不能推广为所有后续实现均如此。

## 评测与应用

- 附录表 9：Large、LV-60k 预训练（约 53000 小时）、10 分钟标注，LibriSpeech test-clean/test-other 使用 Transformer LM 为 4.8／8.2 WER，无语言模型和词典为 40.2／38.7。报告第 4.4 节采用开发集调参、测试集 Transformer LM 束宽 500；本次在正文补充设置，以免把语言模型贡献归于声学编码器。
- 模型卡规定该检查点 16 kHz 音频输入；正文补充 Base 960h 的预训练与微调数据、无外部语言模型的贪心解码 3.4／8.6 WER，并说明这不是前述 Large 低标注实验。补充 48 kHz 重采样示例，避免把改标签误认为重采样。会议数字误读和设备切片为构造案例与应用建议，不声称实测；识别分数与实时延迟按各自协议测量。
