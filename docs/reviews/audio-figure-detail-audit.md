# 语音模型教学图与正文抽查

核对日期：2026-10-28。核对以下四个模型教学图中的主要信息流，以及正文对该部分的解释；不代表逐句核实全文或复现模型实验。

| 模型        | 核对依据与结果                                                                                                                                                                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| wav2vec 2.0 | [论文](https://arxiv.org/html/2006.11477)第 2–3 节：上下文分支遮盖后经 Transformer，未遮盖的卷积特征经量化产生对比目标；识别微调接 CTC。教学图与这些主要步骤一致。                                                                               |
| HuBERT      | [论文](https://arxiv.org/html/2106.07447)第 II 节：离线聚类提供标签，预训练用遮盖语音预测标签，并可从学到的表示重新聚类。教学图与这些主要步骤一致。                                                                                              |
| EnCodec     | [论文](https://arxiv.org/html/2210.13438)第 3 节：编码器产生连续表示，残差向量量化逐级逼近，再由解码器重建；可选概率建模与熵编码。教学图与这些主要步骤一致。                                                                                     |
| VALL-E      | [论文](https://arxiv.org/html/2301.02111)第 4.2 节：自回归模型先预测第一层码；非自回归模型按前面码本、音素和声学提示预测后续层。原教学图只画出了音素到自回归模型的箭头，正文已说明音素也用于非自回归模型；现补充对应箭头、图内说明及无障碍描述。 |

教学图有意省略训练损失、部分网络层和采样细节；不能由流程图推定全部实现细节。
