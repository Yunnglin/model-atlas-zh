- **结构与模型卡**：对照 [5.1 配置](https://huggingface.co/zai-org/GLM-5.1/raw/main/config.json)和[模型卡](https://huggingface.co/zai-org/GLM-5.1)：78 层、前 3 层稠密、256 个路由专家取 8 个、1 个共享专家、索引 top-k 2048、最大位置 202752，模型卡标记 MIT。页面约 754B 权重统计与前代报告不含词嵌入及输出层的 744B 口径不同，不直接相减。
- **训练**：[GLM-5 报告](https://arxiv.org/html/2602.15763)介绍前代预训练、异步智能体训练和后训练；5.1 模型卡未给出其新增训练数据及完整配方。正文将账单任务、验证器和训练闭环明确标为教学例子，不将前代方法断言为 5.1 配方。
- **评测**：模型卡表列 SWE-Bench Pro 58.4、NL2Repo 42.7、Terminal-Bench 2.0 的 Terminus-2 63.5 与 Claude Code 最佳自报 69.0；本次加入两个框架结果的具体对照，不把差距直接归因于框架。AIME 2026 的 95.3/95.4 比较区分两个版本，模型卡表中没有足够信息推出所有运行的完整条件。
