# Wan2.1 资料核查

2026-10-28 对照[官方论文](https://arxiv.org/html/2503.20314)、[官方仓库](https://github.com/Wan-Video/Wan2.1)及 [T2V 1.3B](https://huggingface.co/Wan-AI/Wan2.1-T2V-1.3B)、[T2V 14B](https://huggingface.co/Wan-AI/Wan2.1-T2V-14B) 模型卡。仓库记录 2025-02-25 发布权重和推理代码，许可按各检查点核对。技术报告说明 Wan-VAE 时间和空间压缩、umT5 条件编码、DiT、流匹配、数据筛选、分阶段训练和 I2V 首帧条件；正文区分 VAE 长视频分块处理和 DiT 实际生成能力，也区分训练与文生视频推理。

论文表 4 的 1.3B/14B VBench 综合分 83.96/86.22，14B 的 quality/semantic 86.67/84.44；与正文一致。Wan-Bench 的 1,035 样本每模型、人工评测超过 700 个任务及 20 多位标注者按论文原口径表述，榜单结果不延伸为所有视频的正确率。

原创图是文字条件、随机噪声、DiT 和 VAE 解码的高层教学示意，明确训练才需要对真实视频编码；非官方架构图。没有运行权重、复现论文分数、验证硬件速度或确认逐条训练数据来源。
