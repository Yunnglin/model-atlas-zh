# Wan2.1 专项审校

审校日期：2026-10-29。完整通读 [Wan2.1 正文](../../src/content/docs/cv/wan21-model.md)，以基础文生视频与论文所述图生视频为范围；未运行模型、训练或复现评测，猫和商品示例为教学构造。

- **结构**：对照[技术报告第 4.1–4.2 节](https://arxiv.org/html/2503.20314)及[官方仓库](https://github.com/Wan-Video/Wan2.1)，核对文生视频 umT5、DiT、Wan-VAE，因果 VAE 16 通道、时间 1+T/4 和空间 8 倍的尺寸；81 帧示例的像素和潜变量数按各自通道计算。补充完整时空注意力提供跨帧交流路径，但不能保证视频始终连贯。
- **训练**：报告第 3、4.1–4.2 节核对数据筛选、VAE 三阶段训练、14B 图像预训练及渐进图文视频联合训练、流匹配。新增单变量插值示例，与报告第 4.2.2 节的 x_t=t x_1+(1−t)x_0、目标 x_1−x_0 对应；说明流匹配时间与视频播放时间不同。对抗损失归于 VAE 而非 DiT。
- **评测**：报告第 4.6–4.7 节及表 2、4 核对 Wan-Bench 各候选 1035 个样本、1.3B/14B 的大动作和空间位置指标、VBench 的质量/语义/综合成绩；大动作分数不是物理正确率，人工成对比较与自动分数分开。
- **配图**：核对[图示登记](../../src/content/data/figures.yaml)与[原创教学图](../../public/figures/wan21/overview.svg)，文字编码与随机噪声进入 DiT 后经 VAE 解码，图为推理简图，注明来源与 CC BY 4.0。Chromium 本地正文滚动加载图片成功（1200×400）、替代文本存在；截图目视检查中文与箭头。
