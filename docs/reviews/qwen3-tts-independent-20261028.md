# Qwen3-TTS 独立复核

范围：对照 [Qwen3-TTS 技术报告 v1](https://arxiv.org/html/2601.15621v1)、[官方仓库](https://github.com/QwenLM/Qwen3-TTS)和[1.7B Base 模型卡](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base)，核对文章和官方 Figure 2、Figure 3 的描述；未自行合成语音或复现评测，未修改共享 YAML。

- 12Hz 是系列名称，报告 2.2 节列 12.5Hz、一层语义码本及 15 层 RVQ 声学码本；WavLM 指导语义层，因果编码器和解码器支持流式。正文没有把码本语义划分当作绝对隔离，也未将码本索引与文字 token 等同。
- 报告 3.1 节描述骨干汇总码本特征预测第 0 码本，MTP 产生其余码本，Code2Wav 重建语音；25Hz 单码本和分块 DiT 为不同路线。两张配图分别是原报告 Figure 2、3，仓库许可文件注明 CC BY 4.0 和来源，元数据以 12Hz 及可选条件为范围。
- 对照报告 3.2 节，超过 500 万小时多语言语音、高质量继续训练、8192→32768 的三阶段预训练和 DPO、规则奖励 GSPO、声音轻量微调的概述一致。官方仓库显示 Base、CustomVoice 两种规模，VoiceDesign 为 1.7B；1.7B Base 卡标注 Apache 2.0，正文补入模型卡链接并限定到对应检查点。
- 报告表 5 为 Seed-TTS 零样本声音克隆：1.7B Base 的 test-en WER 1.24、0.6B Base 1.32；正文补全测试性质，记录仓库提供的 bfloat16、2048 最大生成 token 与语言自动选择条件，避免当成通用指标。此设置是仓库所述评估条件，不推断所有表格和对照模型采用相同计算资源。
- 报告表 2 并发 1 的 0.6B 93+4=97ms、1.7B 97+4=101ms 与正文一致；4 帧 320ms 是输出语音时长而非首包等待。图片为本地 PNG，未进行浏览器截图验收或校验原始下载与当前远程图片字节一致性。
