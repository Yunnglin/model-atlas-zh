# PPO 优势估计例子复核（2026-10-29）

范围：核对 PPO 正文新增的三步 GAE 教学示例和相关边界，不代表重新审阅全文或实际运行 PPO。

- 对照 [GAE 原论文](https://arxiv.org/html/1506.02438)的时间差分误差和指数加权优势估计，设折扣 1、权重 0.95、最终奖励 1、结束状态价值 0。三步误差为 0.2、0.1、0.3；倒推优势为 0.3、0.385、0.56575，正文末项保留三位小数。
- [InstructGPT 附录 C.3](https://arxiv.org/html/2203.02155)报告使用广义优势估计、不做折扣；教学样例并非其披露的训练样本。正文没有把 GAE 描述为 PPO 唯一的优势计算法。
- 示例不含 KL 奖励及真实训练中的归一化、截断处理；正文明确其假设和实际实现需要记录的边界。未实际运行训练或复现论文结果。
