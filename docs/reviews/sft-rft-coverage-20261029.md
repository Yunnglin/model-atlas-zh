# SFT：拒绝采样微调覆盖补充（2026-10-29）

- 现有训练技术库独立覆盖 SFT、LoRA、RLHF、RLVR、PPO、GRPO、GSPO、DPO、KTO、ORPO、SimPO、DAPO、CISPO、RLOO、蒸馏及量化；QLoRA、GPTQ、AWQ、SmoothQuant 等已在量化文章说明。拒绝采样在 DeepSeek-R1 页面出现，但原 SFT 主文缺少可复用的总述，因此补入主文而不为相近概念重复创建页面。
- 对照 [RFT 原论文](https://arxiv.org/abs/2308.01825)第 3.3 节：生成多个候选，按答案和计算过程筛选、控制重复，再将通过的示范与原数据结合进行监督训练；论文的模型与数据范围不应扩展成普遍效果。正文示范的四份答案是自构例子，并区分 GRPO 的组相对策略更新。
- 对照 [STaR 原论文](https://arxiv.org/abs/2203.14465)第 3.2 节：对生成失败的题，在训练阶段给出标准答案并重新生成解释，再筛选用于学习；正文没有将答案提示带入评测，也提醒正确结论未必保证推导正确。
- 2026-10-29 在已登录浏览器实读 [绝密伏击：RFT（拒绝采样微调）](https://zhuanlan.zhihu.com/p/703848627)，页面显示 **161 赞、453 收藏**。文章解释候选生成、质量过滤、去重与多模型路径；其“筛选确保高质量”等表达过于绝对，正文据 STaR 论文第 5 节明确指出正确结论可能来自错误推导。论文事实与性能以一手资料为准。
