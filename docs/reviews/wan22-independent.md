# Wan2.2 审校记录

2026-10-28 对照 [Wan2.2 官方仓库](https://github.com/Wan-Video/Wan2.2)、[T2V-A14B 模型卡](https://huggingface.co/Wan-AI/Wan2.2-T2V-A14B)和 [TI2V-5B 模型卡](https://huggingface.co/Wan-AI/Wan2.2-TI2V-5B)。核对 2025-07-28 开放权重、Apache 2.0、两位按噪声阶段切换的专家约 27B 总参数及每步约 14B 激活；TI2V 是独立稠密 5B，VAE 压缩 4×16×16、后续 patch 化总尺度 4×32×32。帧率不是生成速度；卸载与显存取决于具体配置。

官方材料称图像数据增 65.6%、视频增 83.2%，提供不同专家组合的验证损失及 Wan-Bench 2.0 对比，但未公开完整可复现训练配方。仓库引用的 [Wan 论文](https://arxiv.org/abs/2503.20314)是早期 Wan2.1 背景，不冒称 Wan2.2 专属报告。

已在独立已登录 Chrome 标签阅读 [LittleNyima 的代码解读](https://zhuanlan.zhihu.com/p/1933274999587841225)：2026-10-28 可见 60 赞、57 收藏。文章列出官方两个检查点和推理时阶段切换、VAE 代码，有助阅读；其文字将早期/后期的高低信噪比表述反了，正文以官方资料的“高噪前期、低噪后期”为准，未采用反向表述。仅引用作为辅助阅读，没有照抄代码或作者未证实的训练细节。

原创图是 A14B 接力与 TI2V 独立路线的教学概览，并非官方架构图。没有加载权重、验证显存或速度、复现榜单；未修改共享 YAML。
