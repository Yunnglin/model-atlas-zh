# 蒸馏知乎资料交叉核查

2026-10-28 在已登录知乎直接阅读[一只路过的烧鸡：《大模型知识蒸馏：On-Policy Distillation（原理篇）》](https://zhuanlan.zhihu.com/p/2023108953026883794)，页面显示 151 赞、275 收藏；数量是该时点快照。文章把离线教师示范与学生在线生成轨迹的区别、Qwen3 应用及 KL 方向放在一起讨论，适合延伸阅读。

- 对照 [Qwen3 报告第 4.5 节和表 21](https://arxiv.org/html/2505.09388)：8B 学生从相同离线蒸馏检查点继续训练；对照仅使用数学和代码相关查询。表 21 的 GPU 时间是后续两个分支的报告数字，不能据此估算包括教师和前序阶段在内的完整成本，更不能推成所有蒸馏都比所有 RL 省十倍。
- 文章把反向 KL 描述为 LLM 蒸馏中一般用来取代正向 KL；[GKD 论文](https://arxiv.org/abs/2306.13649)研究多种分布差异度量，不能作这种普遍断言。
- 文章把 R1 的 80 万条全归为教师生成推理数据；[R1 论文 2.3.3 节](https://arxiv.org/html/2501.12948v1)描述约 60 万条推理样本和约 20 万条非推理样本，后者沿用 DeepSeek-V3 数据流程。论文 3.2 节亦概述为 R1 生成 800K，应保留这两处表述差异；正文采用更具体的数据准备描述。

本轮只核对上述几项，未运行模型、训练或复现论文结果。
