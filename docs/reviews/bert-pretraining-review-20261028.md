# BERT 预训练与评测核对

- 原始论文：[BERT](https://arxiv.org/html/1810.04805)，第 3.3 节和表 5：掩码位置按 80% / 10% / 10% 三种方式处理；BERT-Base 原设置与去掉 NSP 的 QNLI 开发集准确率分别为 88.4 / 84.9，SQuAD 开发集 F1 分别为 88.5 / 87.9。
- 对照：[RoBERTa](https://arxiv.org/html/1907.11692) 第 4.2 节和表 2 同时改变了输入组织方式与 NSP 目标；不能把跨设置结果差异全部归因于 NSP。
- 中文资料：苏南《[浅谈 NLP 预训练模型](https://zhuanlan.zhihu.com/p/112929902)》，2026-10-28 阅读时显示 53 赞、67 收藏。其对于输入嵌入、微调与特征提取的概述有助于入门；掩码段落用全替换为 `[MASK]` 介绍，省略了随机替换和保持原样两种情况，因此具体比例以原论文为准。文章称 768 / 1024 为 feedforward 隐藏层维度；它们实际是模型隐藏表示宽度，原论文的前馈中间层分别是 3072 / 4096。
- 本次为预训练样本和 NSP 消融的定向审阅，不代表该模型全部细节已逐句完成复核。
