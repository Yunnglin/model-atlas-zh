# Qwen2.5-1M 全维度审阅

审阅日期：2026-10-29。时间线 ID 为 `qwen25-1m`、正文为 `src/content/docs/nlp/qwen25-1m-model.md`；这是 Qwen2.5 长上下文模型，不是 Qwen2.5-Math。完整通读正文，对照技术报告 v1、模型卡、原创配图和既有知乎实读记录；未运行权重或复现论文。

## 结构与模型卡

- [7B 模型卡](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct-1M)与 [14B 模型卡](https://huggingface.co/Qwen/Qwen2.5-14B-Instruct-1M)：参数为 7.61B／14.7B，层数 28／48，查询头与键值头为 28／4 和 40／8；模型卡给出全上下文 1,010,000 token 与生成长度 8192，均为 Apache 2.0。
- [报告第 5 节](https://arxiv.org/html/2501.15383v1)：DCA 对块内、相邻块及远块作不同相对位置处理，结合 YaRN 注意力缩放以外推；稀疏注意力是选择计算位置的另一项推理优化。关键 token 的选择使用较连续的位置，最终权重仍使用 DCA 位置编码。报告区分这两步；正文未把 DCA 写成摘要或删除正文。
- 参考模型卡的 1M 输入配置，本次补充 7B／14B 推荐总显存至少 120GB／320GB，并注明多 GPU 和配置差异；该数据为官方配置参考，不是实际运行验证。

## 训练

- 报告第 3–4 节与表 2：前两阶段 4096／32768 token 沿 Qwen2.5 Base，中间检查点继续训练至 65536、131072、262144 token；后三阶段 75% 当前最大长度、25% 短序列。
- 长文自然材料和合成任务共同使用；短指令 SFT 后混合长短指令，再用不超过 8192 token 的短样本进行类似 DPO 的离线偏好优化。Qwen-Agent 参与合成答案不保证答案无误；无依据将训练长度写成 1M。

## 评测与应用

- 表 2 的 Qwen2.5-14B-1M 在 128K RULER 上，32K 训练阶段 37.6、256K 阶段 87.6；属于预训练阶段实验而非最终 Instruct 普适得分。
- 图 6 的 7B 找针实验中原 MInference 超过 400K 可降到 60% 或更低，改进位置选择和稀疏配置后恢复大部分并约 4 倍预填充加速。报告图 11 中新增对照是 14B、1M、batch 1、8 路张量并行、H20：TTFT 全注意力约 12.2 分钟，优化后 109 秒；包含稀疏注意力及引擎改进，不代表完整响应等比例加速。
- 合同示例中 9/10 格式通过、7/10 严格答对分别为 90% 与 70%，是构造算例；证据位置、解析、分组与独立回归为实践建议。
