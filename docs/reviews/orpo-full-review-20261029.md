# ORPO 训练技术审阅

审阅日期：2026-10-29。完整通读 `src/content/docs/training/orpo.md`，对照原论文 v2、算例、评测及配图；未运行训练或复现论文。

## 原理与资料

- [ORPO 论文第 4 节](https://arxiv.org/html/2403.07691v2)：回答每个 token 的对数概率取平均、再取指数构成长短归一化分数；赔率是该分数除以 1 减去该分数。目标由优选回答的监督损失与加权赔率比损失组成，不需单独参考模型或奖励模型；分数不是答案事实正确的概率。
- 论文符号中的 P 采用上述长度归一化定义；正文写成完整序列概率的 1/长度次方，与之等价。标准 ORPO 用同题优劣对，与 KTO 的单条正负反馈和 DPO 的参考模型对照区分。

## 算例与评测

- A、B 分数为 0.6、0.4 时赔率为 1.5、2/3，赔率比 2.25；本次补充偏好项的 sigmoid 值 9/13≈0.692、负对数约 0.368，与赔率比为 1 时的 ln2≈0.693 对照。完整损失还包含监督项。
- 正文新增两组同为 2 倍的分数比：0.6／0.3 与 0.2／0.1 的赔率比分别为 3.5、2.25，以解释赔率比和简单概率比的区别；对照论文第 7.1 节，这只说明计算性质，不宣称对任何任务均更好。
- 论文附录 E 使用 Mistral 7B、UltraFeedback 对比 λ=0.1、0.5、1.0；λ=1 时优劣回答平均对数概率均下降而间距扩大。本文没有把更大的偏好间距当成单条回答概率必然增加。
- 新增论文表 1、摘要及评测协议：Mistral-ORPO-β 的 AlpacaEval 2.0 为 12.20%、MT-Bench 为 7.32；前者在 GPT-4-turbo 评审设置下对比 GPT-4 参考回答，是偏好指标而非事实正确率。
