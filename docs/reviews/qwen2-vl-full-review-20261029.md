# Qwen2-VL 专项审校

审校日期：2026-10-29。通读 [Qwen2-VL 正文](../../src/content/docs/omni/qwen2-vl-model.md)，范围为 2024 年 Qwen2-VL 的 2B、7B 和 72B；未运行模型或复现评测，发票和视频例子为教学构造。

- **结构**：对照[技术报告 v2 第 2.1 节及表 1](https://arxiv.org/html/2409.12191v2)，核对 675M ViT、Qwen2 骨干、14×14 patch、相邻 2×2 特征经 MLP 合并、动态分辨率、M-RoPE 和双帧深度 3D 卷积。补充说明视觉编码器计算发生在合并之前，不能只按语言模型输入 token 数估算全部计算。
- **训练**：报告第 2.2 节核对三阶段冻结与解冻、6000 亿及 8000 亿预训练 token 的图文合计口径、文本位置监督，以及 DFN ViT/Qwen2 初始化。视频 2 fps 和 16384 token 上限属于论文训练设置，不推广为所有推理的限制。
- **评测**：对照报告表 7、8，核对不同图像 token 预算下 InfoVQA 65.72/75.89、表 8 的 1D-RoPE → M-RoPE：NextQA 43.9 → 46.0、STAR 55.5 → 57.9、InfoVQA 50.8 → 50.3；这些是 Qwen2-1.5B 与 ViT-L 的预训练模型消融，保留不同预算与任务口径。第 2.2.1 节核对定位坐标归一化范围 [0,1000)，补充坐标相对图像尺寸、缩放映射及框正确性的例子。
- **配图**：检查[图示登记](../../src/content/data/figures.yaml)和[原创图](../../public/figures/qwen2-vl/overview.svg)，图中的视觉编码、相邻特征合并、文字与 Qwen2 语言模型的流向与论文简化流程一致，图注注明省略细节、非官方图与 CC BY 4.0。Chromium 本地页面解码图片成功、宽 1060，替代文本存在；截图中中文与箭头可读。
