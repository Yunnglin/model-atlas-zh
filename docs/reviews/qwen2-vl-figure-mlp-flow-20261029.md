# Qwen2-VL 教学图视觉数据流复核（2026-10-29）

对照 [Qwen2-VL 技术报告 v2 第 2.1 节](https://arxiv.org/html/2409.12191v2#S2.SS1)和 `src/content/docs/omni/qwen2-vl-model.md`：视觉编码后，MLP 将相邻 2×2 特征合并，视觉表示与文字进入 Qwen2 语言模型；M-RoPE 为时间、高度和宽度提供位置编码。图省略图像标记、视频管块和训练阶段，不是官方完整架构图。

原图写“2×2 特征合并”，没有体现 MLP，且文字输入箭头朝上停在语言模型左侧，容易被误认为未连到模型。现将框标为“MLP 合并 2×2 特征”，并将文字输入箭头调整为朝向语言模型；同步更新 SVG 描述与 `figures.yaml` 替代文本。用 Chromium 渲染 SVG 并检查文字及箭头；未运行模型或复现论文实验。
