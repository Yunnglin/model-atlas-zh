# 六个专项模型的重点复核

核对日期：2026-10-27。逐篇阅读下列模型卡、结构、训练和评测段落，检查对应教学 SVG 的标题、说明与节点文字，并针对列出的事实对照官方报告或模型卡。没有逐句或逐像素核验全部内容，也未运行模型、训练或基准；知乎文章沿用已有的阅读记录，本轮未重新核对互动量。

- **Qwen2.5-Math**：对照[技术报告](https://arxiv.org/html/2409.12122)第 2–3 节，确认基于 Qwen2.5 的专项续训、1T 语料口径和 GRPO；补充 CoT 问题池、生成样本数与 SFT 训练轮数的区别。教学图将执行工具放在模型外；模型卡和博客／论文的 MATH 分数差异在正文保留来源。
- **Qwen3 Embedding**：对照[技术报告](https://arxiv.org/html/2506.05176)第 2–4 节及附录，核对 EOS 最后一层表示、yes/no 重排、三个规格的维度和训练阶段；补充各阶段数据规模与 checkpoint 球面插值，并保留假负例和实际索引重建的限制。图只展示召回／重排流程，不表示生成最终答案。
- **QwQ-32B**：对照[官方发布](https://qwenlm.github.io/blog/qwq-32b/)和[模型卡](https://huggingface.co/Qwen/QwQ-32B)，核对两个 RL 阶段、32.5B／64 层、40／8 头、YaRN 的使用条件。补充“冷启动检查点”只作为官方描述，构建它的数据与配方未公开。图只表达博客的阶段并省略算法细节。
- **Kimi Linear**：对照[论文](https://arxiv.org/html/2510.26692)第 5.4–5.6 节及附录，核对 3:1 混合层、受控 1.4T 对照、5.7T 开放版本以及 1M RULER 分数和吞吐条件；纠正教学图中“各层前馈 MoE”的概括，实验模型第一层使用稠密前馈，其余专家结构见论文。同步修改图注、可访问替代文字和资产校验值。
- **Kimi-Audio**：对照[技术报告](https://arxiv.org/html/2504.18425)第 2、4、6 节，核对 12.5 Hz／50 Hz 特征对齐、双输出分支、Whisper 特征冻结和 LibriSpeech 分数；补充论文举例的 4 个前瞻 token 对应约 0.32 秒内容，强调这不等于系统端到端时延。教学图省略分块细节。
- **Kimi-VL**：对照[技术报告](https://arxiv.org/html/2504.07491)第 2–3 节，核对 16B／2.8B Moonlight、400M MoonViT、2×2 特征合并与 InfoVQA 83.2 的模型及 ANLS 测试口径；补充视觉训练与冻结语言模型的视觉对齐阶段，区分后续多模态联合更新。图省略路由、预处理及层内细节。
