# PPO 裁剪教学图核对

原创图 `public/figures/training/ppo-clipping.svg` 不含外部图片，对照 [PPO 原论文](https://arxiv.org/abs/1707.06347) 的 clipped surrogate objective，以 ε=0.2 举例。

- 正优势 +1、比率 1.5：未裁剪项 1.5，裁剪项 1.2，目标取 1.2。
- 负优势 −1、比率 0.5：未裁剪项 −0.5，裁剪项 −0.8，目标取 −0.8；必须先乘优势再取较小值。
- 图明确裁剪改变优化目标的激励，不给概率比、模型参数或 KL 设硬边界；这是两条独立样本的演示，不是实际训练结果。
- 图通过 XML 解析，正文插入图片并说明用途；未进行模型训练或真实浏览器显示验收。
