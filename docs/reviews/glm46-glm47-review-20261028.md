# GLM-4.6 与 GLM-4.7 核查记录

核查时间：2026-10-28。范围是两篇模型卡、配置中主要结构、官方公开训练信息、部分评测表和本地教学图；不代表逐条验证全部能力结论，也未进行推理或复现实验。

- 对照 [4.6 配置](https://huggingface.co/zai-org/GLM-4.6/blob/main/config.json)与 [4.7 配置](https://huggingface.co/zai-org/GLM-4.7/blob/main/config.json)：两者都列出 92 层、前 3 层稠密、160 个路由专家、8 个每 token 选中专家、1 个共享专家、96 个查询头与 8 个键值头；配置同样列出一个多 token 预测层。配置相同并不能单独说明两个版本的训练过程相同。
- [系列官方仓库](https://github.com/zai-org/GLM-4.5)列两者均为 355B-A32B，并提供 BF16 和 FP8 权重。两张官方模型卡均指向 4.5 技术报告，未给出可完整还原 4.6／4.7 训练配方的数据和参数；正文保留这一公开范围。
- [4.7 官方模型卡](https://huggingface.co/zai-org/GLM-4.7)的表格列出 4.6 与 4.7 在 SWE-bench Verified 的 68.0 与 73.8，以及 SWE-bench Multilingual 的 53.8 与 66.7。官方给出采样建议与思考保留说明；这不是对全部实验脚手架、重复次数的完整验证。
- 原教学图将工具直接连到最终答案；现改为工具结果返回模型，再由模型输出，Chromium 渲染检查过图内走线；同步了 `docs/assets.md` 的图哈希。图仍是简化交互，不是模型结构图。
- 4.7 保留思考的 SGLang 模板参数对照官方仓库示例，其他框架和服务的实现未验证。现有知乎文章本轮未重新阅读。
