# Transformer 中文图解交叉核对（2026-10-28）

实读[初识CV：Transformer 模型详解](https://zhuanlan.zhihu.com/p/338817680)，页面显示约 1.8 万赞同、3.9 万收藏。文章对原始编码器—解码器结构、因果掩码和注意力计算有图解价值，互动量不能证明全部细节正确。

对照 [Transformer 原论文第 3.1、3.2 节](https://arxiv.org/html/1706.03762)：解码器块先做因果自注意力，再以其输出作为交叉注意力的查询输入；键和值来自编码器输出。最终词表投影与 softmax 位于解码器堆叠之后。中文图解部分文字容易将交叉注意力查询说成上一块直接输出、将词表 softmax 归入每个块；正文已解释数据流。

本次核对上述架构重点，没有逐句检查整篇社区文章或运行翻译模型。
