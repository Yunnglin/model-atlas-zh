# Stable Diffusion v1-4 专项审校

审校日期：2026-10-29。完整通读 [v1-4 正文](../../src/content/docs/cv/stable-diffusion.md)，未运行模型、训练或复现评测。红杯例子、数值和排错步骤是教学构造。

- **结构**：对照 [v1-4 模型卡](https://huggingface.co/CompVis/stable-diffusion-v1-4)、[官方代码](https://github.com/CompVis/stable-diffusion)及 [LDM 论文第 3 节](https://arxiv.org/html/2112.10752)，核对 f=8 的四通道潜空间、CLIP 文字编码、U-Net 中交叉注意力、预测噪声和 VAE 解码；区分 U-Net 860M 与整套参数。512×512×3 与 64×64×4 的数量比为 48，不是文件大小或性能实测。
- **训练**：对照模型卡训练部分核对 v1-1 的 237k/194k、v1-2 的 515k 和 v1-4 从 v1-2 开始的 225k 阶段，以及 512 分辨率、数据、条件丢弃与冻结文字编码器。补入阶段沿革和非英语提示的训练数据背景；明确步数不等于去重样本数量。噪声预测目标和 CFG 的公式及新加标量算例与 LDM/CFG 定义一致；例子并非实测。
- **评测**：对照模型卡 Evaluation Results 核对 COCO2017 验证集随机 10000 条提示、512×512、PLMS 50 步和不同 CFG 强度，及其未针对 FID 优化的条件。对象、颜色、关系和错例的建议是自拟评测方案，未声称论文结果或实际执行；比较 FID 要固定提取方法、样本和参照集。
- **配图**：检查[图示登记](../../src/content/data/figures.yaml)与[原创教学图](../../public/figures/stable-diffusion/overview.svg)；文本编码、潜噪声、多步去噪和 VAE 解码的箭头与推理流程一致，图中明确不展示训练。登记来源、署名和 CC BY 4.0；Chromium 打开本地正文，图解码成功、宽 1060、替代文本存在，截图目视检查文字与箭头。
