# Qwen-Audio 初代重点核查

核查日期：2026-10-28。本次复核模型卡、结构、训练配置及两项识别评测，未逐句核对整篇文章或运行模型。

- [Qwen-Audio 论文 v2 第 3.1 节](https://arxiv.org/html/2311.07919v2#S3.SS1)列出以 Whisper-large-v2 初始化的 32 层音频编码器约 640M 参数，语言底座 Qwen-7B 为 32 层、隐藏维度 4096、7.7B 参数；预处理使用 16 kHz、80 通道梅尔频谱、25ms 窗长与 10ms 步长，池化后的输出约每 40ms 一个时间步。正文新增四秒音频的近似计算，实际边界可能受填充影响。
- [论文第 4.1 节和表 6](https://arxiv.org/html/2311.07919v2#S4.SS1)说明多任务预训练冻结语言模型、优化音频编码器；Chat 微调冻结编码器、优化语言模型。正文加入各阶段训练步数、批量与学习率，保留论文实验口径。
- [论文表 3](https://arxiv.org/html/2311.07919v2#S4.T3)列 LibriSpeech `test-clean` / `test-other` WER 为 2.0% / 4.2%。两者是不同数据切片，不能等同于其他任务表现。
