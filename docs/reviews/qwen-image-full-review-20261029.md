# Qwen-Image 专项审校

审校日期：2026-10-29。范围是 [初代 Qwen-Image 正文](../../src/content/docs/cv/qwen-image.md)；通读正文，对照官方报告和模型卡；未运行生成、训练或评测。海报、流匹配标量和 OCR 错例均为教学构造。

- **结构**：对照 [技术报告第 2 节及表 1](https://arxiv.org/html/2508.02324)，核对冻结 Qwen2.5-VL、VAE、双流 MMDiT、MSRoPE，以及 1024 图片对应 128×128×16 潜变量和 2×2 打包后的 4096 图像 token。补充 60 层、24 头及每头 128 维，区分网络层数与采样步数。初代文生图与 Edit、后续 2.1 的权重和任务分别描述；[初代模型卡](https://huggingface.co/Qwen/Qwen-Image)标注 Apache-2.0。
- **训练**：报告第 2.3、3、4 节核对冻结 VAE 编码器、微调图像解码器、流匹配、多阶段分辨率以及 SFT、DPO、GRPO；新增 256/640/1328 训练尺度示例和约 5% 受控合成数据的范围，报告明确该合成类别不包含其他生成式模型合成的图片。文中公式是一种时间方向约定，教学数据与排错建议不当作官方配方。
- **评测**：对照报告第 5.2.2 节及表 4、9，核对 GenEval 中 SFT 0.87、RL 0.91 和 ChineseWord 一级 97.29、三级 6.48；单字评测不能直接视为整张海报成功率，不将 RL 结果归到任意下载权重。模型提取文字正确性、布局及未修改区域分别评测；例子非实测。
- **配图**：对照[图示登记](../../src/content/data/figures.yaml)与[原创示意图](../../public/figures/qwen-image/overview.svg)，文字编码、随机潜变量、MMDiT 迭代与 VAE 解码方向与报告简化流程一致；明确非官方原图、来源和 CC BY 4.0。Chromium 本地页面滚动加载并解码成功，替代文本存在；截图检查文字及箭头。

## 本轮评测数字复核

- 对照[报告表 2、4、9](https://arxiv.org/html/2508.02324)：内部文字密集图片的 256×256 重建测试中，Qwen-Image VAE 的 PSNR/SSIM 为 36.63/0.9839，Wan2.1 VAE 为 26.77/0.9386；该实验使用 float32，测的是已有图像重建。GenEval 的 Qwen-Image 与 RL 变体分别为 0.87/0.91；ChineseWord 单字渲染的一级和三级准确率为 97.29/6.48。正文中未把这些指标当作海报整体成功率；本轮未运行评测。
