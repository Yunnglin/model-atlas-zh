# F5-TTS 采样流程教学图补充核查

2026-10-29 对照 [F5-TTS 论文第 2.1 节](https://arxiv.org/html/2410.06885#S2.SS1)及[正文](../../src/content/docs/audio/f5-tts.md)：推理时 ODE 求解器从噪声状态开始，在多个时间点调用神经网络估计更新方向；积分得到的梅尔谱再交给声码器。函数评估次数 NFE 指经过网络的次数。

此前教学图底部已有“多次调用模型”的文字，但框之间只画单向箭头，容易让读者把积分看成模型只执行一次。现增加虚线反馈箭头，标示中间状态反复进入 DiT；同步 SVG 描述和图谱登记的替代文本。图仍是简化示意，不展示具体求解器的所有中间步骤。

以 Chromium 渲染本地 SVG，目视检查回路、文字和箭头无截断；未运行模型或复现采样。
