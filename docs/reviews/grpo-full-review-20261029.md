# GRPO 训练技术审阅

审阅日期：2026-10-29。范围为 `src/content/docs/training/grpo.md` 的组内优势、优化、奖励、数学例子、评测、配图和社区参考；未实际运行强化学习或复现基准。

## 原理与资料

- [DeepSeekMath 原论文第 4.1 节](https://arxiv.org/html/2402.03300)：GRPO 以同题多回答的奖励估计组相对优势，去掉单独价值网络；策略比率、裁剪与参考策略 KL 项各有作用。算法 1 在外层迭代设置参考策略，采样时另更新旧策略；正文与不同实现的固定参考设置区分。
- 第 4.1.2–4.1.3 节分别给结果监督和过程监督：结果优势用于整条回答，过程监督将同题所有步骤奖励归一化后对当前及后续结束步骤求和。正文不把验证最终答案等同检查每一步。
- RLHF、RLVR 说明反馈来源，GRPO 描述更新方式；原 DeepSeekMath 实验使用奖励模型，正文没有把其改写为必然采用规则评分。

## 例子与评测

- 1、0、1、0 用总体标准差 0.5 得到 ±1；1、0、0、0 的均值 0.25、总体标准差约 0.433，优势约 +1.73 / −0.58。独立采样正确率 10% 时，8 个样本有对有错的概率约 57%，16 个约 81%。正文已注明标准差与独立采样是假设。
- 原论文第 4.2 节与表 5：约 14.4 万数学题，64 个候选，长度 1024，学习率 1e-6，KL 系数 0.04，每轮采样后一次更新；Instruct 到 RL 的 GSM8K 82.9%→88.2%、MATH 46.8%→51.7% 为 CoT 设置。正文限定训练数据、评测与成本口径。
- 训练奖励、全对全错组、独立题及验证器错误的排查建议与教学例子区分；没有将奖励升高当作模型一定更好。
