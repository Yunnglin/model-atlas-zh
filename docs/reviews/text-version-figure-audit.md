# Qwen 与 DeepSeek 十张教学图版本核对

| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| Qwen1.5       | [Qwen2 官方发布](https://qwenlm.github.io/blog/qwen2/)回顾 1.5 稠密型号中 32B 与 110B 使用 GQA；图补充该型号条件，不将其泛化为整个系列。                                                       |
| Qwen2         | [技术报告](https://arxiv.org/html/2407.10671)第 2.2 节描述 GQA，以及稠密与 MoE 为不同配置；图将它们写为前馈网络的型号选择。                                                                    |
| Qwen2.5       | [技术报告](https://arxiv.org/html/2412.15115)第 2 节描述 GQA 和 SwiGLU；图用于开放稠密文本模型，不代表视觉分支的完整结构。                                                                     |

| DeepSeek-V2   | [技术报告](https://arxiv.org/html/2405.04434)第 2 节描述 MLA 压缩表示，以及共享和路由专家；图明确省略首层前馈差异。                                                                            |

| DeepSeek-R1   | [论文 v1](https://arxiv.org/html/2501.12948v1)第 2.3 节描述冷启动、推理强化学习、筛选生成数据后从 V3-Base 重新监督微调，再进行全场景强化学习；图注明省略 R1-Zero 和蒸馏。                      |
| DeepSeek-V3.1 | [官方模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V3.1)说明一个模型可通过聊天模板切换思考模式，并给出工具调用格式；图把工具执行画为外部可选步骤。                                       |
| DeepSeek-V3.2 | [技术报告](https://arxiv.org/html/2512.02556)第 2.1 节描述轻量索引器评分、选出 top-k 历史位置，再由主注意力处理；图注明省略 MLA 内部投影。                                                     |
