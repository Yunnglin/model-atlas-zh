# PPO、GRPO、GSPO 公式与例子复核

参与说明：本审阅者此前参与本仓库 GRPO/GSPO 的审校与正文调整（见 `rl-dapo-gspo-grpo-followup.md`、`rl-independent-20261028.md`）。因此这是再次对照原论文的复查，不能称为完全独立于既有内容作者的审查。没有实际训练或执行实验。

- [PPO 原论文](https://arxiv.org/abs/1707.06347)：裁剪目标先乘优势再取最小；+1、1.5、ε=0.2 得 1.2，−1、0.5 得 −0.8。代理目标不构成概率或 KL 的硬约束。0.8−0.5=0.3 明确是简化示意，不是一般 GAE。
- [DeepSeekMath 论文 4.1](https://arxiv.org/html/2402.03300)：结果监督组奖励归一化后赋予回答内所有 token；以总体标准差举例，1/0/1/0 得 ±1，1/0/0/0 得约 1.73/−0.58。标准差定义和全零组保护需看实现。原论文迭代算法每个外层迭代重设参考策略，并直接在损失中添加 KL；图也标明参考 KL 和两种可选奖励来源。
- 过程监督原文公式对同题多个回答的**所有步骤奖励**共同归一化，并累加该回答中结束位置大于等于当前 token 的步骤奖励。原正文只说“归一化后”和“之后”，未说明合并范围与等号边界；已补充并将示例数字明确为归一化后的奖励。
- [GSPO v2 论文第 4–5 节](https://arxiv.org/html/2507.18071v2)：序列比是完整新旧序列概率比的 1/T 次方，等于 token 比率几何平均；sqrt(1.44×0.64)=0.96，不能说明单 token 没变化。公式用对称 ε，实验用 0.0003/0.0004、GRPO 对照 0.2/0.27；正文已区分通式与具体实验，且没有把长度归一化比率称为无偏完整重要性权重。
