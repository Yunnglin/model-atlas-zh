# DeepSeekMath 训练与多次采样补充核对

核对日期：2026-10-29。对照 [DeepSeekMath 论文](https://arxiv.org/html/2402.03300)第 4.2、5.1.1、5.2.2 节及图 7，检查 `src/content/docs/nlp/deepseek-math-model.md` 的实验对象与表述。

- 论文第 4.2 节说明，RL 使用 SFT 数据中约 144K 道与 GSM8K 和 MATH 相关的思维链题，每题采样 64 个回答；这是论文的实验配置。
- 论文表 7 的 1.3B 控制实验中，HumanEval pass@1 为代码训练后 25.0%、随后数学训练后 12.2%，代码与数学混合训练 29.3%。正文将三个结果与正式发布的 7B 模型区分，并用其引出跨能力回归测试。
- 图 7 比较 7B Instruct 和 RL 在 GSM8K、MATH 上的 Maj@K 与 Pass@K，采样温度 0.7。论文报告 RL 改善 Maj@K，但没有对应提升 Pass@K；正文新增虚构五次采样示例，解释两个指标并保留论文的实验边界。
- 本次只核对所列训练和评测片段，未运行模型、复现评测或重新审校全文及配图。
