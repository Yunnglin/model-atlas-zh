# DeepSeek 核心版本专项审校

核对日期：2026-10-27。逐篇阅读 V2、V3、V3.1、V3.2 与原始 R1 正文，对照下列官方材料检查模型卡、关键结构、训练、部分评测数字与教学示意图的文字内容；这不是对每项声明和图中每个细节的逐句或逐像素核验。业务示例未实际运行。

- **V2**：对照[技术报告](https://arxiv.org/html/2405.04434)第 2–3 节，核对 236B／21B、MLA、每层 2 个共享与 160 个路由专家、选 6 个、3 设备上限及 8.1T token。补充长上下文扩展训练用 32K 序列，而评测覆盖 128K；标明原论文 MMLU 78.5 与 V3 报告内 78.4 来自两篇报告，不能假设口径完全一致。教学图省略第一层的稠密前馈，图注已有说明。
- **V3**：对照[技术报告](https://arxiv.org/html/2412.19437v2)第 2、4、5 节，核对 671B／37B、MoE、MTP 深度 1、14.8T token 与 GPU 小时所包含阶段；补明 MMLU 数字的评测出处。教学图明确省略前三层稠密前馈及 MTP，不代表完整计算图。
- **V3.1**：对照[官方模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V3.1)和[官方发布](https://www.deepseek.com/en/news/deepseek-v3-1/)，核对 630B／209B 长上下文扩展、两种模板及总／激活参数；补充代码智能体报告的 66.0 与 31.3 是非思考模式，并注明内部智能体与 Terminus 1 不同框架。配图是模式和可选工具流程，省略层结构。
- **V3.2**：对照[技术报告](https://arxiv.org/html/2512.02556)第 2–4 节，核对稠密热身、2048 候选、稀疏阶段 token 数与 BrowseComp 的 51.4 评测设置；在模型卡中添加[正式版文件页](https://huggingface.co/deepseek-ai/DeepSeek-V3.2)显示的约 685B 张量统计，说明其不能直接当成激活参数或与 V3 论文统计口径互换。配图只展示索引器粗筛及主注意力，省略 MLA 层内实现。
- **R1**：对照[初版论文](https://arxiv.org/html/2501.12948v1)第 2.3–2.4 节，修正第二次 SFT 重新从 V3-Base 微调，而不是直接继续推理 RL 权重；区分约 60 万条推理与约 20 万条非推理样本，说明蒸馏版论文采用 SFT 未加入额外 RL。训练图已重绘为数据生成与从底座重新微调两行，区分数据输入和模型训练阶段。AIME 15.6、71.0、86.7 的统计与投票预算分别对照论文，不能直接混用。
