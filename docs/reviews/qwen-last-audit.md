# Qwen 图像与混合注意力模型重点审校

核对日期：2026-10-27。本轮阅读下列三个独立模型页面的模型卡、结构、训练、部分评测与教学例子，并查看三张 SVG 中的标题、节点文字和连线。这是有明确范围的重点核验，不能证明全部陈述已逐句核对或图形已经逐像素审查；未运行模型或复现评测。

- **Qwen-Image 初代**：对照[技术报告](https://arxiv.org/html/2508.02324)第 2、4、5 节，核对冻结 Qwen2.5-VL、VAE 和双流 MMDiT 的职责，流匹配与 SFT、DPO、GRPO 的训练描述；报告 GenEval 表中 Qwen-Image 0.87 与 RL 变体 0.91 的版本区别保留。补充 ChineseWord 单字测试的一级、三级准确率和适用范围，不能推广为整张海报成功率。教学图是文生图的简化流程，未把编辑权重画成初代权重。
- **Qwen3-Next-80B-A3B-Instruct**：对照[官方模型卡](https://huggingface.co/Qwen/Qwen3-Next-80B-A3B-Instruct)，核对 48 层的 3+1 混合布局、512 个路由专家选 10 个与 1 个共享专家、非思考模式；补充 15T 预训练 token、原生上下文、两种注意力的头数及模型卡评测的比较边界。教学图复用范围和 RoPE 差异见[图示抽查](figures-followup.md)。模型卡中 Base 的长上下文吞吐对比有具体模型和长度条件，不能外推到任意设备。
- **Qwen3.8-27B 与 2.4T-A95B**：对照[27B 模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)及[2.4T 模型卡](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)，核对 64／92 层、混合层布局、稠密与 MoE、模态和思考开关限制。补充分版本的许可标识及 Gated Attention 头数，说明 27B SWE-bench Pro 的工具框架、上下文、采样与数据修订条件；2.4T 模型卡的服务榜单不能直接归给本地权重。两种模型教学图只示意输入和主干差异，不是完整层图。
