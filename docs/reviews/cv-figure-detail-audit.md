# 视觉模型图文抽查

核对日期：2026-10-28。本轮针对五张教学示意和相应文章抽查指定主张；未逐项复现论文实验，也未审查所有视觉图。

| 模型                  | 核对点和原始依据                                                                                                                              | 结果                                                                                                       |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| ViT                   | [论文图 1 与第 3.1 节](https://arxiv.org/html/2010.11929)的分块、投影、分类 token 和编码器；正文中 224 × 224 输入按 16 × 16 分为 14 × 14 块。 | 原教学图的“224 ÷ 16 → 196 块”省略了第二维，可能被误读成一维除法等于 196，已改为“14 × 14 = 196 块”。        |
| CLIP                  | [论文第 2.3、3.1 节及附录表 11](https://arxiv.org/html/2103.00020)的双塔、批内双向对比和零样本分类。                                          | 图文流程符合抽查范围；正文中 76.2% 的 ImageNet 数字补充为 ViT-L/14、336 像素输入，避免误认为所有版本同分。 |

| Stable Diffusion v1-4 | [模型卡](https://huggingface.co/CompVis/stable-diffusion-v1-4)的文本条件、v1-2 起点及后续 225,000 步。                                        | 生成示意以文本条件和潜噪声进入去噪过程，再经解码器输出；训练环节在图下注明省略，正文区分训练与采样。       |

教学示意不等于官方结构图。上述核查只说明对应流程与列出的依据没有发现冲突，不保证其他版本及图中省略的细节相同。
