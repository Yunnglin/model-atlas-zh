# Qwen3.8-2.4T-A95B 结构与评测口径补充复核

2026-10-29 对照 [Qwen 官方 2.4T-A95B 模型卡](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)和[公开配置](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B/blob/main/config.json)，核查正文中该具体规格的参数、结构、训练披露和评测来源；不将同页的 27B 数据套用到本规格。

- 模型卡列总参数 2.4T、每 token 激活 95B，92 层由 23 组每组三层 Gated DeltaNet 加一层 Gated Attention 组成，因此分别为 69 层和 23 层。512 个路由专家每 token 选择 10 个，加一个共享专家；Gated Attention 的 Q/KV 头数为 64/4、头维度 256。正文按这些配置解释结构，未将专家数量混作注意力头数。
- 配置 `max_position_embeddings` 为 262,144；模型卡说明原生 262,144，并介绍最高 1,010,000 token 的扩展。正文新增两项明确区分，扩展长度是模型卡公开的配置范围，不是长文任务的准确率保证。
- 模型卡公开预训练与后训练，并标明 MTP 多步训练，没有完整训练数据与奖励配方。正文调整“语言、视觉”并列的概括，明确开放 2.4T 权重是文本模型，27B 的视觉输入不能套用于该权重。
- 模型卡基准表的列名是 Qwen3.8-Max：SWE-bench Pro 为 67.7；脚注列 Claude Code、256K 上下文、temperature 1.0、top-p 0.95 和修正后的题集。该表属于带额外能力的 Max 服务，并非独立运行开放 2.4T 权重的评测；正文新增数字时明确标出服务及协议。

本次为定向静态审校，未执行模型、测量显存、运行训练或复现评测；未重新核查配图与知乎文章。
