# Qwen2-VL 视频预算与训练示例复核

2026-10-29，针对 Qwen2-VL 页面的视频输入和训练讲解，复读[官方技术报告第 2.1、2.2 节](https://arxiv.org/html/2409.12191v2)。这是定向补充，不代表重新逐项复核全文、运行模型或复现评测。

- 报告采用每秒两帧采样、时间深度为二的 3D 卷积，并在训练中将每个视频的视觉 token 预算限制为 16,384。正文新增一分钟／两分钟的教学算例，以处理后每组 160 个 token 为假设，强调实际缩放和抽帧策略影响数量；没有将训练预算说成所有部署时的固定限制。
- 报告描述三阶段训练：先训练视觉编码器，再解冻所有参数联合训练，最后固定视觉编码器并微调语言模型；预训练时总 token 统计包含图像与文字，但监督只施加于文本 token。正文用虚构发票示例说明监督信号和可训练参数的区别，不把示例描述为官方样本。
- 本次同时复核现有 224×224 图像 66 个位置、ViT 后 2×2 特征合并与位置编码三维描述，均与报告一致。
