# Qwen2.5-VL 与 Qwen3-VL 原图的来源核对

核查日期：2026-10-28。两份技术报告的 Figure 1 均是相应版本的官方架构图，分别展示视觉编码器、视觉语言连接和语言模型；Qwen3-VL 图还展示多层视觉特征注入。两图来源为 [Qwen2.5-VL 报告](https://arxiv.org/html/2502.13923v1#S2.F1)和 [Qwen3-VL 报告](https://arxiv.org/html/2511.21631v1)，后一份的 [Figure 1 原图](https://arxiv.org/html/2511.21631v1/figures/qwen3vl_arc.jpg)可直接打开。

arXiv 的[前者许可](https://arxiv.org/abs/2502.13923v1)和[后者许可](https://arxiv.org/abs/2511.21631v1)均指向[非独占分发许可](https://arxiv.org/licenses/nonexclusive-distrib/1.0/)，其文字授予 arXiv 分发文章的权利，不能据此断言第三方有权在开源仓库重新分发图像。模型权重或其他代码仓库的许可也不能自动推定适用于论文原图。因此保留已有原创教学图，通过论文或原图链接供读者查看官方版本；并未复制或重新授权图像。若将来获得明确的图像复用许可，可再按照资产登记流程接入。
