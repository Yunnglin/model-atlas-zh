# RLVR 训练技术审阅

审阅日期：2026-10-29。通读 `src/content/docs/training/rlvr.md`，对照 DeepSeek-R1 初版、规则验证示例、配图与既有社区线索；未运行训练或复现评测。

## 原理与资料

- [DeepSeek-R1 v1 第 2.2 节](https://arxiv.org/html/2501.12948v1)描述 R1-Zero 的 GRPO、正确性规则奖励及格式奖励；后续 R1 有不同训练阶段。正文将可验证奖励的来源与策略更新算法分开，也区分规则验证器、学习型 ORM 和 PRM。
- 最终结果可验证不意味着推理每步正确；验证器可因答案提取或有限测试给出错误结果。案例的数值与奖励只是解释方法，不称作模型实测。
- 第 2.2.2 节还说明 R1-Zero 未使用神经 ORM 或 PRM，原因是担心奖励模型被利用以及额外训练开销；正文新增直观例子，同时指出规则也可能误判，不把个案选择推广为所有 RLVR 的通用要求。

## 例子与评测

- 80×0.8=64；错误算法示例 80−8=72；仅返回第二个参数的程序通过 (1,2)、(3,5)，在 (9,2) 失败。答案奖励 (1,0,1,0) 平均 0.5，未把均值差误写成标准差归一化后的优势。
- 报告图 2 与表 2：R1-Zero AIME 2024 估计 pass@1 从 15.6% 升至 71.0%，cons@64 为 86.7%；曲线每题 16 次采样估计单次结果，64 次多数投票是另一种决策预算。本次补充采样次数及区分测量与投票。
- 验证器覆盖、隐藏测试、格式和执行故障的区分，以及独立回归均为可复验建议。
