# RLOO 组合奖励补充核查（2026-10-29）

本次核对 [RLOO 论文第 2 节公式 2、3，以及 2.3 节](https://arxiv.org/html/2402.14740)：论文将奖励模型分数减去参考策略的对数概率比乘以系数，构造序列奖励，再用同一提示下其他回答的序列奖励计算留一基线。此前正文说明了可能使用 KL 约束，但没有讲清该实验的具体奖励与留一基线的关系。

正文补充奖励 2、系数 0.1、对数比 3 得到 1.7 的假设例子，并区分单个样本的对数概率比与在当前策略分布上取期望所得的 KL 散度。数值是教学演示，并非论文实验结果；本次未运行模型或复现论文评测。

本次另对照论文表 1 与评测说明确认 TL;DR 的 77.9 与 67.6 是相对于 SFT 回答的 GPT-4 模拟胜率，论文按测试奖励选择检查点；已有正文已明确这些条件。相关社区来源和图片核查继续沿用 [RLOO 完整审阅](rloo-full-review-20261029.md)，本次没有重新查阅知乎或检查图片。
