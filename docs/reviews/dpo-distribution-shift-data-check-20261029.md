# DPO 分布迁移对照的数据条件核查（2026-10-29）

对照 [DPO 论文第 6.3 节及表 1](https://arxiv.org/html/2305.18290#S6.SS3)：从 Reddit TL;DR 摘要任务转到 CNN/DailyMail 测试集，表中 GPT-4 胜率以数据集参考摘要为对手，温度 0 与 0.25 下 DPO 为 36%／31%，PPO 为 26%／23%。论文另说明该比较的 PPO 使用额外未标注 Reddit 提示，而 DPO 没有使用该批额外提示；正文补充这一条件，避免只看胜率误以为训练数据使用完全相同。

本次只核对上述论文实验和相关表述，没有运行模型、复现评测或重新审阅图与知乎文章。原 DPO 目标、Bradley–Terry 奖励差及配分函数消去也与论文第 4 节一致；实际训练公式与理论最优策略的差别已在正文说明。
