# 四种语音模型配图复核（2026-10-29）

本次核对 Whisper、Qwen3-ASR、Qwen3-TTS、F5-TTS 的模型指南配图登记、关联正文及对应官方资料。没有运行模型或复现论文结果，也没有逐张复核其他语音模型。

- **Whisper**：核对 [官方仓库架构图](https://github.com/openai/whisper) 与本地图片 SHA-256，均为 `2b25fb2ed94da7273e10db82f1b7383b38d1b3ee1cc09037c87ec95448de3525`；图中的编码器、解码器及任务 token 与正文的模型家族范围相符。官方仓库 main 可变化，此次只证明本次取得文件与本地文件一致。
- **Qwen3-ASR**：对照[技术报告第 2.1 节和图 2](https://arxiv.org/html/2601.21337v1#S2.F2)，左侧是独立 AuT 编码器—解码器预训练，右侧是识别架构。报告另说明编码器和语言模型之间的 projector；现有图注已提醒该模块没有在图中单独绘出，避免把官方简图当作完整模块清单。对齐器另用图 3，不混成同一个识别头。
- **Qwen3-TTS**：对照[技术报告第 3.1 节及图 3](https://arxiv.org/html/2601.15621v1#S3.F3)，现有图注标明 12Hz 路线、骨干预测第零码本、MTP 生成剩余码本以及可选条件；报告的 25Hz 路线是单级码本，不能把 12Hz 图中的 MTP 细节推广到它。
- **F5-TTS**：核对[论文 3.1 节](https://arxiv.org/html/2410.06885)和原创教学图：参考转写与待生成文本共同组成文本条件；参考音频经梅尔谱提供条件；模型多次预测速度、数值积分生成谱，再通过声码器生成波形。图中“多步积分”应理解为多次调用模型，底部说明对此已有提示；该图不表示声码器是 DiT 内部模块。Chromium 实际渲染检查了图中文字、各箭头及框的连接，未发现遮挡或断口。

这四项复核没有发现需要改动的明确错误；模型图及正文仍应随对应资料和版本变化重新检查。
