# RL 方法公式和示例复核

复核日期：2026-10-28。范围为 PPO、GRPO、DAPO、GSPO、RLOO、RLVR 六篇的核心公式、算例、方法边界；对照原始论文，不包含对训练框架实现或实验效果的验证。

- **PPO**：[PPO 原论文](https://arxiv.org/abs/1707.06347)的裁剪代理目标与正文一致。正优势、比率 1.5 对上界 1.2 的目标取 1.2；负优势 −1、比率 0.5 的目标取 −0.8，注意乘优势后比较。裁剪不是硬约束，参考策略与旧策略也不必相同。
- **GRPO**：[DeepSeekMath §4.1](https://arxiv.org/html/2402.03300)使用组均值和标准差构造优势、PPO 式 token 比率裁剪，原始方法含参考 KL；过程监督对后续步骤归一化奖励求和。用总体标准差复算 1、0、1、0 得 ±1；1、0、0、0 得约 +1.732、−0.577。其他标准差约定及零方差处理会改变结果。
- **DAPO**：[论文 §3.1–3.4、§4.1](https://arxiv.org/html/2503.14476)的上下阈值 0.2/0.28、基于正确率过滤全对全错组、组内 token 聚合、长度惩罚公式与正文一致。新增 18,432 token 对应长度惩罚 −0.5 的算例，并澄清截断损失屏蔽与长度奖励是不同操作；被屏蔽样本是否参与组内统计取决于实现顺序。
- **GSPO**：[论文 v2 §4–5](https://arxiv.org/html/2507.18071v2)以整序列比率的长度次方进行优化和裁剪；算例 sqrt(1.44×0.64)=0.96，正确。其实验设置左右阈值分别为 0.0003/0.0004，GRPO 对照为 0.2/0.27，与正文一致；该长度归一化比率不等于完整重要性采样权重。
- **RLOO**：[Back to Basics §2.3](https://arxiv.org/html/2402.14740)的留一基线与示例一致；奖励 1、0、0 对应 +1、−0.5、−0.5。留一差与组均值差的 k/(k−1) 倍关系适用于该代数形式；对无偏性仍需同题独立采样及适当基线假设。
- **RLVR**：[DeepSeek-R1 v1 §2.2](https://arxiv.org/html/2501.12948v1)是规则奖励配合 RL 的实例，而不是 RLVR 唯一定义；正文示例的 80×0.8=64 及验证漏洞说明正确。过程奖励模型是学习评分器，不能直接等同确定性验证器。

没有运行训练或重算论文实验，也未证明各种实现的裁剪、采样、奖励或掩码时序一致；上述判断仅覆盖所列论文和正文的表达。
