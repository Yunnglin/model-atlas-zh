# GPT-2 官方报告补充核验

核对日期：2026-10-27。此前原论文 PDF 读取超时，本次通过 [OpenAI 原报告](https://cdn.openai.com/better-language-models/language_models_are_unsupervised_multitask_learners.pdf)重新读取正文及表 2、表 3。并对照 [2019 年官方模型卡](https://github.com/openai/gpt-2/blob/master/model_card.md)与 [分阶段发布记录](https://openai.com/index/gpt-2-6-month-follow-up/)。这是对下列具体内容的核查，不代表论文全部表格、文章每句话或图形逐像素均已复核；未运行模型或实际评测。

- **参数与结构**：原论文表 2 列出 117M、345M、762M、1542M，以及对应层数 12、24、36、48 和隐藏维度 768、1024、1280、1600。2019 年模型卡和发布记录使用 124M、355M、774M、1.5B 的称呼，正文保留两种来源的口径，不推测差异成因。论文另说明 1,024 token 上下文与 50,257 词表。
- **WebText**：原报告第 2.1 节所述 Reddit 外链满足至少 3 karma；约 4,500 万是原始链接数量，论文实验使用截至 2017 年底、去重清洗后超过 800 万篇且约 40 GB 的早期文本版本。报告说明移除 Wikipedia 文档，不能据此认定与所有测试数据完全隔离。正文已补足链接、文档和截止时间的差异。
- **语言建模评测**：论文表 3 的最大模型 WikiText-103 困惑度 17.48、所列当时对照 18.3；One Billion Word 分别为 42.16 与 21.8。只在同一数据集内比较；报告采用可逆去分词处理，8 个数据集有 7 个取得当时所报告的领先结果。具体比较取决于模型、指标和预处理，不能直接外推到现在的榜单。
- **CoQA 与重合**：论文第 3.5 节的 55 F1 来自 CoQA 开发集，模型以文档与对话历史为条件并使用贪心解码；第 4 节指出新闻领域约 15% 的文档在 WebText 中出现、这些样本表现约高 3 F1，估计不同领域汇总收益约 0.5–1.0 F1。论文说明 CoQA 训练问答对产生于 WebText 截止日期之后；这不等于所有潜在泄漏均不存在。正文补充开发集、对话历史和重合边界。
