# Transformer、BERT、T5 定向审校

核对日期：2026-10-28。逐篇检查模型卡、正文和教学示意图中的编码器／解码器、掩码、训练任务、数据及文章引用的评测数字。审阅者此前参与过 BERT、T5 模型卡审校，本轮不构成这两篇完全独立的复核；未发现曾参与 Transformer 正文的记录。

- [Transformer 原论文](https://arxiv.org/html/1706.03762)：原模型是编码器—解码器；编码器自注意力、解码器带因果掩码的自注意力与交叉注意力职责不同。Base 为六层编码器加六层解码器，隐藏维度 512、八头；WMT14 英德训练数据约 450 万句对。Big 的 28.4 BLEU 对应最后 20 个检查点平均、束宽 4、长度惩罚 0.6。补充原论文使用标签平滑；修订教学图，以免把前馈层误认为只在整个解码器栈之后执行一次。论文评测结果不代表真实业务准确率。
- [BERT 原论文](https://arxiv.org/html/1810.04805)：双向编码器；原始 MLM 对 15% WordPiece 位置预测，其中被选位置按 80%／10%／10% 替换为掩码／随机词／原词；另有下一句预测。原始英文预训练数据是 BooksCorpus 与英文维基百科。SQuAD 1.1 的测试 F1 93.2 是七模型集成且加入 TriviaQA 微调；单个 Large 的 90.9 是开发集结果。正文及图所核查部分一致，本轮未改动。
- [T5 原论文](https://arxiv.org/html/1910.10683)：原始 T5 是双向编码器加因果解码器，使用 C4 和片段破坏目标；论文示例目标以哨兵标记分隔并用额外哨兵结束，最终实验使用 15% 破坏率与平均 3 token 的片段。论文表 14 的 CNN/Daily Mail 测试 ROUGE-2 为 Base 20.34、11B 21.55。改进图示文字：训练使用正确前缀，推理使用已生成前缀，两者均不看未来目标。

三图均为简化教学图，并非原论文架构原图。此轮没有重新训练或复现评测，也未逐项检查所有下游实验及社区参考文章。
