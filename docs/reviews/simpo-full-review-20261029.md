# SimPO 训练技术审阅

审阅日期：2026-10-29。完整通读 `src/content/docs/training/simpo.md`，对照原论文 v3、公式、示例、评测和配图；未训练模型或复现评测。

## 原理与资料

- [SimPO 论文 v3 第 2 节](https://arxiv.org/html/2405.14734v3)：用每个回答的平均 token 对数概率构造隐式奖励，在 Bradley–Terry 损失中加入目标间隔；目标无需额外参考模型，也不在损失中使用独立奖励模型。它与 DPO 使用参考模型比率、KTO 使用单条正负样本、ORPO 额外包含监督项的区别已检查。
- 论文第 3 节 Instruct 设置先对每题生成 5 条回答，用 PairRM 选择得分最高与最低作为偏好对；本次补充数据准备可使用评分器与策略训练时不需要评分器的区别，不把前者冒称人工标注。

## 例子与评测

- 教学例子 A 长 4、总对数概率 -4，B 长 2、总和 -3，平均值分别 -1 和 -1.5；取 β=1、γ=0.2 时 sigmoid 输入 0.3，负对数约 0.554。长度平均不保证彻底消除长度偏差，正向分差提升不保证所有优选样本的绝对概率上升。
- 论文表 4、表 5：Mistral-Instruct 7B 下 AlpacaEval 2 长度控制胜率 DPO 26.8、SimPO 32.1、去掉长度归一化 19.1；表 2 指该评测包含 805 题、GPT-4 Turbo 作为基准和评审。本次补充指标和比较口径，不能当事实正确率。
- 论文第 4.3 节观察增大间隔时排序准确率持续提高、生成胜率先升后降；开发集选参数和独立问题回归是实践建议。

## 社区

- 2026-10-29 主审通过已登录 Chrome 实读 [akaihaoshuai 的 Qwen3 偏好优化实践](https://zhuanlan.zhihu.com/p/1907949654739513685)，页面显示 443 赞、956 收藏；数字是当时快照。文章讨论 DPO 相对于参考模型的排序与当前模型自身排序可能不同，也提到 SimPO 的长度归一化及不使用参考模型。
- 对照[原论文第 2、4.4 节](https://arxiv.org/html/2405.14734v3)：在作者的 UltraFeedback 训练集实验中，DPO 奖励排序正确的样本对近一半在平均对数概率排序上相反；这不等于所有数据或模型都如此。正文增加单 token 教学算例说明两种排序可以不同。文章中对 SimPO 实测效果的评价属于其具体项目经验，不作为跨任务结论。

## 2026-10-29 补充

- 对照[论文第 2.3、4.4 节](https://arxiv.org/html/2405.14734v3)，补充标准目标没有显式参考模型 KL 约束；论文在特定实验观察到偏离较小，同时指出缺少显式约束时理论上可能退化。正文以偏好数据奖励措辞的例子说明需要独立检查事实与长度，不将实验观察写成普遍保证。

## 评测数字复核

- 再对照[论文表 2、4、5 和附录 B](https://arxiv.org/html/2405.14734v3)：Mistral-Instruct 7B 设置在 AlpacaEval 2 的长度控制胜率分别为 DPO 26.8%、SimPO 32.1%、SimPO 去掉长度归一化 19.1%。805 个问题以 GPT-4-Preview-1106 作为基准和评审，候选回答的采样温度为 0.5。表中的原始胜率与长度控制胜率是不同列；正文现明确基准模型并区分比较和长度控制指标。
