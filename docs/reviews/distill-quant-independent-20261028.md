# 蒸馏与量化补充复核

此前本审校者已对这两篇做过重点审校并修改部分内容；本次是补充复核，不属于独立作者的首次审查。未训练、量化模型或复现实验。

- **经典蒸馏**：[Hinton 等论文](https://arxiv.org/abs/1503.02531)核对相同温度的软分布、硬标签结合与 T² 梯度尺度调整。示例温度 1 时 softmax(2,0)≈(0.881,0.119)，温度 2 时≈(0.731,0.269)，与正文一致；T² 不是所有蒸馏方法的必选项。
- **语言模型蒸馏**：[GKD](https://arxiv.org/html/2306.13649)支持学生生成轨迹、混合数据及多种差异度量；[MiniLLM](https://arxiv.org/html/2306.08543)采用反向 KL，讨论教师混合采样与长度归一化。自然对数下 KL(p‖q)=0.2263、KL(q‖p)=0.3112。删除正文两次重复的 DeepSeek-R1 同一蒸馏案例说明，保留原有模型链接和官方来源。
- **GPTQ / AWQ**：[GPTQ](https://arxiv.org/abs/2210.17323)为近似二阶的训练后量化；[AWQ](https://arxiv.org/html/2306.00978)通过激活感知缩放保护敏感权重，不能将其部署方式简化为必须保留 1% FP16 权重。两篇正文对校准与硬件加速限制的描述一致。
- **QLoRA / QAT**：[QLoRA](https://arxiv.org/html/2305.14314)第 3 节描述冻结 4 位基座、训练低秩适配器，通常反量化为 BF16 计算；不等同于所有运算均为 4 位。对照 [PyTorch QAT](https://pytorch.org/blog/quantization-aware-training/) 检查训练中模拟量化、近似梯度和转换后的实际部署评测；正文没有把 QAT 与 QLoRA 合并为一种算法。
- **图文数值**：量化示例 scale=0.1、整数范围 −8 到 7：0.31→3→0.30、0.76→8→裁剪到 7→0.70，图和正文一致。离线蒸馏图正确将示范数据生成、学生训练和部署分开，也注明其他方法可能在线使用教师。两图 SVG XML 解析通过，未进行网页视觉验收。
