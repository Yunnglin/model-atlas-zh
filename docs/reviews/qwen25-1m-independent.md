# Qwen2.5-1M 独立审校

核查日期：2026-10-28。核查独立正文与教学图，对照官方技术报告 v1、两张模型卡及发布文章；不修改共享文件，也未加载权重或复现论文。

- [7B 模型卡](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct-1M)和 [14B 模型卡](https://huggingface.co/Qwen/Qwen2.5-14B-Instruct-1M)分别给出 7.61B/14.7B、28/48 层、28/4 与 40/8 查询/键值头；上下文 1,010,000、生成长度 8,192。两者标注 Apache 2.0；1M 使用应核对引擎和输入输出配置，不能只靠修改一般模型窗口。
- [报告 v1 第 3、4 节](https://arxiv.org/html/2501.15383v1)给出 4K→32K→64K→128K→256K 的逐阶段训练，后 3 阶段 75% 当前最长与 25% 短序列；短指令 SFT、混合长短 SFT 与不超过 8192 token、类似 DPO 的离线偏好训练。正文区分这与百万 token 训练，合成数据及 Qwen-Agent 用法未当成质量保证。
- 第 5.1 节 DCA 的块内、相邻块及远块使用不同位置处理，重映射距离以支持超出训练长度的推理；报告结合 YaRN attention scaling。DCA 不等同丢弃上下文或稀疏注意力。第 5.2 节具体说明关键 token 选择使用较连续的位置关系，最终注意力权重仍使用 DCA 位置编码；正文已补充这一容易混淆的区别。
- 表 2 为 14B 不同**预训练阶段**在 RULER 128K 上的 37.6→87.6，不是最终指令模型的通用准确率。图 6 是 7B 指令模型的找针测试：原始 MInference 超过 400K 时准确率可降至 60% 或更低，改进关键 token 选择与稀疏配置后恢复大部分表现并在该配置下约 4 倍预填充加速。正文保留任务、模型与速度范围；未将其等同最终响应加速或资源节省。
