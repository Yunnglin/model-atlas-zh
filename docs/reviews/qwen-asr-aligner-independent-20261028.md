# Qwen3-ASR 与 ForcedAligner 独立复核

范围：对照 [Qwen3-ASR 技术报告 v1](https://arxiv.org/html/2601.21337v1) 第 2–4 节和 [ForcedAligner 官方模型卡](https://huggingface.co/Qwen/Qwen3-ForcedAligner-0.6B)，检查两篇文字、官方图与自绘图的模型边界；没有自行执行识别、对齐或复现报告评测，也没有修改共享 YAML。

- 语音识别模型由 AuT、投影层、Qwen3 语言模型构成；报告给出 128 维 Fbank、8 倍下采样、12.5Hz、0.6B 版 AuT 180M 与 1.7B 版 300M；ASR 后训练使用 GSPO。Figure 2 左侧是 AuT 的编码器—解码器预训练示意，右侧是识别系统，正文已明确区分。
- 发现并修正 ASR 文章的评测口径：Fleurs 30 语言的 12.60 与 8.16 是按语言选择 CER 或 WER 后的语言宏平均，原文将其笼统称 WER 不准确。数值取自表 5，现说明中文、粤语、韩语等用 CER，英语、德语、法语等用 WER。报告表 8 的 2 秒块、5 token 回退与最后四块不固定设置与文章一致。
- 强制对齐器以已知转写与语音为输入，使用 AuT、Qwen3-0.6B 与时间预测层；80ms 是音频编码帧与时间编号粒度，不是 80ms 误差保证；报告第 3 节列最多 3750 类、300 秒、11 种语言、时间槽并行预测和因果训练。其任务不是识别或修正文字；自绘图和正文均已区分。
- MFA 伪时间标签及动态时间槽来自报告 3.3 节；表 9 人工 Raw 27.8/49.9/88.6 ms、Raw-Noisy 41.8/53.3/89.5 ms 与各自模型列对应。人工标注表中无 MFA 同集对照，不能据此断言较 MFA 更接近人工标注。
- 报告中的时间戳官方 Figure 3 和 ASR 结构 Figure 2 为论文图；单页对齐器 SVG 标注为原创简化图。原创 SVG 通过 XML 解析，图片未进行浏览器截图验收。
