- [2512 官方模型卡](https://huggingface.co/Qwen/Qwen-Image-2512)将模型定位为文生图，标注 Apache 2.0、权重页显示 20B；列出人物真实性、自然纹理、文字渲染三个改善方向。模型卡声称 AI Arena 超过 10,000 轮盲测；正文正确限定为轮数与发布方报告，不当成独立题目数，也不把榜单推广到所有任务。
- [权重文件目录](https://huggingface.co/Qwen/Qwen-Image-2512/tree/main)包含 text_encoder、transformer、vae、scheduler；[基础 Qwen-Image 论文](https://arxiv.org/abs/2508.02324)描述多模态语言模型、VAE、多模态扩散 Transformer 和流匹配。图示以文字条件、迭代生成和 VAE 解码概括，明确省略具体网络，不宣称是 2512 官方逐层图；正文将早期论文明确限定为家族背景。
- 官方模型卡示例中的多个画幅、50 步、`true_cfg_scale=4.0` 与固定种子符合正文描述，但示例的无 CUDA 分支将设备设为 CPU，后续仍写死 `torch.Generator(device="cuda")`。已在正文补充这一设备不一致，提醒根据实际设备及管线版本调整生成器；这是对示例源码的静态检查，未在 CPU 环境运行。
- 正文未将原版数据筛选、偏好训练等细节断言为 2512 的确切训练配方；模型卡公开说明不足以复现 2512 的训练数据、阶段和盲测协议。作品使用和模型许可之外的数据与依赖许可需分别核查。
- [Qwen 官方仓库](https://github.com/QwenLM/Qwen-Image)记录 2025-12-31 发布 2512 与权重；图和工单示例均为教学构造。

本次未检查所有推理框架的兼容性、不同设备的数值一致性或真实海报的 OCR 效果；官方案例展示不是独立复现实验。
