范围：初代 [DeepSeek-V3](../../src/content/docs/nlp/deepseek-v3.md) 与 [DeepSeek-R1](../../src/content/docs/nlp/deepseek-r1.md) 的后训练阶段及代表性评测；不包含后续 0324、0528 更新。此次未运行模型，也未重新实读社区文章。

- 对照 [R1 初版报告第 2.2.2 节](https://arxiv.org/html/2501.12948v1#S2.SS2.SSS2)，在正文补充 R1-Zero 的答案正确性与格式奖励；该阶段未采用神经网络结果奖励或过程奖励模型。区分之后 R1 在一般任务上的模型奖励，例子不是论文原始数据。
- 对照同报告 2.3.2–2.4 节，确认语言一致性、筛选约 60 万推理样本并混合约 20 万非推理样本、重新微调 V3-Base、对学生模型进行 SFT 的阶段；原有表述保留。
- 对照同报告 2.2.4 与 3 节，确认 Zero 训练曲线每题 16 次采样，71.0 为表中 pass@1，86.7 为 cons@64；初版标准评测默认温度 0.6、top-p 0.95、输出上限 32768，按题集通常采样 4 至 64 次。对开放式评测或外部模型的不同协议不作统一推断。
- 对照 [V3 报告第 5.1–5.2 节](https://arxiv.org/html/2412.19437v1#S5.SS2)，确认约 150 万指令样本、SFT 和 GRPO；补充可验证任务使用规则奖励、自由形式答案和开放式任务使用模型奖励的区分。奖励来源与策略更新算法是不同环节。
