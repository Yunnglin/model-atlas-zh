# Llama 3.1 专项审校

审阅日期：2026-10-29。范围为 [Llama 3.1 文本模型正文](../../src/content/docs/nlp/llama.md)；通读全文并对照官方材料，未运行模型或复现评测。

- **结构：完成。** 对照 [Llama 3 报告第 3.2 节及表 3](https://arxiv.org/html/2407.21783#S3.SS2)，核对稠密因果 Transformer、8/70/405B 的模型范围、70B 的 80 层、8192 隐藏维、64 查询头与 8 KV 头。根据 BF16 单序列假设重新计算 8192 token 的 KV 缓存约 2.5 GiB，不包括权重和运行时开销。核对 [Meta 官方配置](https://github.com/meta-llama/llama-models/blob/main/models/sku_list.py)中的 RoPE 缩放及不同版本的规格，不能据相同尺寸推断权重相同。
- **训练：完成。** 对照报告引言、第 3.1、3.4.2、3.4.3 和 4 节，核对 405B 的 15.6T 初始训练 token、六阶段 8K 至 128K 长上下文训练约 800B token，随后退火，以及多轮 SFT、拒绝采样与 DPO。合成数据、过滤和 429 案例分别标明公开流程或教学举例。对照第 4.1、4.2.2 节补充拒绝采样通常每题生成 10–30 个候选、奖励模型选择和 SFT 对目标回复计算损失而屏蔽提示；该设置属于论文具体流程。按[官方模型卡](https://github.com/meta-llama/llama-models/blob/main/models/llama3_1/MODEL_CARD.md)补出其八种支持语言及中文不在列表内，不能把输出中文等同官方支持。
- **评测：完成。** 对照报告表 2、第 5.2.1 节核对 Llama 3.1 Instruct 的 MMLU 5-shot 得分：8B 69.4、70B 83.6、405B 87.3；报告按子任务准确率宏平均、使用生成任务且该设置不采用 CoT。正文补出数字和协议，并限定不能直接推断中文业务准确率。论文的污染分析与独立业务评测建议分开；其他指标无需假称已复现。
- **配图：完成。** [70B 教学图](../../public/figures/llama-common/llama70b-backbone.svg)展示分词、80 层含 RMSNorm、因果 GQA、SwiGLU 的解码层以及下一 token 预测；箭头与正文、官方结构一致。图为项目原创简图，不表示逐层完整结构，图内注明两版权重及后训练不同；许可见 [教学图许可](../../public/figures/LICENSE-TEACHING.txt)。Chromium 打开本地正文并实际查看图片，加载成功、替代文本存在，截图中的中文与连线可读。
- **社区：完成。** 2026-10-29 主审通过已登录 Chrome 阅读包包大人的 [Llama 3.1 405B 解读](https://zhuanlan.zhihu.com/p/710779376)，当时 182 赞同、255 收藏。文章讨论稠密架构、GQA、长上下文以及奖励模型筛选与 SFT/DPO 迭代，对照报告第 3.2、3.4、4.1–4.2 节核对；其格式标记遮罩和 NLL 正则需结合对应实验范围阅读。文章中 40B/40M 表述不一致，退火数据以官方报告为准；对其他闭源模型参数的猜测不采纳。互动数为阅读时快照。
