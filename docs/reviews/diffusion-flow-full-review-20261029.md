# 扩散与流匹配方法审阅

审阅日期：2026-10-29。完整通读 `src/content/docs/training/diffusion-flow.md`，对照 DDPM、Flow Matching 与 F5-TTS 论文、数学算例及网页配图；未运行训练、生成或复现评测。

## 原理与资料

- [DDPM 原论文](https://arxiv.org/html/2006.11239)的简化目标比较模型预测噪声与实际噪声；正向加噪可在指定时间直接采样，生成时由采样过程逐步更新。正文限定这是常见的噪声预测形式，不把所有扩散实现都简化为同一损失。
- [Flow Matching 原论文第 3–4 节](https://arxiv.org/html/2210.02747)用条件路径监督向量场并构造目标边缘场；正文的线性插值是具体教学路径，而非所有方法的路径。模型根据当前状态、时间和条件学习方向，不在推理时直接拿到真实目标。
- 数据表示、网络骨干、训练目标和采样器是不同选择；DDPM 和流匹配示例中 x₀ 使用相反定义，正文已经提示。
- 对照 [Wan 报告第 4.2.2 节](https://arxiv.org/html/2503.20314)：视频或图像潜变量和高斯噪声做线性插值，时间由 logit-normal 分布抽取，模型在文本条件下预测速度，用均方误差监督。正文新增公交车教学例子，将模型实际设置与通用路径区分。

## 例子与评测

- ᾱ=0.25 时系数为 0.5 和 √0.75≈0.866；流路径在 x₀=1、x₁=5、t=0.25 时 xₜ=2、目标速度 4。Euler 速度 3.6、步长 0.25 的下一状态 2.9；本次补充 midpoint 半步 2.45、假设中点速度 3.8 后完整一步为 2.95，说明每步调用数与函数评估数不同，均为教学示意。
- [F5-TTS 附录表 5](https://arxiv.org/html/2410.06885)：同一基础模型、LibriSpeech-PC test-clean、midpoint、32 NFE，有／无 Sway Sampling 的 WER 2.41／2.84、SIM-o 0.66／0.62；Sway 使用 s=−1。该条件下对照不能泛化为所有模型或声码器收益，WER 依赖识别器。
- 图像条件遵循、声音可懂度、音色相似、主观听感和计算预算是不同评价维度；固定候选与多个随机种子属于教学建议。
