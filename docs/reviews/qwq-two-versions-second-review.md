# QwQ 预览版和正式版独立二次审校

范围：对照 Qwen 2024/2025 两次发布文章和各自官方模型卡核对模型版本、结构、训练、评测及教学图。未加载权重、运行模型或复现评测，也没有修改共享表。

- [QwQ-32B-Preview 发布](https://qwenlm.github.io/blog/qwq-32b-preview/)和[模型卡](https://huggingface.co/Qwen/QwQ-32B-Preview)确认 2024-11-28、Apache 2.0、32.5B、64 层、40 个 Q 头与 8 个 KV 头、32,768 上下文。模型卡只笼统列预训练和后训练，正文没有把后续版本的 RL 训练算法倒推到预览版；教学图的程序复核明确是外部步骤。
- 预览发布文章列 GPQA 65.2、AIME 50.0、MATH-500 90.6、LiveCodeBench 50.0；正文保留原文章没有充分明确的具体版本、采样与预算边界，未补造 pass@k。图示引用“上图”改为“阅读器中的图”，避免它被章节末插图的实际位置误导。
- [QwQ-32B 发布](https://qwenlm.github.io/blog/qwq-32b/)和[模型卡](https://huggingface.co/Qwen/QwQ-32B)确认 2025-03-06、32.5B、Qwen2.5 基础、131,072 上下文与超过 8,192 提示启用 YaRN 的建议。RL 第一阶段对数学使用准确性验证、代码使用执行服务；第二阶段采用通用奖励模型与部分规则验证。完整优化方法和数据未披露，正文未把示例或外部复现说成官方配方。
- 正式版图原来在冷启动检查点框内标“基于 Qwen2.5”，容易暗示官方详述冷启动检查点具体构建。虽模型卡说明最终模型基于 Qwen2.5，但博客未披露冷启动检查点构建过程，图中改为“具体构建未披露”；图仍是解释两阶段的原创简图。
