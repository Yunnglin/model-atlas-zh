## DAPO

- [ducati：《论文总结：DAPO: An Open-Source LLM Reinforcement Learning System at Scale》](https://zhuanlan.zhihu.com/p/1886955155527815959)，编辑于 2025-05-16；实读正文，**271 赞同、371 收藏**。正文按 Clip-Higher、动态采样、token 级聚合、超长处理逐项讲解，并将个人分析标为 thoughts，适合作中文导读。
- 与 [DAPO 论文 v2 §3–4](https://arxiv.org/html/2503.14476v2)对照：动态采样按组正确率筛除全对和全错；软长度惩罚与被截断样本的策略损失遮罩是不同处理。作者认为额外采样不会拖慢训练的说法偏绝对；论文称特定同步非流水系统中不一定妨碍效率、其实验观察到更快收敛，不能推广到所有负载。已在方法页参考链接旁说明该边界。

## GSPO
