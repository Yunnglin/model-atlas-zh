# DeepSeek-V3 与 R1 重点核查

2026-10-28 按[原始 V3 报告](https://arxiv.org/html/2412.19437v1)第 2.1、2.2、4.2–4.4 和 5 节及 [R1 报告初版](https://arxiv.org/html/2501.12948v1)第 2.2–2.4、3 节，检查两篇正文中的结构、主要训练阶段及所引用评测；同时查看对应官方模型卡的许可信息。本次核查不是全文逐句审阅。

- V3：61 层、512 维 KV 压缩和 64 维位置相关键与原报告一致。新增缓存估算按论文所述缓存两种向量、BF16、单序列、8,192 token 计算，不含权重和工作区。代码 MIT，Base/Chat 权重使用 DeepSeek 模型许可。未跑推理或测量显存。
- R1：冷启动、推理强化学习、拒绝采样、重新从 V3-Base 进行 SFT 及第二轮 RL 的顺序与论文第 2.3 节一致；报告中 60 万推理与 20 万非推理样本合计约 80 万，重新 SFT 两轮。模型卡注明原版 MIT，同时列出蒸馏模型的底座许可；本文说明了区分。
