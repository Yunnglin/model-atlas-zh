# GSPO 序列比率教学图核对

核对对象：`public/figures/training/gspo-sequence.svg` 和 GSPO 正文的图注；未执行训练或复现论文实验。

- 对照 [GSPO 原论文 v2 §4.1，式 5–7](https://arxiv.org/html/2507.18071v2)：图中每个 token 的条件概率比为当前策略除采样时旧策略，完整序列比为各位置相乘；GSPO 用完整序列比的 `1/T` 次方并进行序列级裁剪，区别于逐 token 裁剪。
- 自行计算：1.44 × 0.64 = 0.9216，平方根 = 0.96。0.96 不等于完整序列比，也不能用来证明每个 token 的比率都接近 1。
- 图中 `[0.8, 1.2]` 仅为一致阈值的教学对照，两个 token 的比率在区间外，而长度归一化序列比率在区间内；它不是论文设定。超出阈值不意味着实际概率被强行限制，裁剪是否影响目标还取决于优势符号。正文已保留此边界及论文的不同实验阈值。
- SVG 含可访问标题与文字说明，采用仓库既有训练示意图风格；以 XML 解析和数值计算验证，未做真实设备视觉验收。
