# SFT 与 LoRA 独立复核

核对日期：2026-10-28。范围包括正文公式、数值示例、术语、训练过程和共享教学图；以论文及官方文档为依据。未执行模型微调或复现基准。

- **SFT 损失和示例**：[TRL SFT Trainer](https://huggingface.co/docs/trl/sft_trainer)描述按预测 token 的负对数似然计算监督目标。两位置示例 −(ln 0.8 + ln 0.5)/2 ≈ 0.458，算术正确；正文注明位置掩码、平均方式和其他损失因实现而异。文档要求助手位置损失使用合适的对话数据与生成区间模板，对已知模型可能自动适配，正文保留了版本与模板边界。[InstructGPT](https://arxiv.org/abs/2203.02155) 是指令示范训练的具体例子。
- **术语修正**：指令微调是常见的 SFT 用途，而非 SFT 的完全同义词；PEFT 是方法类别，而 LoRA 只是其中一种。移除两篇的过宽别名并在正文解释关系，避免读者把范畴当成等价概念。
- **LoRA 公式及算例**：[LoRA 论文 §4](https://arxiv.org/html/2106.09685)使用冻结权重和低秩增量、缩放 α/r；正文矩阵尺寸相容，4096²=16,777,216，两个秩 8 矩阵合计 65,536，比例为 1/256。此比较仅针对该矩阵的可训练参数，不意味着整模型显存按此比例下降。[PEFT 官方文档](https://huggingface.co/docs/peft/main/package_reference/lora)提供不同缩放、目标模块与可训练模块选项，因此不能推断所有变体和配置完全一致。
- **QLoRA**：[QLoRA 论文](https://arxiv.org/abs/2305.14314)说明梯度经过冻结的 4-bit 量化基座传给低秩适配器，并介绍 NF4、双重量化和分页优化器。正文没有声称激活、梯度或优化器状态都为 4-bit。
- **图片修正**：共享图原将某个选中层的输入 x 标为“问题与答案前缀”，容易误以为该层直接接收原始文本；现改为“层输入 x / 上下文计算出的表示”，前后层及冻结权重、低秩分支相加和反向更新含义保持不变。这是教学流程图，不代表所有层结构或训练配置。

官方文档可能随版本变化；本次没有逐版本检查模板、损失移位、量化合并支持，也未验证数据处理和模型效果。
