# Qwen3.5 全维度审阅

审阅日期：2026-10-29。时间线 ID `qwen35`，正文 `src/content/docs/omni/qwen35-model.md`。通读正文并核对官方发布、397B-A17B 模型卡与配置、教学配图及既有知乎实读记录；没有运行模型或复现评测。

## 结构与模型卡

- [397B-A17B 官方模型卡](https://huggingface.co/Qwen/Qwen3.5-397B-A17B)及[配置](https://huggingface.co/Qwen/Qwen3.5-397B-A17B/blob/main/config.json)：语言部分 397B 总参数／17B 激活、60 层，由 15 组各 3 层 Gated DeltaNet 和 1 层 Gated Attention 组成，MoE 从 512 个路由专家选 10 个，另有共享专家；模型卡标注 Apache-2.0。
- 全注意力层每层 32 个查询头、2 个 KV 头、头维度 256；15 层、单序列 8192 token、BF16 的键值缓存估算为 `15×2×2×256×8192×2 = 251658240` 字节，即 240 MiB，不含其他状态、权重及运行时开销。
- 模型支持文字、图片和视频输入及文字输出；截图操作需外部工具。正文示例为教学构造，不把系列中其他规格一概视为同一 MoE 配置。

## 训练

- 模型卡描述早期多模态 token 融合、广泛智能体环境中的强化学习及异步训练基础设施；具体数据配比和逐阶段奖励公式没有在正文引用材料中完整披露。正文的截图监督和工具轨迹是一般教学示例，不伪称官方样本或确定配方。
- 视觉编码、语言建模、专家路由与工具执行在文章中分工区分；没有把服务端内置工具说成本地权重自带执行环境。

## 评测与应用

- 模型卡 Vision Language 表中 MMMU 为 85.0、MMMU-Pro 为 79.0；各指标和模型版本按表保留，不能作为任意界面任务成功率。对定位、状态、表达、拒绝猜测的 20 张截图数量是构造示例。
- 模型卡声明原生上下文 262144、经扩展可达 1010000 token；其超长文本说明使用 YaRN，并提醒静态 YaRN 可能影响短文本。本次补充输入／输出共享上下文预算的例子：250000 token 输入后理论余量为 12144 token，实际须扣除模板和框架开销。
- 视频抽帧、外部工具成功率、输入截断和独立任务回归均为建议；Plus 的托管工具与默认窗口不等同下载权重配置。
