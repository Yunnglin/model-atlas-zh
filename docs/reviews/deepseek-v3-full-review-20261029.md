# DeepSeek-V3 初版全维度审阅

审阅日期：2026-10-29。范围为 `src/content/docs/nlp/deepseek-v3.md` 的原始 V3-Base／Chat，不包含后续 V3-0324、V3.1 和 V3.2 的独立页面；没有运行模型或复现论文实验。

## 结构与模型卡

- [技术报告 v2](https://arxiv.org/html/2412.19437v2)第 2、3 节：主模型 671B 总参数、约 37B 激活，61 层中前 3 层为稠密 FFN，后续每层有 256 路由专家选 8 个及 1 个共享专家。论文提及 MTP 深度 1 的额外预测；[官方模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V3)说明权重额外含约 14B MTP 模块。
- MLA 缓存示例的 `(512+64)×8192×61×2 / 1024²` 为 549 MiB，限定 BF16 数值缓存和单条序列，不包含其他运行时开销。模型卡区分代码 MIT 与 Base／Chat 模型许可。

## 训练

- 报告第 2–4 节：14.8T 预训练 token、4K→32K→128K 的长度扩展、约 150 万指令数据及 R1 思路的后训练。辅助损失自由路由使用偏置影响选择，输出合并仍用原始亲和分数，同时保留小的序列级均衡损失；MTP 不是无条件并行输出。
- 报告表 2 的正式训练预训练／长上下文扩展／后训练分别为 266.4 万／11.9 万／0.5 万 H800 GPU 小时，共 278.8 万；2 美元每小时估算 557.6 万美元。正文说明不含前期研发及消融，未将估算视为总研发支出。

## 评测与应用

- 报告表 3 的 Base MMLU 5-shot EM：V2 78.4、V3 87.1；正文区分 V2 原报告的另一成绩，并说明不同规模、数据和训练不能归因于单一架构。售后案例 17/20、13/20 分别是 85%、65%，属于教学例子。
- 错例中区分输入截断、外部订单信息、模型判断和业务动作；不把生成“已退款”等同实际调用工具。
