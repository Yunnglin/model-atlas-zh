# Llama 3.2 文本模型知乎资料补查

2026-10-28 用已登录 Chrome 阅读 [刀刀宁：《Llama 3.2》](https://zhuanlan.zhihu.com/p/730549847)。页面显示编辑于 2024-09-27，查阅时 **18 赞同、17 收藏**。正文直接介绍 1B/3B 纯文本模型的结构化剪枝、蒸馏、128K 上下文与边缘部署，并对视觉分支作区分；篇幅不长，属于入门概览而非独立实验报告。互动数量只是快照，不代表技术正确性。

对照 [Meta 官方发布说明](https://ai.meta.com/blog/llama-3-2-connect-2024-vision-edge-mobile-devices/)：1B/3B 均从 Llama 3.1 8B 单次结构化剪枝；其后蒸馏使用 Llama 3.1 8B 和 70B 的 logits，两个大模型的角色并不相同。文章关于从 8B 剪枝并借蒸馏恢复性能的概要与此一致；不同设备是否能运行及速度仍需按权重精度、上下文和工具实测，不能从边缘定位推出任意手机均能支持 128K。

搜索还读到[平凡的相关回答](https://www.zhihu.com/question/668261069/answer/3691835406)，页面当时显示 43 赞同、29 收藏；其关于“从 8B 和 70B 剪枝和蒸馏”的概括容易混淆不同模型的作用，与官方明确的从 8B 剪枝、用 8B 和 70B logits 蒸馏不一致，因此没有将其作为模型页导读。
