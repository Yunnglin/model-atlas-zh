# 视觉模型专题复核（2026-10-27）

本轮对照了 ViT、Swin、SAM、LLaVA 原论文及其官方代码说明，重点检查输入输出、原版架构、训练分阶段与代表性评测，范围不等于逐句事实核验或运行模型。

- ViT：核对图块数和分类 token 的教学图；原论文表 2 与表 5 的 ImageNet 分数使用不同设置，正文补充分辨率和参数平均的区别。88.55% 与 94.55% 均对应表 2 的 JFT 预训练 ViT-H/14，并非从零训练小模型的成绩。[ViT 原论文](https://arxiv.org/abs/2010.11929)
- Swin：核对常规窗口、移位窗口及 patch merging 教学图；补明 87.3% 是 ImageNet-22K 预训练、384 输入的 Swin-L，58.7／51.1 是配 HTC++ 的多尺度测试结果。[Swin 原论文](https://arxiv.org/abs/2103.14030)
- SAM：对照官方架构图和论文中对提示歧义的解释，补充三个候选只对最小掩码损失反向传播以及质量排序与真实 IoU 的区别；本文描述原始图像 SAM，不扩张为 SAM 2 的视频能力。[SAM 原论文](https://arxiv.org/abs/2304.02643)
- LLaVA：检查教学图的视觉编码器、线性投影与语言模型路径，核对初版两阶段训练、ScienceQA 的 LLaVA 单模型和 GPT-4 裁决组合、LLaVA-Bench 相对分数；图文例子未实际运行。[LLaVA 原论文](https://arxiv.org/abs/2304.08485)

知乎方面，协作复核 [德怀特：ViT 解析](https://zhuanlan.zhihu.com/p/445122996)，2026-10-27 页面显示 1420 赞同、2139 收藏。结构算例和数据规模的组织可参考；位置编码和数据规模的泛化结论需限定条件，事实以原论文为准。SAM、Swin 和 LLaVA 的知乎文章与互动量已补充核验，详见 [视觉社区参考](visual-community.md)。
