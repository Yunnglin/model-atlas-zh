- GLM-4-9B：对照[家族报告第 1 节和表 1](https://arxiv.org/html/2406.12793)、[Base 模型卡](https://huggingface.co/zai-org/glm-4-9b)、[Chat 模型卡](https://huggingface.co/zai-org/glm-4-9b-chat)与 [Chat 配置](https://huggingface.co/zai-org/glm-4-9b-chat/raw/main/config.json)。核对 40 层、4096 宽、32 个查询头、2 组 KV、每头 128 维，BF16 8192 token 的理论 KV 缓存 320 MiB；Base 为 8K，Chat 配置为 131072，并有实验性 1M Chat。报告称预训练约 10 万亿多语言 token，后训练使用 GLM-4（0520）流程与数据，已补正文。Base 模型卡 MMLU 74.7 / GSM8K 84.0；Chat 模型卡为 72.4 / 79.6，已在正文标明两个权重口径。后训练完整数据和训练超参数未在本次逐项核实。
