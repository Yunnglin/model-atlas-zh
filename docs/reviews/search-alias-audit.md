# 模型搜索别名抽查

核对日期：2026-10-28。模型的搜索别名应指向同一模型或家族名称，不能将其他代际直接作为该模型的别名。

- GPT-2 页面原将 GPT-3、GPT-4 列为别名。它们是后续不同模型，不是 GPT-2 的其他名称；已移除这两个别名并增加搜索回归检查。GPT 系列的历代比较仍在正文介绍。
- 原始 GLM 模型卡中 Base／Large 的训练序列长度、短片段与长片段遮盖设置，已对照 [GLM 论文](https://arxiv.org/abs/2103.10360)抽查；该检查不代表整个系列或全文已逐项核验。

此记录只覆盖上述页面和问题，其他模型的别名仍需要按型号检查。
