# Qwen-Image-2.1 提示词与评测补充核查

2026-10-29 对照 [Qwen-Image-PE 研究报告 v1 表 1 与第 3.1 节](https://arxiv.org/html/2610.33472v1)：固定 Qwen-Image-2.1 图像生成模型，在 Qwen-Image-Bench 上直接使用原始请求的综合分为 54.36；以 Qwen-Image-PE-9B 增强提示后为 60.28。报告列出 2K 分辨率、同一请求匹配采样种子，评测使用 Q-Judger；评估请求不与增强器 SFT/RL 训练请求重叠。模型和增强器都属于 Qwen 团队；这是提示处理与图像生成组合的团队报告，不能当作纯图像模型更换后产生的分数，也不等同人类满意率。

正文增加咖啡杯例子、原始与增强提示的保存和人工检查建议。此前博客图中的 60.28 没有足够的直接文字协议，未把其作为“裸模型分数”；本次以可以直接读取的研究表格及协议为准。未运行模型或复现基准，也未重读知乎页面。
