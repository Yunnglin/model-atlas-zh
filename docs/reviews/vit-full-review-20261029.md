# ViT 全维度审阅

审阅日期：2026-10-29。通读 `src/content/docs/cv/vit.md`，对照论文、官方资料、教学图与既有知乎实读；未训练模型或复现评测。

## 结构与模型卡

- [ViT 论文第 3–4 节和表 1](https://arxiv.org/html/2010.11929)：B／L／H 为 12／24／32 层、768／1024／1280 宽度、约 86M／307M／632M 参数；图片切块、线性投影、分类 token 和可学习位置嵌入进入 Transformer 编码器，微调不同分辨率时对图块位置嵌入做二维插值。
- 224×224 图像以 16×16 分块得到 196 块，RGB 每块 768 数值，增加分类 token 后 197 个位置；分类头及视觉先验的解释已核对。

## 训练

- 论文比较 ImageNet、ImageNet-21k、JFT-300M 的监督预训练及下游微调；预训练 MLP 分类头、微调线性头，另有初步自监督掩码实验。商品分类、冻结与全量微调是教学建议。

## 评测与应用

- 论文表 5 中 ViT-B/16 在 384 分辨率微调、分别用 ImageNet／ImageNet-21k／JFT 预训练时的 ImageNet top-1 为 77.91／83.97／84.15；表 2 的 JFT 预训练 ViT-H/14 为 ImageNet 88.55、CIFAR-100 94.55，ImageNet 使用 518 分辨率和参数平均。表 5 同模型 ImageNet 为 88.04、384 分辨率，评测设置不同。
- 本次补充 197²=38809、785²=616225，约 15.9 倍的位置配对数量；这是矩阵元素数，不等于整体耗时。商品分类、90/100 top-1、背景干扰及独立回归均为教学构造。
