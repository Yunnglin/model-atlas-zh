- **结构与模型卡**：对照 [官方模型卡](https://huggingface.co/Qwen/Qwen3.6-27B)核对 64 层、16 组 3 层 Gated DeltaNet 加 1 层 Gated Attention、24 个查询头、4 个 KV 头和每头 256 维，以及原生 262,144 token 和 Apache-2.0 许可。按 16 层全注意力、单条 8192 token 序列、BF16 计算，KV 缓存估算 512 MiB；不包括模型权重、线性状态和工作区。
- **训练**：模型卡注明 MTP 多步训练、预训练和后训练方向，但未披露完整语料比例或奖励配方；正文不补造训练细节。推测解码示例依赖框架配置，不能仅从 MTP 推出固定吞吐收益。正文的仓库适配与训练数据拆分均为教学方案，非官方实验。
