# Qwen-VL 视觉分支重点审校

核对日期：2026-10-27。对照以下各版原论文，检查四篇正文的模型卡、主要结构、训练阶段和部分评测设定；阅读四张教学 SVG 的文字、连接和数字，不等于逐像素或所有事实逐句核验。业务例子均为教学构造，未运行模型或评测。

- **初代 Qwen-VL**：对照[论文第 2–3 节及附录](https://arxiv.org/html/2308.12966v3)，核对 ViT-bigG 初始化、448 像素输入与 256 个查询、三阶段冻结策略及坐标范围。补充 Qwen-7B 初始化是中间检查点，区分 50 亿原始图文对、清洗后 14 亿条和约 15 亿次训练样本读取。教学图不展开训练阶段。
- **Qwen2-VL**：对照[技术报告](https://arxiv.org/html/2409.12191v2)第 2–3 节，核对动态分辨率、2×2 特征合并、M-RoPE、训练用 2 fps 采样和 7B 消融表；补充 DFN ViT 初始化与约 6000 亿预训练 token 的口径。图省略视频管块和编码器内部。
- **Qwen2.5-VL**：对照[技术报告](https://arxiv.org/html/2502.13923v1)表 1–2、训练与后训练章节，核对 14 像素 patch、四块合并、窗口和全注意力、三阶段及 SFT/DPO 的冻结策略。补充训练 token 和长度，指出视觉编码器的单独初始化；图中 840×560 算例的 2400 个 patch 与 600 个合并 token 经算术复核，仅代表静态图教学路径。
- **Qwen3-VL**：对照[技术报告](https://arxiv.org/html/2511.21631v1)第 2、3、5 节核对 DeepStack、时间戳、四阶段、15B-A2B 消融和官方长视频评测。补充 235B-A22B-Instruct 视频评测的帧数、token 上限、裁判和对手帧数不一致的限制；不可当成业务实测。教学图省略各融合器和网络细节。

知乎：[Qwen2.5-VL 源码深读](zhihu-reading.md)已记录正文及互动量；其他三代的知乎参考已补查，见 [视觉社区资料核查](qwen-vision-community.md)。不同视觉模型的版本与运行预算应单独对照，不能把高热度社区解读作为技术事实的最终依据。
