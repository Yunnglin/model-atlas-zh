# SAM 初代文章专项审校（2026-10-29）

审校对象：`src/content/docs/cv/sam.md`，仅覆盖 2023 年初代 SAM，不包含 SAM 2。本文记录本次实际核查范围，不替代全库审校台账。

## 模型与结构

对照 [原论文第 4 节及附录 A](https://arxiv.org/html/2304.02643) 和[官方模型构建代码](https://github.com/facebookresearch/segment-anything/blob/main/segment_anything/build_sam.py)，核对 ViT 图像编码器、提示编码器、掩码解码器、B/L/H 配置，以及 1024 输入、64×64 图像特征。密集掩码提示与图像特征逐元素相加；图中的文字提示不等同于公开图像预测接口提供自然语言分割。

## 数据与训练

对照论文第 5 节与附录 A，核对数据引擎的辅助、半自动、自动三个阶段，以及正负点和边界框提示、上一轮掩码、三个歧义候选及最小损失候选的训练处理。SA-1B 的掩码存在模型生成与筛选环节，不能说全部为人工精细标注。

## 评测与实践

对照论文第 7.1 节与图 9：23 个数据集使用真值掩码中心点，按平均 IoU 比较；SAM 在 16 个数据集高于 RITM。已补充结果的提示条件，并解释预测质量排序和用真值挑选的 oracle 结果的区别。原文对点击次数、边界质量和业务错误归因的建议是应用方法，不宣称已运行实测。

本地文章 `/cv/sam/` 使用官方结构图 `public/figures/sam/model_diagram.png`，浏览器实测图片加载成功（2412 × 514），图示包括 image encoder、prompt encoder、mask decoder 与候选掩码。正文说明了图中 text 的接口边界。资源来源和许可证见 `docs/assets.md`；本次没有运行模型或量化移动端图片可读性。
