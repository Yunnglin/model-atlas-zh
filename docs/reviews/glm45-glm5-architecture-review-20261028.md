# GLM-4.5 与 GLM-5 结构和训练核查

核查日期：2026-10-28。本次对照 [GLM-4.5 技术报告](https://arxiv.org/html/2508.06471)第 2、3、4 节，以及 [GLM-5 技术报告](https://arxiv.org/html/2602.15763)第 2 节、附录表 10 和[官方配置](https://huggingface.co/zai-org/GLM-5/raw/main/config.json)，并核对两张教学图的信息流。

- GLM-4.5 报告表 1 给出 3 个稠密层、89 个 MoE 层、160 个路由专家、每 token 选 8 个及 1 个共享专家；96 个查询头共享 8 组键值头。新增教学图展示语言主干，并保留现有的专家后训练图；后者补画工具结果回流箭头。
- GLM-5 报告附录表 10 和官方配置对应 3 个稠密层、75 个 MoE 层，以及 1 个 MTP 层。报告叙述中的总层数和配置字段使用不同口径，正文按附录与配置分别表述。报告第 2.1.1 节给出 DSA 预热 1,000 步及 20B token 稀疏适配。
- GLM-4.5 的 SWE-bench Verified 64.2% 对应报告中的 OpenHands 0.34.0、100 次迭代上限、128K 历史截断、温度 0.6 与 top-p 1.0。GLM-5 的 77.8% 对应报告的 OpenHands 与针对模型的提示。
- 使用 Chromium 分别渲染检查了 GLM-4.5 新增主干图及修改后的后训练图，确认连线和文字可见；SVG 通过 XML 解析。图为自制教学简图，不等同官方原图。
