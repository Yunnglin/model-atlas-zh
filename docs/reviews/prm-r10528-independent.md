# Qwen2.5-Math-PRM 与 DeepSeek-R1-0528 独立审校

核对日期：2026-10-28。范围为两篇正文、模型卡、教学图及其在现有图表登记中的说明；未修改共享 YAML，也未运行权重或复现论文实验。

## Qwen2.5-Math-PRM

- [官方论文 v1 第 4.1 节](https://arxiv.org/html/2501.07301v1)说明 7B、72B 分别从对应数学指令模型初始化；每步 8 次续写，全部失败才标负，由 Qwen2.5-72B-Instruct 逐步判断，滤去蒙特卡洛标签与模型判断不一致的实例，在步骤结尾使用交叉熵训练。正文此前“保留一致的标签”容易误解为单标签筛选，已改为论文的实例筛除口径。
- [官方 7B 模型卡](https://huggingface.co/Qwen/Qwen2.5-Math-PRM-7B)和 [72B 模型卡](https://huggingface.co/Qwen/Qwen2.5-Math-PRM-72B)列出公开权重和 Qwen 许可；7B 示例明确 `<extra_0>` 和 softmax 正类取分，且对数学指令模型生成结果建议按双换行分步。没有将类别分数视为保证校准的概率。
- 论文第 4.2 节及表 6 确认 Best-of-8 使用 7B 指令生成器、步骤分数乘积，七个数据集均值多数投票 66.2、PRM 7B 67.6、pass@8 上界 74.7。补明均值是七项任务成绩平均，不是按题数加权。ProcessBench 的首错定位与 Best-of-8 的最终答案选择是不同任务。
- `public/figures/qwen25-math-prm/overview.svg` 是生成、评分与选择的原创简化流程，不冒充官方架构图；说明步骤分数并非证明。图中没有暗示训练数据由人工全面标注。

## DeepSeek-R1-0528

- [官方配置](https://huggingface.co/deepseek-ai/DeepSeek-R1-0528/blob/main/config.json)列出 61 层、7168 隐藏维度、前 3 层稠密前馈、256 路由专家加 1 个共享专家、每 token 选择 8 个、128 注意力头和 163840 位置设置；正文注明该配置值不自动等于实际服务可用窗口。
- [官方模型卡](https://huggingface.co/deepseek-ai/DeepSeek-R1-0528)标注 MIT、介绍训练计算与算法优化，但未提供完整训练配方。对需采样的基准报告温度 0.6、top-p 0.95、每题 16 次估计 pass@1，最大生成长度 64K；AIME 2025 为 70.0 → 87.5，平均思考 token 为约 12K → 23K，SimpleQA 30.1 → 27.8。正文不把 pass@1 当 pass@16，不推断长输出是唯一原因。
- 同一模型卡明确蒸馏版从 Qwen3-8B **Base** 后训练；已在正文补充 Base，以免与 Instruct 混淆。原版 R1 论文只是家族背景，不能视作 0528 的完整方法证明。
- `public/figures/deepseek-r1-0528/overview.svg` 为原创生成与应用外部校验流程，不是论文网络结构图。原图的“外部验证判断是否可靠”可能暗示验证器可保证结论正确，已改为“辅助检查”，并明确程序测试也不能保证回答完全正确。
