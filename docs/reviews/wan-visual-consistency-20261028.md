# Wan2.1 与 Wan2.2 图文一致性自查

本次核查由两篇正文和图的原作者完成，是作者自查，不是独立审阅。检查正文、原创 SVG 和官方论文/仓库/模型卡，未运行模型、复现评测或进行网页渲染验收。

- **Wan2.1 结构与图**：[Wan 官方论文](https://arxiv.org/abs/2503.20314)第 4 节：umT5、文生视频的文本条件和噪声、DiT 潜变量生成以及 VAE 解码与图相符；图明确区分文生视频推理与训练时真实视频编码，没有画成推理必须提供真实视频。论文 VAE 时间维按首帧加后续 4 帧压缩、空间各 8 倍，文中 81 帧到 21 时间位置正确；图未画具体尺寸，不存在数字冲突。
- **Wan2.1 评测**：论文第 4.7 节称 Wan-Bench 每候选模型 1035 个样本、人评超过 700 个任务和超过 20 人；表 4 的 1.3B 总分 83.96%、14B 总分 86.22%、视觉质量 86.67%、语义 84.44% 与正文一致。这些是公开评测结果，不代表本文复现或当前排名。
- **Wan2.2 模型及图**：[官方仓库](https://github.com/Wan-Video/Wan2.2)说明高噪与低噪专家按去噪阶段处理，两个约 14B 专家合计约 27B、每步约 14B；TI2V-5B 是独立稠密模型。图正确展示相同潜在状态接力，而非拼接两段成片；参数约数只在正文出现，未产生图文数字冲突。
- **Wan2.2 压缩**：官方记载 VAE 时空压缩 4×16×16，再经 patchification 为 4×32×32。原正文误将包含时间维的 4×32×32 称为“空间下采样”，已改为“时空下采样”，并分别标出时间 4 倍、两个空间维各 32 倍；图没有数字标注，无对应冲突。
- **Wan2.2 评测**：官方仓库 Wan-Bench 2.0 和验证损失图只用于说明官方实验，正文未将 2.1 的 VBench 分数归到 2.2，未自行推测分数。仓库引用的 arXiv 2503.20314 是较早 Wan 报告，不把它称为 2.2 专属报告。
- 两份 SVG 均通过 XML 解析；同步修正文中的一处重复转折。尚未在真实设备运行视频生成或核实原始评测配置。
