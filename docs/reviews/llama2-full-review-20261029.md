# Llama 2 全维度审阅

审阅日期：2026-10-29。时间线 ID `llama2`，通读 `src/content/docs/nlp/llama2-model.md`，对照论文、官方模型卡、配图与既有知乎实读记录；未运行模型或复现评测。

## 结构与模型卡

- [论文第 2 节与表 1](https://arxiv.org/html/2307.09288)：公开 7B、13B、70B 基础及 Chat 版本，另报告未发布的 34B 实验；原始上下文长度 4096，decoder-only、RMSNorm、SwiGLU 和 RoPE。70B 与实验 34B 使用 GQA，7B、13B 不使用，不能概括为所有型号均用 GQA。
- [官方模型卡](https://huggingface.co/meta-llama/Llama-2-7b-hf)标注 Llama 2 Community License；允许符合条件的商业使用且存在额外要求。GQA、窗口和 KV 缓存解释是示意，并未声称固定速度收益。

## 训练

- 论文第 2 节：使用公开来源混合预训练约 2 万亿 token；第 3 节：SFT 后收集偏好、训练奖励模型，以拒绝采样和 PPO 迭代。表 6 的 Meta 人类偏好比较为 1,418,091 条，和 27,540 条 SFT 标注不是同一计数。
- 论文 3.2.2 说明分别训练有帮助性与安全奖励模型；正文补充两者职责及误拒绝例子。3.2.3 描述早期只用拒绝采样，后结合 PPO；拒绝采样使用 70B，大模型结果用于训练较小模型。
- 论文 3.3 的 Ghost Attention 是多轮指令数据构造方法，不是新增注意力层。会议摘要场景为教学构造。

## 评测与应用

- 报告表 3、4 和附录表 19、21：70B Base 的 MMLU 为 68.9，5-shot；HumanEval 29.9，0-shot，pass@1 温度 0.1、top-p 0.95。不能把预训练模型分数等同 Chat 对话质量，亦不能跨协议比较。
- 论文分析污染及人工偏好、安全测试的边界；会议摘要真实性、引用、拒绝行为和独立回归均为教学设计，非实跑结果。
