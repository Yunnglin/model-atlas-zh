# Qwen3.8-LiveTranslate 社区与官方资料核查

核查日期：2026-10-28。通过已登录的知乎页面搜索并阅读[千问大模型发布介绍](https://zhuanlan.zhihu.com/p/2084615937060234923)，页面显示 7 赞同、8 收藏。文章来自模型团队，是相关方资料，不是独立复现实验；互动数是查看时快照。

中文介绍与 [Qwen 官方发布](https://qwen.ai/blog?id=qwen3.8-livetranslate)均描述 Thinker–Talker、音频／文本交错、多人说话人区分、60 种输入音频／输出文字语言与 29 种输出语音语言。官方报道 LAAL 由上一代 2.8 秒降为 2.3 秒，属于其评测定义下的平均滞后，不等同首包或真实端到端延迟。FLEURS 的 70 个语向和 Omnilingua-MSpeaker 的 14 个语向是不同评测口径。

本次未确认官方可下载权重或完整训练数据和超参数，不把可调用 API 描述为开源权重。教程中的会议内容、数字和评测方案为教学构造；未实际调用服务或复现评测。
