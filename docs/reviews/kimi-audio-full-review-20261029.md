# Kimi-Audio 专项审校

审校日期：2026-10-29。完整通读 [Kimi-Audio 正文](../../src/content/docs/audio/kimi-audio-model.md)，以原始 7B 公开模型与论文 v1 为范围；未运行模型、训练或复现评测。天气问答和分块朗读为教学构造。

- **结构**：对照[技术报告 v1 第 2 节](https://arxiv.org/html/2504.18425v1)核对 12.5 Hz 离散 token、Whisper 连续特征从 50 Hz 下采样、逐位置相加、共享层及文本/音频头初始化、流匹配和声码器。后续 4 token 前瞻与帧率换算仅是粗略序列时长，不当成实测首包延迟。补充分块朗读类比及依赖历史频谱与语义码的说明。
- **训练**：报告第 3、4 节核对约 1300 万小时原始音频、原始/增强随机各半、英语与普通话转写、585B 音频和 585B 文本 token、Whisper 前 20% token 阶段冻结、30 万小时 SFT 及指令数量。补充音频解码器约 100 万小时预训练、0.5–3 秒分块微调和高质量单说话人微调，不把系统实用案例写成官方训练数据。
- **评测**：报告表 4、5 核对 LibriSpeech test-clean/test-other WER 1.28/2.42、Qwen2-Audio-base 对照 1.74/4.04 和 MMAU 各项分数，区分[另一份报告](https://arxiv.org/abs/2407.10759v1)数据及不同评测配置；分别解释 WER、背景声音理解和生成语音质量，业务例子不是实测。权重许可及使用方式对照[官方模型卡](https://huggingface.co/moonshotai/Kimi-Audio-7B-Instruct)。
- **配图**：对照[图片登记](../../src/content/data/figures.yaml)及[原创教学图](../../public/figures/kimi-audio/overview.svg)，双路径特征、对齐相加、共享层、两种输出和声码器流向与论文图 2 的简化范围一致，来源、非官方简图与 CC BY 4.0 已注明。Chromium 本地页面滚动加载并解码图像成功（宽 1060）、替代文本存在；截图检查中文与箭头。
- **社区**：2026-10-29 主审通过已登录 Chrome 实读模型之声的 [Kimi-Audio 解读](https://zhuanlan.zhihu.com/p/1994899292989698600)，当时 6 赞、16 收藏。文章介绍 Whisper 连续特征与 12.5 Hz 离散语义 token、文本和音频双头、流匹配解码以及预训练和微调；对照论文 v1 第 2、4 节，基本流程一致。文章的全双工表述不能仅凭分块解码认定：可边听边说、打断和延迟需对完整系统单独验证。互动量是阅读时快照。
- **训练例子补核**：对照论文 v1 表 3 与第 4.1.2–4.1.3 节，正文新增映射和交错任务的两段录音教学例子。ASR 映射在给定音频后只对对应文本计算损失；交错任务以一段输入预测相邻另一段，输出类型取决于任务。例子不是实验样本，也不将特定任务推广到所有序列。
