# GLM-5 审阅

审阅日期：2026-10-29。时间线 ID `glm5`，通读 `src/content/docs/nlp/glm5-model.md`，对照技术报告 v1、模型卡、配置、配图及既有知乎阅读记录；未运行模型或复现评测。

## 结构与模型卡

- [报告 v1 表 10](https://arxiv.org/html/2602.15763v1#A1.T10)：744B 总参数、40B 激活口径包括 MTP、不含词嵌入和输出层；3 个稠密层、75 个 MoE 层及 1 个 MTP 层。[模型配置](https://huggingface.co/zai-org/GLM-5/blob/main/config.json)标明 78 个主干层、256 个路由专家选 8、1 个共享专家、索引器 top-k 2048 和 202752 最大位置。模型卡标注 MIT。
- DSA 选择历史位置，MoE 选择专家，MLA 改变注意力和缓存表示；对于 100000 个 token，2048/100000=2.048%，不把这个比例称为整体加速比。Webhook 案例为构造案例，工具由外部执行器运行。

## 训练

- 报告第 2.1.1、2.3 节：GLM-5 的 DSA 预热 1000 步后以 20B token 稀疏适配；中期依次在 32K、128K、200K 最大长度下训练 1T、500B、50B token。本次补充长上下文训练的阶段及抽样含义。
- 报告第 3.1–3.5 和 4.1 节：多任务 SFT 后依次进行推理、智能体和通用 RL，最终跨阶段 on-policy 蒸馏以减轻能力回退；异步轨迹保留生成 token 并排除环境输出的训练损失，定期同步策略、处理过旧样本。本次补充后训练阶段及需要独立回归；对照报告 4.1.2 节补充 TITO 的工具轨迹例子，区分原始 token 记录与奖励算法。

## 评测与应用

- 报告表 7 与附录 B.2：SWE-bench Verified 77.8% 使用 OpenHands、针对 GLM-5 的提示，温度 0.7、top-p 0.95、生成上限 16384 token 和 200K 上下文；本次补充公开设置，不把系统结果当作裸模型或任意项目的成功率。
- 报告表 3 的 DSA 与 MLA 长上下文对照是特定测试；环境隔离、Webhook 错例与业务回归为教学方案，未实跑。
