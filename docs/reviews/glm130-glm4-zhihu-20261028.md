# GLM-130B 与 GLM-4-9B 知乎资料复核

2026-10-28 使用已登录的 Chrome 阅读两篇文章并查看页面互动数；数字是当天快照。知乎文章用于补充解释和案例，不替代论文与模型卡。

- [【报告笔记】大规模语言模型系列技术：以 GLM-130B 为例](https://zhuanlan.zhihu.com/p/636329188)，作者 xyiz，223 赞同、785 收藏。笔记根据 GLM 团队报告整理，讲解了双向上下文、自回归填空和稳定训练。对照 [GLM-130B 论文第 2.2 节](https://arxiv.org/html/2210.02414)：自监督填空使用 30% 的序列进行短片段遮盖，遮盖内容合计为输入的 15%；另 70% 序列使用前缀加后续生成的方式。这里比例针对不同对象，正文已明确，避免误解为每个序列都遮掉 30%。论文另指出多任务指令预训练占总训练 token 的 5%，不能将其和上述序列比例混成同一分母。
- [最新 qwen2-7b 和 glm4-9b 本地部署和速测报告](https://zhuanlan.zhihu.com/p/702475296)，作者混沌随想，75 赞同、171 收藏。文章实际加载 `glm-4-9b-chat` 和 `Qwen2-7B-Instruct`，给出 BF16、RTX 4090 等运行条件，并展示翻译、代码和敏感信息识别的少量案例；其主观比较不能代表一般性能排名。对照 [GLM-4-9B-Chat 官方模型卡](https://huggingface.co/zai-org/glm-4-9b-chat)，两者都用 Chat 权重及相应对话模板；技术报告的 Base 成绩不能直接当成该文章使用的 Chat 成绩。正文增加以相同任务比较、记录模型版本和输入设置的实践引导。

这次没有运行文章代码或复现评测，也没有把点赞、收藏作为正确性的证明；GLM-4 后训练细节与两篇文章的全部说法不在本次逐项核对范围。
