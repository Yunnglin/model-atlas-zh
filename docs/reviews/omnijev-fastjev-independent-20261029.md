# OmniJev v1.1 的第三方推理研究复核（2026-10-29）

本次阅读第三方 [FastJEV 论文 v1](https://arxiv.org/html/2610.11379v1)。论文参考文献明确指向 `tinnel123666888/OmniJev`，实验使用 v1.1 的 0.8B、2B 和 4B，因此不是 Jev-Omni 或 `OmniJev/OneJev` 等同名项目。研究者对已发布模型的候选计算做不需额外训练的优化，不是 OmniJev 官方新版本，也不是本次实际运行或复现。

论文 3.1、3.2 节描述共享视觉和文本前缀，候选各有后缀分支；研究进一步共享相同候选前缀，对分支层做基于少量无标签校准输入的敏感度剪枝，保留完整上下文、全部候选和决策头。正文据此增加可读的保存按钮示例，区分共同上下文与共同候选前缀。

论文表 1 和第 4.2 节核对 4B 的 32 层候选路径跳过 14 层（43.75%），六集分数相对原版的平均保留为 93.66%；其中论文重建的 LIBERO-10 离线问答为 65.23% 对 50.20%。论文测出的六集几何平均加速比为 0.953×，不能将减少层数直接称为加速。评价是论文的固定数据、模型与一张 L20 GPU 的测量；平均保留是各数据集准确率比的非加权平均，不是总准确率，重建 LIBERO 不是在线机器人成功率。
