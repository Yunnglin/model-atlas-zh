# Llama 3 初版页面核验

核验日期：2026-10-28。范围为 2024-04 发布的 8B/70B 基础版与指令版，不包括模型运行或论文实验复现。

- [Meta 2024-04-18 发布介绍](https://ai.meta.com/blog/meta-llama-3/)：初版 8B、70B 均用 GQA、128K 词表、8192 token 序列；预训练超过 15T token，非英语内容超过 5%；指令后训练介绍 SFT、拒绝采样、PPO、DPO。不要把后来的 405B 或 128K 窗口倒灌到初版。
- [8B 官方模型卡](https://huggingface.co/meta-llama/Meta-Llama-3-8B)：初版文本输入和文本/代码输出，8K 上下文，面向英语使用，开放权重为 Llama 3 Community License。其许可有使用政策、再分发和特定规模服务的额外条件，不是 Apache。
- 同模型卡分别列基础与指令版评测：MMLU 5-shot 基础 8B/70B 为 66.6/79.5、指令版为 68.4/82.0；HumanEval 0-shot 指令版为 62.2/81.7。成绩属于特定评测和版本，不等于实际任务通过率。
- 已登录知乎阅读[真真锋《llama1-3 模型结构详解》](https://zhuanlan.zhihu.com/p/625775403)的 Llama 3 部分；页面显示编辑 2025-07-04，查阅时 172 赞同、290 收藏。该文说明 128K 词表、GQA、初版 8K 及 3.1 版本区别；具体事实以 Meta 模型卡为准。互动数会变化。
