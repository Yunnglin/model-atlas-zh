# LoRA 与 SFT 重点复核

日期：2026-10-28。核对了两篇正文的损失和参数例子、训练配置说明，以及共用教学图；不是全部工具版本和应用数据的实测。

- [LoRA 原论文第 4.1 节](https://arxiv.org/html/2106.09685)采用随机初始化 A、零初始化 B 与 α/r 缩放。新增的第一步梯度解释依据其 $BAx$ 计算：B 为零时损失对 A 的梯度为零，B 的梯度是否非零取决于输入和上游梯度；优化器的权重衰减等作用另计。矩阵与层数的参数量为教学算例。
- [TRL SFT Trainer 文档](https://huggingface.co/docs/trl/sft_trainer)区分对话助手消息损失和 prompt-completion 数据的完成部分损失；`assistant_only_loss` 依赖能标记助手生成区域的模板，某些已知模型的模板会由训练器适配。正文对工具消息、截断与标签位置的检查属于建议。
- [InstructGPT 论文第 3 节](https://arxiv.org/html/2203.02155)给出约 1.3 万条 SFT 训练提示及分别用于奖励模型、PPO 的数据。本次补充说明 SFT 与后续阶段的数据用途，并未将后训练模型的偏好成绩归功于 SFT 单阶段。
- 共用图 `public/figures/training/lora-sft.svg` 已用 Chromium 渲染查看；冻结支路、低秩支路、损失与仅更新适配器的箭头均可见。图表达的是只训练 LoRA 的示例，未画出其他可选训练参数。

本轮没有重新阅读正文已有知乎文章，没有运行模型、训练或业务评测，也没有核对所有框架和模型版本。原文链接可供读者继续查阅。
