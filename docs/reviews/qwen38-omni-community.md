# Qwen3.8-Omni-Flash 来源与知乎核查

核查日期：2026-10-28。已阅读[千问大模型的知乎发布文章](https://zhuanlan.zhihu.com/p/2084035289178231553)，页面显示 **30 赞同、23 收藏**，发布日期为 2026-09-18。该文属于模型团队的发布介绍，适合查发布、输入输出和应用场景；不是独立评测。其产品介绍与研究报告对平均提升的统计口径不同，不将聚合数字当作无条件通用收益。

- 依据[技术报告 v1](https://arxiv.org/html/2609.25611v1)第 2–4 节核对 Thinker 混合骨干、AuT、Spatial AuT、QSA 和四阶段预训练；报告所写约 2.5 万亿总量与列出的近似分项相加约 2.6 万亿不完全一致，正文保留此限制。
- 报告表 5 和表 7–9 用于核对 WorldSense、智能体与静态理解的不同设置、token 统计以及 Realtime 首包指标。首包从输入提交后开始，排除连接建立、上传及播放；不能说是端到端体验。知乎发布中的 OmniVideoBench 数字与报告表 8 同口径。
- [标准服务官方模型页](https://www.qwencloud.com/models/qwen3.8-omni-flash)列出文字、图片、音频和视频输入及文字输出。报告第 7 节另外讨论 Realtime 语音输出；不能将后者直接套进标准接口。
- 技术报告及服务说明未给出此 Omni 型号的总参数和激活参数。本次未确认官方开放模型权重；Qwen-MM-Plugins 与 Qwen-Live-Harness 开源不能证明模型权重已开放。未实际调用、训练或复现实验。
