# Llama 3.2 Vision 与 Llama 3.3 独立复核

2026-10-28 对照 [Llama 3.2 Vision 11B 官方模型卡](https://huggingface.co/meta-llama/Llama-3.2-11B-Vision-Instruct)、[Llama 3 论文](https://arxiv.org/html/2407.21783)及 [Llama 3.3 70B 官方模型卡](https://huggingface.co/meta-llama/Llama-3.3-70B-Instruct)，核对两篇正文和配图。

- **3.2 Vision 结构与训练**：模型卡列 11B/90B、图文输入和文字输出、128K 与 GQA；视觉适配器用交叉注意力连接图像编码和 Llama 3.1。论文视觉适配器训练阶段更新图像编码器与适配器、冻结语言模型，正文已补精确论文链接并限定阶段。模型卡列 60 亿图文对和超过 300 万合成指令示例；数量不等于唯一图片数量。
- **3.2 Vision 评测及许可**：官方指令版 ChartQA test CoT、0-shot relaxed accuracy 为 83.4/85.5，DocVQA test ANLS 为 88.4/90.1，与正文一致。官方图文支持语言为英语；模型卡将超出支持语言的使用列为范围外，允许在遵守许可和政策前提下针对额外语言微调并由开发者负责安全使用，正文已补充。社区许可对居住于欧盟的个人及主要营业地在欧盟的公司的多模态权利有特别限制，同时规定最终用户例外；此前页面只说许可有条件，现补充具体边界并指向原文。
- **3.3 训练及语言**：模型卡列 70B、128K、GQA、15T+ token、超过 2500 万合成示例及 SFT/RLHF；没有公开这些合成样例均由某个教师产生。支持语言名单不含中文，模型卡将未列出语言的使用列为范围外，允许按许可与政策针对额外语言微调、开发者负责安全；正文已补充这一限定。
- **3.3 评测**：官方表中 3.1 70B / 3.3 70B / 3.1 405B 的 MMLU Pro、GPQA Diamond、HumanEval 和 MATH 数值及 shot/评分口径与正文一致；不同项排序不同，不支持全面超越的结论。社区许可并非 Apache。
- **配图**：3.2 图为图片经编码和交叉注意力进入语言模型的简化示意；3.3 图为文本自回归及 GQA 概念图。两者标明不是逐层官方图，XML 解析通过。
