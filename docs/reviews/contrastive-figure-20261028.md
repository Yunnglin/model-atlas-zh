# 图文对比学习配图核查

原创图 `public/figures/training/contrastive-pairs.svg` 依据 [CLIP 原论文](https://arxiv.org/abs/2103.00020) 的图文编码器、相似度矩阵及对称目标绘制，不含外部图片。

- 对应正文的猫图、杯子图与两条描述，0.8/0.2/0.3/0.7 是虚构教学相似度。已知配对在对角线；行内图找文、列内文找图分别计算交叉熵并取平均。
- 本批非配对作为候选竞争，不意味着语义上永远不匹配；图示与说明明确近重复和多个正确描述可能导致假负例。没有把两方向损失画成两个独立模型或概率校准保证。
- 正文插入图片、替代文本和教学限定，SVG XML 解析与 Markdown 格式检查通过；未训练模型或做浏览器截图验收。
