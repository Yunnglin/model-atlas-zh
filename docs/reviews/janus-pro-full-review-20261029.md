# Janus-Pro 全文审校

审校日期：2026-10-29。范围为 [Janus-Pro 正文](../../src/content/docs/omni/janus-pro-model.md)，不将 JanusFlow 的流匹配当作本模型方法。未运行模型或复现评测。

- **结构与模型卡**：对照[官方报告第 2.1、3.1 节](https://arxiv.org/html/2501.17811)与[仓库](https://github.com/deepseek-ai/Janus)，核对理解路径 SigLIP、生成路径 VQ tokenizer、两个两层 MLP 适配器、共享自回归主干和独立图像预测头；生成时历史图像编号经生成适配器输入下一步。4096 为语言主干最大序列长度，384×384 为论文实验图像尺寸。仓库代码 MIT、模型遵守 DeepSeek Model License。
- **训练**：报告第 2.2–2.4、3.1 节和表 2 核对三阶段训练、理解／文本／文生图配比、冻结策略、增加约 9000 万理解样本和 7200 万生成样本，以及第二阶段计划 360K 与实际提前停止 270K。新增 1B、7B 训练机器和时间，明确与推理资源区分。
- **评测**：报告表 3、4 核对 7B 的 MMBench 79.2、GenEval 总分 0.80、单对象 0.99 与计数 0.59；区分理解与生成指标及各自测试设置。正文中的海报、数量统计与错误分析是教学构造。
- **配图**：对照[图示登记](../../src/content/data/figures.yaml)和[原创教学图](../../public/figures/janus-pro/overview.svg)，理解和生成两条路径及文字直接输入主干与报告一致。2026-10-29 使用 Chromium 打开本机模型页，图成功解码为 1060×360，替代文本存在；截图目视检查文字与箭头。图明确为简化示意、非官方原图，来源及 CC BY 4.0 已登记。
- **社区**：2026-10-29 主审使用已登录 Chrome 实读 Eternity 的 [Janus-Pro 解析](https://zhuanlan.zhihu.com/p/20582287990)，当时 22 赞、31 收藏；文章解释理解路径的 SigLIP 与适配器、生成路径的 VQ 离散码与独立预测头，以及共享自回归主干，并介绍 Pro 的三阶段训练和合成数据。对照报告第 2 节核对；初代 Janus 和 Pro 的训练比例不能混用。赞藏是阅读时快照，文章作为论文解读而非独立复现实验。

- **评测数字补充复核（2026-10-29）**：[Janus-Pro 论文 v1 表 3、4及 3.2 节](https://arxiv.org/html/2501.17811v1)列 Janus-Pro-7B 的 MMBench 79.2；GenEval 的 overall 0.80、Single Obj. 0.99、Counting 0.59。分别对应图文理解和文生图组合能力，正文没有将总分解释为业务通过率，数值与论文一致。表中结果是作者报告，未在本项目复现。
