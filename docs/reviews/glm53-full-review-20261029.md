# GLM-5.3 专项审校

审校日期：2026-10-29。完整通读 [GLM-5.3 正文](../../src/content/docs/nlp/glm53-model.md)，区分 5.3、5.2 和 5.3-Flash；未运行模型或复现评测，账单案例为教学构造。

- **结构**：对照[官方配置](https://huggingface.co/zai-org/GLM-5.3/raw/main/config.json)和[模型卡](https://huggingface.co/zai-org/GLM-5.3)，核对 78 层、前 3 层稠密、256 路由专家选 8 加 1 共享专家、稀疏索引上限 2048、`indexer_types` 及 1048576 位置；相邻层共享索引结果不等于共享整个注意力层。官方权重页参数统计与每 token 激活量、许可分别说明。
- **训练**：模型卡明确与 GLM-5.2 同一基座、性能提升来自后训练；数据配比和具体奖励超参数未完整公开。长程环境、异步训练和账单案例为对官方描述的解释，不把前代方案或例子当成已披露的本版完整配方。
- **评测**：模型卡核对 Terminal Bench 3.0 的 28.3/4.6、DeepSWE v1.1 的 66.9/46.2、CyberGym 84.5/77.2 和内部代码基准相对提升；Terminal Bench 采用 Claude Code 2.1.207、max、400K 上下文、128K 最大输出、每题三次及 600 轮/10 小时上限。另核对 DeepSWE 使用 mini-swe-agent、每题 6 小时；CyberGym 为 1507 项单次运行、任务不限时、限制互联网访问的隔离评测。不同工具、任务和指标不当成统一的业务成功率。本次补充 `clear_thinking` 默认值及聊天建议，与控制预算的 `reasoning_effort` 区分，均依模型卡。
