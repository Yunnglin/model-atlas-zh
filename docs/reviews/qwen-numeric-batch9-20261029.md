# Qwen 模型指定评测数字与协议补充复核（第九批）

核对日期：2026-10-29。本记录只覆盖以下正文中列出的数字或评测材料，不代表全文所有数字、图示或知乎资料已再次复核，也未运行模型或复现评测。

- **Qwen3 初版**：对照[技术报告 v1 表 22 和第 4.6 节](https://arxiv.org/html/2505.09388v1#S4.SS6)，Qwen3-32B 思考模式在推理 RL 阶段与通用 RL 阶段的 IFEval 严格提示级准确率为 73.0 与 85.0，AIME 2024 为 83.8 与 81.4。报告说明 AIME 每年 30 题、每题采样 64 次取平均准确率；两检查点之间还有思考模式融合阶段。正文的数字与限制一致。
- **Qwen-VLA**：对照[技术报告 v2 表 4、表 11 与真实实验说明](https://arxiv.org/html/2605.30280v2)，Instruct 的 LIBERO、Simpler-WidowX、RoboTwin Easy/Hard 分别为 97.9%、73.7%、86.1%/87.2%；表 11 的继续预训练、SFT、RL 三阶段在 Simpler 为 64.3%、70.8%、73.7%，RoboCasa 为 40.4%、56.0%、56.7%，RoboTwin Easy 为 64.3%、86.3%、86.1%。真实 ALOHA 的 76.9% 属于从 Base 使用真实示范微调后的分布外测试，不是仿真 Instruct 权重零样本成绩。正文与所查协议一致。
- **Qwen3-Omni-Captioner**：正文评测节没有引用该模型的官方定量基准分数；100 条、20% 是标注为教学构造的方案。[技术报告 v1 第 4.3 节及附录 9.2](https://arxiv.org/html/2509.17765v1)将 Captioner 描述为使用详细音频描述微调并提供定性示例；主体基准表覆盖其他指定型号。另据[第三方研究](https://arxiv.org/html/2603.25767)，其使用 Captioner 处理 CaptionsStew 的约 400k 子集并生成监督材料；不能当成 Captioner 的独立准确率。
- **Qwen-Image-2.1**：正文评测节没有引用具体官方榜单分数；十张里三张错误只是标明用途的教学假设。[官方模型卡](https://huggingface.co/Qwen/Qwen-Image-2.1)支持文生图、编辑和透明图任务，说明可按这些维度设计评测，但该核查不是对全部官方图表逐项复算。
- **Qwen3.7-Max**：[阿里巴巴集团发布文章](https://www.alibabagroup.com/en-US/document-1994119844504535040)报告特定芯片算子任务运行约 35 小时、超过 1000 次工具调用，正文注明是厂商单例且依赖环境。更具体的 1158 次工具调用、432 次内核测量沿用[此前团队发布文章的实读记录](qwen37-full-review-20261029.md)；本次未重新读取该知乎文章或独立核验日志，不将该案例当作统一基准分数。
