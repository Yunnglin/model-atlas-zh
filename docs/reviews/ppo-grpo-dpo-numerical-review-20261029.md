# PPO、GRPO、DPO 数值示例核查（2026-10-29）

本次核对三篇文章的公式和教学算例，范围限定于下列项目，不代表重新审校全部训练文章，也未运行模型训练。

- [PPO 原论文第 3 节](https://arxiv.org/pdf/1707.06347)的目标是带符号优势的两项乘积取最小值。重算正文与图中的正优势、负优势示例，结果分别为 1.2 和 −0.8；进一步补充了反方向越界时的 0.5 和 −1.5，说明不是所有越界都被截成平坦目标。这一数值例子由教学构造，不能视为实测训练结果。
- [DeepSeekMath 第 4.1.2–4.1.3 节](https://arxiv.org/html/2402.03300)区分同组结果奖励标准化和过程奖励归一化；核对四个二值奖励、独立采样概率以及步骤奖励的算术，原正文的总体标准差口径和包含当前步骤结束 token 的处理一致。实际实现的标准差口径可能不同。
- [DPO 原论文第 4、6.3 节](https://arxiv.org/html/2305.18290)核对参考模型对数比与配分函数消去；按正文的 0.03、0.16、0.06、0.08、β=1 重算损失约 0.223。论文表 1 的 36%、31%、26%、23% 是与参考摘要比较的胜率，不是 DPO 与 PPO 直接对决。
