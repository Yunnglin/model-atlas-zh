# 扩散与流匹配教学图核对

- [DDPM 原论文](https://arxiv.org/abs/2006.11239)：图中选择其常见的噪声预测训练形式，用加噪数据构造训练输入；生成从噪声开始，由采样过程多次更新。扩散也可以采用其他目标和采样策略，图内已注明。
- [Flow Matching 原论文](https://arxiv.org/abs/2210.02747)介绍条件概率路径及其向量场。图使用正文的简化直线条件路径 `x_t=(1-t)x_0+t x_1`，该样本路径目标速度为 `x_1-x_0`；推理从 `t=0` 的噪声通过预测速度更新到数据端。不能将此例理解为每个流模型都使用同一条直线路径，或推理直接知道真实的 `x_1`；图中训练和生成分行明确区分。
- [Latent Diffusion](https://arxiv.org/abs/2112.10752) 与 [F5-TTS](https://arxiv.org/abs/2410.06885)分别是正文的图像潜变量和连续语音表示案例；图为跨方法概念示意，不声称二者使用完全相同路径、时间约定或网络。
- 图含 SVG 标题与描述，正文提供中文 alt、解释和两项来源；已验证 XML、图像链接与图内标签。未实际训练模型、复现论文或在真实设备做视觉验收。
