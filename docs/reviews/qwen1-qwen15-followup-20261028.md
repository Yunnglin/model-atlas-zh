# Qwen 初代与 Qwen1.5 重点复核

核对日期：2026-10-28。本轮核对两个页面中具体版本的结构、训练和评测，以及既有教学图的数据流；并非所有型号、全部表格或逐句独立审校。

- [Qwen 技术报告第 3 节](https://arxiv.org/html/2309.16609)介绍 ChatML 样本、系统与用户位置的损失掩码、SFT 的 2048 长度、128 批量和 4000 步，以及 PPO 前先更新价值模型 50 步、每个问题采样两个回答。正文增加这些设置和客服示例；报告表 5 给出 Qwen-7B-Chat 的 C-Eval 零样例 59.7、五样例 59.3 与 HumanEval 零样例 37.2。
- [Qwen1.5-7B 配置](https://huggingface.co/Qwen/Qwen1.5-7B/blob/main/config.json)列 32 层、4096 隐藏维度、32 查询头和 32 键值头；32B 与 110B 的 GQA 区别参见 [Qwen2 发布说明](https://qwenlm.github.io/blog/qwen2/)。正文按 BF16、单序列和 8192 token 推算常规 KV 缓存约 4 GiB，这只是算术估算，未运行模型或测量显存。配置中 `model_type: qwen2` 指实现配置名，不改变检查点所属系列。
- [Qwen1.5 发布说明](https://qwenlm.github.io/blog/qwen1.5/)介绍 DPO 与 PPO，以及 MT-Bench 用三个随机种子测评 7B Chat 得分 7.58、7.55、7.66，平均 7.60、标准差 0.05。正文保留任务与评价方式；博客未逐个型号完整披露训练配方。
- 两张既有教学图仅呈现文本因果注意力与前馈网络的高层数据流，不是官方完整网络图；图中 Qwen-7B 32 层以及 1.5 稠密 32B / 110B 的 GQA 标注与上述资料一致。本轮检查了 SVG 结构、连线及 Chromium 渲染，尚未逐项验证图像以外全部历史模型配置。
