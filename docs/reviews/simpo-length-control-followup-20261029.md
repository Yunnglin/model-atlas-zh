# SimPO 长度控制与实验条件核查（2026-10-29）

对照 [SimPO 论文 v3 的表 4、5、11 与附录 B.3](https://arxiv.org/html/2405.14734v3)：Mistral-Instruct 7B 的 SimPO 在 AlpacaEval 2 上长度控制胜率为 32.1%、原始胜率 34.8%，平均响应长度 2,193；移除长度归一化后分别为 19.1%、19.7% 和 2,067。该设置采用温度 0.5 采样，表 2 报告 AlpacaEval 2 包含 805 个问题，GPT-4 Turbo 既作比较基准也作评审模型。正文以这两组数字说明长度控制不使实际生成长度相同，不将偏好胜率当作事实正确率。

此次仅核对上述评测数据和配置，未运行模型或复现评测；未重新检查配图和知乎资料。
