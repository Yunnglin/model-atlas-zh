# DAPO 训练技术审阅

审阅日期：2026-10-29。通读 `src/content/docs/training/dapo.md`，对照论文 v2、算例、图和已有知乎实读记录；没有实际训练或复现评测。

## 原理与资料

- [论文 v2 第 2–3 节](https://arxiv.org/html/2503.14476v2)：目标包括非对称裁剪、按正确率过滤全对／全错题组、按组内 token 总数聚合损失、长度奖励；论文还讨论了对截断样本遮罩策略损失，并移除参考策略 KL 项。
- 修正四项设计摘要中“按奖励差异过滤”的简写：论文条件按正确率，叠加长度奖励后总分可能不同。新增从采样、筛选、奖励到 token 梯度汇总的教学流程。
- 长度惩罚加到正确性奖励，截断遮罩处理的是策略损失，二者不同；遮罩样本是否参与奖励归一化依实现及处理顺序，正文没有断言统一行为。

## 例子与评测

- 100／900 token 的两回答，逐回答平均时单 token 权重为 1/200、1/1800；组内 token 聚合时都是 1/1000。裁剪阈值 0.2／0.28 对应区间 0.8–1.28，正优势 1 和比率 1.25 的教学对照正确。
- 论文式 13 和第 4.1 节：期望长度 16384，缓冲 4096，长度 18432 时长度奖励 -0.5；若正确性奖励 +1，总奖励 +0.5。上限为 20480，达到上限不必然等同真正截断。
- 表 1：Qwen2.5-32B Base 的 AIME 2024 从 naive GRPO 30，经逐项叠加到 36、38、41、42、50；评测 32 次平均、温度 1.0、top-p 0.7，非 pass@32。DAPO-Math-17K 整数答案、每题 16 份训练回答与论文第 3.5、4.1 节一致。
