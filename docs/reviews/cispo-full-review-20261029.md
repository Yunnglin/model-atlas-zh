审阅日期：2026-10-29。通读 `src/content/docs/training/cispo.md`，对照 MiniMax-M1 论文 v1、算例、配图与已有知乎实读记录；未实际运行训练或复现评测。

## 原理与资料

- [MiniMax-M1 论文第 3.1 节](https://arxiv.org/html/2506.13585v1)：重要性比率是当前策略与旧策略在同一条件下的 token 概率之比；CISPO 将裁剪权重停止梯度后乘以优势与对数概率，按组内 token 总数归一化。目标采用 GRPO 组相对优势，论文实验不额外加参考策略 KL 项。
- 论文一般公式有上下界，但其实验只调上界、不施加有效下界；CISPO 对权重裁剪会引入一定偏差，且优势为零时该项无更新信号，不能误称所有 token 必然有非零梯度。
- PPO 的目标裁剪根据优势符号和比率决定是否饱和；比率 3、上限 2、正优势时，PPO 对应饱和项的梯度为零，CISPO 权重仍是 2。停止梯度指将权重当系数，不能从目标数值直接比较两种方法梯度大小。

## 例子与评测

- 教学例子中 0.3／0.1=3，示例上限 2 得裁剪权重 2；本次补充优势 −0.5 时对数概率梯度系数 2×(−0.5)=−1，以及零优势下无该项梯度。
- 论文图 2 使用 Qwen2.5-32B-Base、DAPO 数学数据与 AIME 2024，研究者描述 16 次离策略更新；在其设置中 CISPO 达到 DAPO 相近表现用约 50% 训练步数。补充动态采样、长度惩罚和成本范围；训练步数并非真实总成本或所有任务都快两倍。
- 工具轨迹、评测隔离与计算开销为实践建议，不表示已实测。
