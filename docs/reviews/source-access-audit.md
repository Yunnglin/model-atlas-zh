# 官方来源可访问性与引用抽查

审查日期：2026-10-28。

## 范围和方法

- 对审查开始时 `src/content/data/sources.yaml` 注册的 231 条来源发起 HTTP GET，跟随重定向，最多并发 8 个请求；以既有 `source-links.json` 的 118 条结果为对照，其中 113 条 ID 或地址为新增或变更。
- 检查最终状态码和重定向目标，重点人工核对可能从旧模型跳到新模型的地址。结合内容与知识结构单元测试，检查正文“参考资料”是否包含节点声明的注册来源，以及来源 ID 是否存在。
- 自动检查得到 227 条 HTTP 200、3 条 HTTP 403、1 条域名解析超时，没有观察到 HTTP 404。HTTP 200 只表明请求返回成功，不足以证明页面内容、版本或论据正确；结果是当时网络环境下的一次快照。

## 发现与处理

- Qwen2-VL 的 GitHub 旧仓库地址会跳转到 Qwen3-VL，Qwen2.5-Coder 的旧仓库地址会跳转到 Qwen3-Coder。两者虽返回 200，却不再是页面文字所说的对应旧版本实现。已把来源登记与两篇正文的对应引用同步替换为 Qwen 官方发布的对应版本模型卡，并明确标注为模型卡。
- OpenAI 的 GPT-4o、GPT-2、Whisper 三个官方页面在本环境返回 403；这说明本次请求被拒绝，不能据此认定页面已删除或准确判断拦截原因，因此保留原地址。
- CTC 原始论文地址所在域名本次解析超时；这不等同于 404，保留原地址，后续可在其他网络环境复核。
- ChatGLM3、GLM-4 模型卡及 DeepSeek V3.2 发布页发生重定向，最终目标仍指向对应官方仓库、模型卡或同一官方页面，因此未改写。

## 限制和验证

- 本次没有逐篇阅读全部来源、核对所有论文数据和论断，也没有检查知乎等正文额外延伸阅读的可用性；不能将这份记录视为内容事实全面审校。
- 来源与正文一致性检查只覆盖节点声明来源在“参考资料”中的存在性及结构引用，不能验证每个来源与每一段文字的论证关系。
- 修改后运行 `vitest run tests/unit/content.test.ts tests/unit/knowledge.test.ts`：2 个测试文件、25 个测试通过。
