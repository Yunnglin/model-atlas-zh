- [BERT 原论文](https://arxiv.org/html/1810.04805)附录 A.2 和表 2：核对预训练 90% 的步数使用 128 token、剩余 10% 使用 512 token；SQuAD 1.1 测试 F1 93.2 是先用 TriviaQA 微调的七模型集成，单模型 Large 的开发集 F1 为 90.9。图示的双向编码与任务头属于下游任务示意，不是声称预训练即完成所有任务。
- [T5 原论文](https://arxiv.org/html/1910.10683) 3.1.2、3.7 节及表 14：核对基线 524,288 步、每批约 65,536 token 与最终多任务预训练的不同设置；CNN/Daily Mail 中 Base 的 ROUGE-2 20.34 与 11B 的 21.55 均为论文表中测试值。教学图描述编码器—解码器数据流，省略层内结构。
