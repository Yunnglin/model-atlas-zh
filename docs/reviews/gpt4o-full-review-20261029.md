# GPT-4o 专项审校

审校日期：2026-10-29。完整通读 [GPT-4o 正文](../../src/content/docs/omni/gpt4o.md)，范围为 2024 年研究模型、系统卡与指定 API 模型页；未调用接口或复现评测。

- **结构与接口**：对照[发布说明](https://openai.com/index/hello-gpt-4o/)和[系统卡](https://openai.com/index/gpt-4o-system-card/)核对音频、文字、图片和视频的研究模型输入与文字、音频、图片输出，以及单一网络端到端训练；内部组件、参数和 token 编码未公开。区分 2024 发布范围、后续 Realtime 和 [`gpt-4o` API 模型页](https://developers.openai.com/api/docs/models/gpt-4o)的文字图片输入、文字输出、128000 上下文；页面于审校日标记 Deprecated，不能理解为全部接口已停用。
- **数据与训练**：系统卡 Model data & training 核对预训练截至 2023 年 10 月、公开与合作数据的类别、对齐和语音风险后训练；完整采样、损失及规模没有公开，正文的图表训练样本为教学构造。
- **评测**：发布说明核对音频响应最快 232 ms、平均 320 ms，系统卡核对身份相关 should-refuse 的 0.83/0.98 和著名引言内容 should-comply 的 0.70/0.83；两种拒绝与配合指标不等于说话人识别准确率。本次补充系统卡的 3 种官方声音与 27 段多样英语声音对照、四个任务及统计显著性表述；不推广到所有语言或录音条件。
- **配图**：核对[图示登记](../../src/content/data/figures.yaml)与[原创教学图](../../public/figures/gpt4o/overview.svg)：图区分研究描述的输入输出、未知内部结构和实际产品接口，未臆测网络层；来源和 CC BY 4.0 已记录。Chromium 打开本地正文后滚动加载，图成功解码（1100×360）且有替代文本，截图检查中文和箭头。
- **社区**：2026-10-29 在已登录浏览器实读生信森林的 [GPT-4o 与 GPT-4 比较](https://www.zhihu.com/tardis/bd/ans/3566251433)，页面显示 99 赞同、109 收藏。文章引用发布说明介绍 GPT-4o 文本、视觉和音频的端到端训练，也列举工单分类、合同字段抽取与推理的不同表现，说明比较应按任务、指标和误报代价进行。其声称 GPT-4 完全缺乏内置图像处理，以及 GPT-4o 可以生成视频，均不应直接采纳：[GPT-4V 系统卡](https://openai.com/index/gpt-4v-system-card/)明确支持视觉输入，[GPT-4o 的 2024 发布说明](https://openai.com/index/hello-gpt-4o/)列出的视频是输入，输出为文字、音频和图像。文中价格和用户体验属于历史信息；正文未把这些视为当前接口能力或稳定排名。
