# Qwen3.5 与 Qwen3.8 模型卡核查

核查日期：2026-10-28。本轮检查下列具体配置、评测和两张教学图；未逐句审阅全部正文，也没有运行模型或重新读取知乎文章。

- [Qwen3.5-397B-A17B 官方模型卡](https://huggingface.co/Qwen/Qwen3.5-397B-A17B)：语言主干 60 层，15 组每组三层 Gated DeltaNet 和一层 Gated Attention；后者有 32 个查询头、2 个键值头，每头 256 维。每层路由 512 个专家中的 10 个，并使用 1 个共享专家。模型卡标注 Apache-2.0。文中按 8,192 token 和 BF16 对 Gated Attention 的键值缓存估算约 240 MiB，未将其他状态、权重与视觉编码计入。
- [Qwen3.8-27B 官方模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)：64 层，16 个 Gated Attention 层，各有 24 个查询头、4 个键值头，每头 256 维；标注 Apache-2.0，并提供图像文本输入示例。
- [Qwen3.8-2.4T-A95B 官方模型卡](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)：92 层，23 个 Gated Attention 层，各有 64 个查询头、4 个键值头，每头 256 维；发布权重为文本输入输出、始终思考，标注 Qwen3.8-Max 许可。按 8,192 token、BF16，27B 与 2.4T 的全注意力键值缓存分别约为 512 MiB、736 MiB；这些是依配置计算的理论大小，并非实际运行测量。
- 3.8-27B 模型卡报告的 SWE-bench Pro 为 61.7，模型卡表中 3.6-27B 为 53.5；脚注说明二者用 Claude Code、256K 上下文及修正后的任务集评测。两项相差 8.2 个百分点；这一对照不能分解架构、数据和后训练的贡献。
- 两张本地教学 SVG 已用 Chromium 渲染检查：3.5 图表示视觉编码和文本输入汇入语言模型；3.8 图区分 27B 视觉语言与 2.4T 文本模型。两图是简化示意，不是官方原图，本轮未修改图或共享图登记。

未核查事项：各服务端功能及所有推理框架的支持范围、完整训练数据和具体奖励配方、页面全部来源和社区文章的当前可读性；文章中的教学算例未进行训练、模型推理或基准复现。
