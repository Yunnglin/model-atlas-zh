## 原理与资料

- [GSPO 论文 v2 第 4 节](https://arxiv.org/html/2507.18071v2)：序列似然比取长度倒数次方，即 token 对数概率比的平均再取指数；它是代理目标中的归一化比率，不是完整的无偏序列重要性采样权重。优势采用同组奖励归一化，目标在序列级裁剪。
- 论文式 5 使用对称阈值，实验采用不同左右阈值；正文明确区别。GRPO 使用逐 token 比率，RLVR 则描述奖励来源，不能将更新粒度与奖励来源混为一谈。
- 补充同组奖励相同时标准差为零的边界：跳过或加入稳定项是实现选择，并不声称所有实现一致。

## 例子与评测

- 核对 1.44 和 1.00 的几何平均为 1.2；1.44×0.64=0.9216，平方根为 0.96。正优势上界案例以及新增负优势下界案例符合 min 目标：负优势 -1 时，0.8 和 0.9 对应 -0.8、-0.9，选 -0.9。裁剪不强制概率比处于区间。
- 论文第 5 节：Qwen3-30B-A3B-Base 冷启动，rollout 批分四个 mini-batch；GSPO 左右阈值 0.0003／0.0004，GRPO 为 0.2／0.27。AIME 2024 为 32 次采样平均 Pass@1，LiveCodeBench 为 8 次平均 Pass@1；不等于 Pass@32 或 Pass@8。
- 论文对同样样本每次更新后约 10% 专家选择发生变化的观察和 Routing Replay 比较限定于实验条件；隐藏测试与奖励漏洞为教学建议。
