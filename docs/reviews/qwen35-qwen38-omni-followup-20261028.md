# Qwen3.5-Omni 与 Qwen3.8-Omni 复核

核对日期：2026-10-28。核对范围为两篇模型文章及其登记的官方配图，依据 [Qwen3.5-Omni 技术报告 v1](https://arxiv.org/html/2604.15804v1) 和 [Qwen3.8-Omni 技术报告 v1](https://arxiv.org/html/2609.25611v1)。

- Qwen3.5-Omni 报告第 2.2 节称 AuT 的 4000 万小时音频文本配对由 Qwen3-ASR 生成；正文原来的“其中部分转写”缩小了来源范围，已改为与论文一致的说法。四层卷积、16 倍下采样和 6.25 Hz 输出，以及文本／语音交错与首包延迟实验条件也已核对。
- Qwen3.8-Omni 报告第 7.2 节的 6 秒音频测试中，首个音频块延迟为 978.36 ms，生成 RTF 为 0.1538。正文补充 RTF 的计算含义和例子，明确首块等待不计入该 RTF。报告说明每项条件一次预热后取十条有效回复，且计时不包含上传、建立连接和播放。
- 3.5 的官方图展示 Thinker、Talker、MTP 和流式解码；3.8 的官方图分别展示通用／空间音频编码器和实时应用框架。已检查本地图片内容及登记说明，没有将 3.8 的局部结构或应用框架图说成完整的标准 Flash 模型结构。
- 两份报告中关于前代 WorldSense 分数的差异，以及 3.8 预训练第二阶段分项约数与总数不完全一致，保留在正文中，避免把存在差异的数字合并为同一口径。
