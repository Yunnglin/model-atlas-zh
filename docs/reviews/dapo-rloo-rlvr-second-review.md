# DAPO、RLOO、RLVR 继续复核

本审校者此前参与过 RLVR 页审校，故 RLVR 为继续复核；DAPO 和 RLOO 本轮对照原论文检查。未运行训练或复现论文成绩。

- **DAPO**：[论文 v2](https://arxiv.org/html/2503.14476)方程 7–13、实验表 1：正确性奖励 +1/−1，动态采样按正确率过滤全对与全错；组内总 token 求和再除组内 token 数，裁剪下限 0.8、上限 1.28。正优势 1 且概率比 1.25 时，非对称目标为 1.25、对称上限 1.2 时为 1.2。长度 18432、软区起点 16384、缓冲 4096，惩罚为 −2048/4096=−0.5，若正确性 +1 则总奖励为 +0.5。论文叠加 overlong filtering 与 soft punishment，但停止原因影响是否截断；已明确不能只因到达长度上限就断定被截断。
- **DAPO 评测**：论文 §4.1 为 AIME 2024 设温度 1.0、top-p 0.7、重复 32 次并报告 avg@32；正文已明确不是 pass@32，且未将对照分数直接归因于算法以外的同等条件。max 20480 及缓冲区来自论文具体实验，不推广到所有实现。
- **RLOO**：[Back to Basics §2.3](https://arxiv.org/html/2402.14740)在同提示独立同分布采样条件下使用其他 k−1 项奖励均值作为基线。奖励 (1,0,0) 得优势 (1,−0.5,−0.5)，与组均值中心化的比例为 k/(k−1)=1.5。已补基线的停止梯度和策略相关奖励应按目标处理，避免将无偏结论外推到任意可微奖励或基线。
- **RLVR**：[DeepSeek-R1 v1 §2.2](https://arxiv.org/html/2501.12948v1)核对 R1-Zero 的规则正确性和格式奖励；区分 R1 后续其他阶段与学习型奖励模型。80×0.8=64；公开测试中总返回第二数确会在 (9,2) 失败。过程奖励模型与结果验证器、奖励来源与 GRPO 更新方法被正确区分。
- **图**：DAPO 和 RLOO 当前无独立图；RLVR 使用的 `feedback-grpo.svg` 是规则或偏好评分、再经 GRPO 的教学示意，不称所有 RLVR 使用 GRPO，正文说明一致。已检查 SVG 的 XML 格式，但未做浏览器视觉验收。
