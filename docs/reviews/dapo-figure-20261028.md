# DAPO 长度处理教学图核对

依据 [DAPO 论文 v2 §3.4、式 13 和 §4.1](https://arxiv.org/html/2503.14476v2)：实验将期望长度设为 16,384 token，另设 4,096 token 缓冲，生成上限为 20,480。长度惩罚在缓冲中线性变化，与正确性奖励相加；论文表 1 在基线之上先加入截断过滤、再逐步加入软惩罚等组件。

图中 18,432 位于缓冲区中点：`(16384 − 18432) / 4096 = −0.5`。该值只是长度奖励，不是直接把样本判错；例子假设回答完整。图另行描述真正截断样本的策略损失屏蔽，强调达到上限不能单凭长度断言截断。组内奖励统计是否包含被屏蔽样本依实现和处理顺序，正文已有提示。

横轴只展示缓冲区，已在图内注明；原创 SVG 具有标题和描述，正文提供中文替代文字与图注。数值与 XML 解析已核验，未复现训练或进行真实设备视觉验收。
