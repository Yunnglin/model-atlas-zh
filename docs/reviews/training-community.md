# 训练方法的知乎参考核查

核查日期：2026-10-27。使用已有 Chrome 登录会话搜索并阅读正文，赞同与收藏是查看时的动态值；互动量辅助筛选，不证明事实正确。文章作为延伸阅读，公式、配置及实验结论回到原论文、官方文档和所用版本的实现核对；没有复制其图文。

- **LoRA**：[猛猿：图解 LoRA 原理](https://zhuanlan.zhihu.com/p/646831196)，956 赞同、1054 收藏。适合从矩阵、秩和低秩分支建立直观认识；作者明确将部分关于缩放和子空间的解释标为个人推测。文中将反向计算必须物化完整矩阵及某层峰值显存与全参基本相同作为一般结论，但实际自动微分和算子计算方式不同，不能直接推断；以 [LoRA 原论文](https://arxiv.org/abs/2106.09685)与具体实现为准。
- **SFT**：[LLMCat：loss 与 mask 配置](https://zhuanlan.zhihu.com/p/1954712810387903769)，74 赞同、165 收藏。单轮、多轮的目标位置和右移对照有助于排查错位；其中条件符号与右填充相关说法需按具体代码及模板核验，不能认为右填充必然避免溢出，也不能认为所有 SFT 都只监督助手回复。对照 [InstructGPT](https://arxiv.org/abs/2203.02155) 和 [TRL SFT 文档](https://huggingface.co/docs/trl/sft_trainer)。
- **GRPO**：[知行者：GRPO](https://zhuanlan.zhihu.com/p/20021693569)，509 赞同、860 收藏。可参考组内比较与 PPO 的训练流程；作者标注部分公式不全，KL、奖励和优势计算应回查 [DeepSeekMath](https://arxiv.org/abs/2402.03300)及具体实现。去掉 value 模型不等于不需要奖励信号，也不能保证任意任务都优于 PPO。此前 [RLHF/GRPO 参考](zhihu-reading.md)可作补充。
- **蒸馏**：[小张：MiniLLM](https://zhuanlan.zhihu.com/p/706214065)，140 赞同、239 收藏。适合认识学生采样、反向 KL 和教师混合采样；文中将序列级蒸馏简单等同前向 KL、以及对性能和参数量的概括都应限定方法和实验，不作为通用结论；以 [MiniLLM 论文](https://arxiv.org/abs/2306.08543)和 [序列级蒸馏论文](https://arxiv.org/abs/1606.07947)为准。
- **量化**：[吃果冻不吐果冻皮：量化技术总结](https://zhuanlan.zhihu.com/p/11886909512)，252 赞同、611 收藏。可用于了解权重、激活和 KV 缓存及常见方法；文中一些性能、精度和硬件适配结论有特定实验背景，广告内容亦非技术依据，不能直接推广；QLoRA 训练冻结的量化基座与 LoRA 适配器，不应与对基础权重进行量化感知训练混为一谈。对照 [QLoRA](https://arxiv.org/abs/2305.14314)、[AWQ](https://arxiv.org/abs/2306.00978)与 [SmoothQuant](https://arxiv.org/abs/2211.10438)。

本次核对集中于上述说明及原论文相关部分，不代表社区文章逐句核实；未运行模型、训练或评测。

## RLOO 对比文章补查（2026-10-28）

实读 [无易：一文对比 4 种 RLHF 算法](https://zhuanlan.zhihu.com/p/1898862420878947530)，当时为 507 赞同、1198 收藏。其留一基线算例有助于理解同题多个回答的比较，但互动量不代表技术结论可靠。对照 [RLOO 论文](https://arxiv.org/abs/2402.14740)与 [ReMax 论文算法 1](https://arxiv.org/abs/2310.10505)：ReMax 使用贪心回答的奖励作基线，文章将它描述为只训练多个答案中最高分者，不符合原论文；评论中也有人指出基线问题。另对照 [REINFORCE++ 当前论文](https://arxiv.org/abs/2501.03262)第 3 节，它讨论全局批次归一化及组基线变体，不能概括为只用过去多个批次的平均奖励。文章对“抗噪声”和优劣的泛化说法也不足以作为通用结论。

本次仅核对上述关键点，未全面核验文章其余内容，也未运行训练。RLOO 正文补充了 ReMax 和 REINFORCE++ 的对照例子；该知乎文章保留在审阅记录中，未作为推荐教程引用。
