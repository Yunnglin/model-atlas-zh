# DAPO、GSPO、GRPO 原论文跟进审校

核对时间：2026-10-28。对照三篇原始论文的目标函数、采样、裁剪、奖励和实验设定，复算正文教学例子；未运行训练或复现原论文结果。

## DAPO

- 对照 [DAPO 论文 v1 §3、§4](https://arxiv.org/html/2503.14476v1)：动态采样按照同组正确率过滤全对与全错，token 聚合先除同一题组总 token 数，Clip-Higher 实验的上下阈值为 0.2 / 0.28，16,384 + 4,096 = 20,480。AIME 2024 使用 avg@32。
- 修正对过滤的解释：仅有二值正确性奖励时全对组没有差异；加入软长度奖励后总分可能不同，但论文过滤依据仍是正确率，不能笼统说总奖励必然相同。
- 原文分别介绍截断损失屏蔽与软长度惩罚，部署和其他实现要检查具体行为；本文不宣称所有框架都采用相同做法。

## GSPO

- 对照 [GSPO 论文 v2 §4、§5](https://arxiv.org/html/2507.18071v2)：长度归一化的序列比率是 token 比率的几何平均；整个回答的优势、裁剪对象和 token 级 GRPO 不同。教学算例的 1.44、0.64 的几何平均为 0.96。
- 补充论文实验阈值：GSPO 的左右裁剪范围为 0.0003 和 0.0004，GRPO 基线为 0.2 和 0.27。两种统计口径不同，数字不能直接比较为强弱。

## GRPO

- 对照 [DeepSeekMath 论文 v3 §4.1](https://arxiv.org/html/2402.03300v3)：组内奖励标准化、结果监督、过程监督和原始目标的参考策略 KL。两例总体标准差的结果分别为 ±1，以及约 +1.73 / −0.58。
- 补充原论文迭代算法会在外层更新参考策略；当前批次的旧策略与参考策略角色不同，但不必始终为同一或不同检查点。

文中示例为教学构造，指标和训练成本取决于实际数据、奖励、样本长度与实现；该记录不是完整算法正确性证明。
