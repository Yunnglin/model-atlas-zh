# GPT-4 与 GPT-4o 独立二次审校

范围：对照 OpenAI 原始发布说明、GPT-4 技术报告、GPT-4o 系统卡及现行 API 模型页，核对正文和自绘 SVG 的结构与模态、训练披露、所引用评测、不同版本的开放时间；未自行调用接口或复现基准。

- **GPT-4**：2023 年 3 月 14 日[发布说明](https://openai.com/index/gpt-4-research/)确认当时公开文字输入、图像与一家伙伴先行使用；[技术报告](https://arxiv.org/html/2303.08774)确认 Transformer、预测下一 token、公开及授权数据和 RLHF，具体结构/参数不披露。模拟律师考试约第 90 百分位的对照和限定与报告一致。增加报告附录 E 关于 MATH/GSM8K 部分训练样本与 GSM8K 成绩的限定，避免误以为完全无相关任务训练；论文称已检查 GSM8K 测试集未包含在训练中。图为输入输出概念图而非内部架构。
- **GPT-4o**：2024 年[发布说明](https://openai.com/index/hello-gpt-4o/)和[系统卡](https://openai.com/index/gpt-4o-system-card/)确认其自回归、图文音视频输入/图文音频输出的模型级描述、端到端训练、数据截止 2023 年 10 月，以及当时 API 先开放文本和图像输入。图明确模型能力与各接口可用能力不同，不宣称内部结构。
- 语音 232/320 毫秒及说话人识别测试 0.98/0.83 与系统卡一致；明确 0.83 指基于著名引言**内容**识别关联人物的应配合题，而非识别当前录音中发声者。系统卡的测试是特定评估条件，不代表其他音频或场景。
- 截至 2026-10-28，[API 模型页](https://developers.openai.com/api/docs/models/gpt-4o)显示 `gpt-4o` Deprecated、128,000 上下文、文本及图片输入/文本输出，2024-05-13 快照标为 Shut down。文中对可变状态补充核查日期；不把废弃等同已停止服务，也不把 API 能力当作 2024 研究模型全部能力。
- 两图 SVG XML 已解析，未完成浏览器截图或视觉验收。开放时间、模型规格及测试以引用材料在核查日呈现内容为准。
