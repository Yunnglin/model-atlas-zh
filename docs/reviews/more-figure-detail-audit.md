# 基础、语音与生成模型教学图抽查

核对日期：2026-10-28。本轮对六张教学图的主要数据流与对应一手资料进行对照；这是特定点抽查，并非全图或全文的逐项核验，也没有运行模型。

| 模型             | 一手依据与本次核对                                                                                                                                                                                                                                   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 原始 Transformer | [论文](https://arxiv.org/html/1706.03762)第 3.1 节：编码器表示供解码器交叉注意力使用，解码器按已生成前缀预测下一 token；图中标明省略位置编码、残差与归一化。                                                                                         |
| GPT-2            | [官方实现](https://github.com/openai/gpt-2)与[论文](https://cdn.openai.com/better-language-models/language_models_are_unsupervised_multitask_learners.pdf)：token 和位置嵌入进入因果语言模型，逐步选择下一 token；图未把采样描述为必然选择最大概率。 |
| Conformer        | [论文](https://arxiv.org/html/2005.08100)第 2 节：两段半步前馈包围自注意力和卷积模块；最终文字由外部识别组件生成。                                                                                                                                   |
| F5-TTS           | [论文](https://arxiv.org/html/2410.06885)第 3.1 节：推理条件包含参考音频的梅尔谱，以及参考转写与待生成文本组成的序列。原图的“参考音频／文本 → 声学条件”可能让人以为文本直接转换成声学条件；已将文本条件和参考音频路径分别写清。                      |
| Qwen-Image       | [技术报告](https://arxiv.org/html/2508.02324)第 2 节：使用冻结的 Qwen2.5-VL 提供文本特征，MMDiT 与潜空间配合生成；图是文生图简图，不代表完整编辑训练流程。                                                                                           |
| Qwen3Guard       | [技术报告](https://arxiv.org/html/2510.14276)第 2 节：Gen 对完整内容生成安全标签，Stream 对生成过程增量判断；应用如何处置由上层系统决定。                                                                                                            |

图示均为简化教学材料，不能依据未画出的模块断言其不存在；模型参数、训练与评测结果应另看对应文章和来源。
