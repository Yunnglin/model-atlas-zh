# 闭源模型指定评测数字复核（2026-10-29）

本次对照五篇正文中下列指定数字及其评测条件；不等于重新核查全文或全部数字，也没有调用模型或复现结果。

- **GPT-2**：[原论文第 3.5 节和第 4 节](https://cdn.openai.com/better-language-models/language_models_are_unsupervised_multitask_learners.pdf)给出以文章及对话历史为条件、贪心解码的 CoQA 开发集 55 F1；新闻领域约 15% 文档与 WebText 重合，相关样本约高 3 F1。正文的 F1、划分和重合范围一致。
- **GPT-3**：[论文表 3.3、3.6](https://arxiv.org/html/2005.14165)列 TriviaQA 闭卷零／单／少样本 64.3、68.0、71.2%，少样本在 Wiki 划分测试服务器评估；ARC-Challenge 分别为 51.4、53.2、51.5%，当时微调最佳对照 78.5%。正文的任务、模式和数字一致；TriviaQA 的测试服务器描述仅明确用于少样本结果。
- **GPT-4**：[技术报告表 2 及表 11](https://arxiv.org/html/2303.08774)给出 HumanEval GPT-4 67.0%、GPT-3.5 48.1%，潜在数据重合排除后 GPT-4 65.58%。后者是不同题目集合上的结果，正文没有把差额直接归因于数据污染；模拟律师资格考试约前 10% 是报告的模拟考试估算。
- **GPT-4o**：[系统卡语音识别隐私评测](https://openai.com/index/gpt-4o-system-card/)列早期／部署版本 `should_refuse` 0.83／0.98、`should_comply` 0.70／0.83；它们对应拒绝根据声音识人和应配合回答等规则，不是声音识别准确率。同页用 3 种系统声音和 27 段不同英语声音合成输入，报告四项能力任务上的差异未达统计显著；正文范围一致。
- **Gemini 1.5**：[技术报告 v5 第 5.2.1、5.2.2 节及表 9](https://arxiv.org/html/2403.05530v5)报告 Pro 的合成长文本找针在 10M token 内 99.2%；1H-VideoQA 有 125 道五选一题、视频 40–105 分钟，按每秒一帧采样再线性抽取，Pro 在 16／150／全部帧为 45.2／56.3／72.2%，Flash 为 39.7／50.8／65.9%。正文数据及抽样条件与该报告一致，10M 指研究评测长度。

上述结果为各官方论文或系统卡在对应时点报告的指标，不能与未统一提示、数据集和模型快照的结果直接比较。
