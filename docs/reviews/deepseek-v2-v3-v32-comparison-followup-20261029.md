# DeepSeek-V2、V3 与 V3.2 版本对照复核（2026-10-29）

本次针对三篇正文的主要结构、训练及代表性评测进行专项核对，没有逐句审校全部数字，也没有复现模型或重新阅读知乎。

- **V2**：对照[技术报告表 2](https://arxiv.org/html/2405.04434)核对原版 236B 总参数、21B 激活参数，和原报告 MMLU 五样本 78.5；它不应与 V3 报告对 V2 的重新评测值混为一次实验。
- **V3**：对照[初版报告](https://arxiv.org/html/2412.19437v1)核对 14.8 万亿预训练 token，以及表 3 的 V2-Base 78.4 与 V3-Base 87.1。正文补充报告 4.4.1 节所述 MMLU 基于困惑度的测评方式，避免读者误以为该数字必然来自自由生成答案。报告表头的 EM 名称沿用原文。
- **V3.2**：对照[技术报告](https://arxiv.org/html/2512.02556)第 2 节及第 4.4 节，核对 DSA、主模型与索引器的不同目标、上下文管理触发条件与 BrowseComp 51.4／67.6；其中 67.6 对应报告的 Discard-all 策略，不能只比较分数而不说明工具与上下文条件。

验证：V3 正文 Prettier 检查、内容单元测试和差异检查通过。其他历史审校依据和社区资料仍见各模型已有专项记录。
