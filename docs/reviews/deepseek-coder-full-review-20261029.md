# DeepSeek-Coder 初代全文审校

审校日期：2026-10-29。核对[正文](../../src/content/docs/nlp/deepseek-coder-model.md)，范围为初代模型，不混用 Coder-V2 和以通用语言模型续训的 Coder-v1.5。未运行模型或复现评测。

- **结构**：对照[技术报告](https://arxiv.org/html/2401.14196)第 3.3 节和表 2，核对稠密解码器、1.3B／6.7B／33B 的层数与维度以及 33B GQA；对照[官方仓库](https://github.com/deepseek-ai/DeepSeek-Coder#2-code-insertion)核对特殊标记的前缀、后缀与中间段使用方式。FIM 是对输入重新排序，模型仍按自回归方式生成。
- **训练**：对照论文第 2、3 节，核对 2T、数据比例、仓库级去重、依赖排序和 FIM 比例。正文补充文件依赖与路径注释、长上下文再训练和指令微调实验参数；静态依赖解析有范围限制。16K 是论文经验上较可靠的范围，不把理论上的 64K 描述成已验证的稳定能力。
- **评测**：对照论文表 3、4、7：33B Base/Instruct 的 HumanEval Python pass@1 分别为 56.1%/79.3%，使用贪心解码；33B Base 的 DS-1000 总分为 40.2%，其中 NumPy/Pandas 为 49.6%/25.8%；6.7B 模型在 CrossCodeEval Python 的完全匹配率从无检索的 9.53% 提升至使用 BM25 的 16.14%。正文补充 DS-1000 分库差异，说明不同数据集的分数不能直接相减；代码执行与外部测试不等于模型自身具备执行能力。
- **配图**：对照[图登记](../../src/content/data/figures.yaml)与 [SVG](../../public/figures/deepseek-coder/overview.svg)，在本地页面用 Chromium 实际加载并目视检查，文字与箭头可辨；图为 FIM 流程教学示意，不是官方架构原图，外部执行和测试明确为可选。
