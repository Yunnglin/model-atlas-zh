# KTO 训练技术审阅

审阅日期：2026-10-29。通读 `src/content/docs/training/kto.md`，对照 KTO 论文、示例、配图和已有知乎实读记录；未运行训练或复现评测。

## 原理与资料

- [KTO 论文第 4.1 节](https://arxiv.org/html/2402.01306)：可取和不可取样本分别以正、反方向比较单条回答的策略与参考模型对数概率比和参考点；两类权重与 sigmoid 目标和正文公式一致。参考点构造为策略到参考模型的 KL，论文采用微批次错配输出的有偏近似并截到非负，训练中不反向传播其梯度。理论 KL 与单次对数概率差不同。
- 论文第 4.2 节所述错配估计要求 microbatch 至少 2；参考点在某些配置也可设为零，不能将单一实现强加给所有方法。DPO 使用同题成对偏好，KTO 使用单条可取／不可取标签，二者数据来源和优化目标不同。
- 本次补充错配两项对数比 (0.4, −0.2) 平均为 0.1、负均值截为 0 的教学示例，明确错配用于估计而非重标注。

## 例子与评测

- z=0、β=1、权重为 1、r=ln2 时，正样本损失为 1/3，负样本损失为 2/3；负例 1000、正例 100 及权重 13.33 与 1 时，加权数量约 1333 和 1000。权重改变各类影响，不等于实际梯度贡献一定相同。
- 论文表 3：Mistral-7B 和 OpenAssistant 数据中，DPO、KTO 每题仅一条、KTO 全部回答相对 SFT 目标的 GPT-4-0613 评审胜率为 60.0±3.7、63.1±3.6、65.2±3.6%，区间为 90% 二项置信区间；不是事实正确率，也不能外推为所有任务 KTO 优于 DPO。
- 客服示例、错例归因、训练验证集隔离和标签质量建议为教学设计，并无实测。
