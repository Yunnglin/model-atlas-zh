# CISPO 中文资料核对

阅读日期：2026-10-28。实读 [炼熵师《CISPO 的发现过程》](https://zhuanlan.zhihu.com/p/1962307894105048283)，页面显示 393 赞同、441 收藏；数字是阅读时快照。作者自述参与过 CISPO 的探索。文章回顾了复用采样数据、裁剪 token 和反思词学习信号的观察，并展示早期版本的构思。

对照 [MiniMax-M1 论文第 3.1 节](https://arxiv.org/html/2506.13585)：论文同样描述某些反思 token 的概率较低、裁剪后无法贡献后续更新，并正式给出停止梯度后的权重及优化目标。作者回忆的早期损失不是论文最终公式；文章中一次采样做 8 次更新是作者描述的实验，论文相关实验设置提到 16 次更新，二者不应混为同一个设置。未复现实验。
