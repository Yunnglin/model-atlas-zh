# Qwen3.8 开放系列审校

审校日期：2026-10-29。通读 [正文](../../src/content/docs/omni/qwen38.md)，对象是 27B 与 2.4T-A95B 开放权重；Flash-Next 和 Omni 各有独立页面。未运行模型或复现评测。

- **结构与模型卡**：对照 [27B 模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)和 [2.4T-A95B 模型卡](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)：前者为图文视频输入的 64 层稠密骨干，后者为纯文本、92 层 MoE、512 个路由专家选 10 加一个共享专家；均为原生 262,144 上下文，但支持输入、思考开关与许可不同。正文 BF16 缓存是指定假设下算术估计，不是实测显存。
- **训练**：两张模型卡列预训练、后训练和多步预测，但未公开完整配方；正文的工具轨迹和样本切分是教学方案，不归给官方训练。激活参数不能替代完整权重存储量。
- **评测**：对照 27B 模型卡 SWE-bench Pro 脚注，61.7 与 3.6 的 53.5 使用 Claude Code、256K、temperature 1.0、top-p 0.95 和修正题集；2.4T 卡上的 Max 服务成绩不能自动算为本地权重。新增 MathVision 无代码解释器 90.0、有解释器 94.6，注明标注修正与不同模型提示选择方式，避免把工具收益写成固有模型收益。
- **配图**：对照 [登记](../../src/content/data/figures.yaml)及 [原创教学图](../../public/figures/qwen38/overview.svg)，27B 的文字直入、图像视频经视觉编码，2.4T 权重文本输入；图省略层内结构，非官方原图。2026-10-29 Chromium 打开本地正文，图片成功解码为 1060×300、替代文本存在，目视检查文字与排版。
- **知乎**：2026-10-29 由主审通过已登录 Chrome 阅读量子位（署名梦瑶）的 [27B 解读](https://zhuanlan.zhihu.com/p/2071960777104402013)，当时 21 赞、19 收藏；文章介绍 64 层中 48 层 Gated DeltaNet 与 16 层全注意力、262K 原生上下文及推理档位，对照 27B 模型卡核对。文章中的榜单与第三方 GPU 演示依赖具体配置，不作为普遍速度或端到端效果。互动数是阅读时快照。

补充：[2.4T 版本的社区实读与官方对照](final-community-a.md)；原文为作者分析，参数及许可按官方资料核对。
