# DeepSeekMath 初代全文审校

审校日期：2026-10-29。通读 [DeepSeekMath 正文](../../src/content/docs/nlp/deepseek-math-model.md)，范围是 2024 年初代 7B，不混用 DeepSeekMath-V2 或 R1。此次未运行模型或复现评测。

| 维度       | 核查与结果                                                                                                                                                                                                                                                                                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 结构       | 对照 [技术报告](https://arxiv.org/html/2402.03300v3) 第 2、3 节与 [7B Base 配置](https://huggingface.co/deepseek-ai/deepseek-math-7b-base/blob/main/config.json)：代码底座继续预训练，配置为 30 层、4096 隐藏维度、32 个注意力头与 32 个键值头；工具执行由外部环境提供。                                                                                             |
| 数据与训练 | 对照技术报告第 2、3 节：数学语料库 120B token，继续预训练混合总量 500B token；正文区分语料库规模与训练读取量。GRPO 实验从 Instruct 出发，每题 64 条采样、学习率 1e-6、KL 系数 0.04，采样后做一次更新，最大长度设置为 1024；奖励模型与策略更新方法分别解释。                                                                                                          |
| 评测       | 对照技术报告第 3 节表 5：不使用工具的思维链设置中 Instruct GSM8K/MATH 为 82.9%/46.8%，RL 为 88.2%/51.7%；同领域数据、工具条件、答案提取及独立测试的限制在正文交代。单次结果不等同论文摘要中 64 次采样投票的 60.9%。                                                                                                                                                  |
| 配图       | 实际查看本地页面中的 [训练流程图](../../public/figures/deepseek-math/overview.svg) 与 [语言骨干图](../../public/figures/deepseek-math/backbone.svg)，图片可读，分别解释训练阶段与内部数据流，均为简化教学图而非论文原图；尺寸、来源、许可和哈希登记于 [素材记录](../assets.md)。                                                                                     |
| 知乎       | 2026-10-29 通过已登录 Chrome 阅读进击的Bruce的[《速读 deepseek v2（三）—理解 GRPO》](https://zhuanlan.zhihu.com/p/700878867)，当时 81 赞同、201 收藏；文章解释同题多次采样、以组内得分计算基线，和原论文第 3 节一致，可帮助理解正文的组内相对优势。文中关于 GRPO 必须满足的采样条件是作者的判断，不作为通用定律；其后讨论的 V2 两阶段对齐不套用到初代 DeepSeekMath。 |

正文的算术题与错例统计均标为教学示例，非模型实测。知乎赞同与收藏数为阅读时快照，不用于证明技术结论。

2026-10-29 补充逐项核对论文表 6：正文的代码先训对照实验使用 DeepSeek-LLM 1.3B，代码或通用数据各 400B tokens 后接 150B 数学 tokens；无工具 GSM8K/MATH 分别为 21.9%/15.3% 与 19.1%/14.4%。该对照实验不是初代 DeepSeekMath 7B 的成绩。
