# Qwen2.5-VL 与 Qwen3-VL 独立复核

对照 [Qwen2.5-VL 技术报告 v1](https://arxiv.org/html/2502.13923v1) 和 [Qwen3-VL 技术报告 v1](https://arxiv.org/html/2511.21631v1) 的结构、数据流程、原文所引用评测与教学图；未执行模型、复现基准或修改共享 YAML。

- Qwen2.5-VL 报告表 1 和 2.1 节给出 14×14 patch、预处理宽高为 28 的倍数、32 层视觉编码器、112×112 窗口和全注意力 0 基索引 7/15/23/31；Merger 将相邻 2×2 特征合并、两层 MLP 投影。示例 840×560 得 2400 patch、600 视觉 token 的静态图算式正确。报告提到视频相邻两帧分组，正文补上以免误读为每输入帧独立对应一组视觉 token。
- 2.5 的动态 FPS 与绝对时间对齐 MRoPE、三阶段 1.5T/2T/0.6T、ViT 与 LLM 的训练冻结及 SFT/DPO 冻结 ViT，均与报告相应章节一致。发票图为原创情景，未伪称模型实测。
- Qwen3-VL 报告 2.1–2.3 节确认时空位置频带交错、三个视觉层分别经 Merger 加到语言模型前三层，以及每个视频时间 patch 前加文本时间戳。图是教学简化且注明省略对应融合器，未将 DeepStack 误画成多份复制文本。
- 报告第 5.9 节对 235B-A22B-Instruct 的视频评测限定 2048 帧与 224K token，VideoMMMU/MMVU 每帧 768 token，其余 640；Charades-STA 4fps、其他 2fps，对手输入帧预算不同；已补每帧预算。DeepStack 表 9 内部 15B-A2B、200B 预训练 token、未后训练，74.7→76.0 与 TVQA 80.6→80.5 均一致。
- 视频找针使用 1fps 均匀采样并动态调整分辨率维持视觉 token 预算；已补具体采样以区别第 5.9 节基准的 2fps/4fps。结果取决于指定合成插帧、位置和预算，不能代表任何真实视频。
- 两张原创 SVG 通过 XML 解析；未进行浏览器截图或模型计算验收。
