- **图示**：两张原创 SVG 都是多图、指令、生成与验收的教学流程，明确不代表逐层内部结构；2511 图也说明不是实际生成结果。XML 解析通过。没有发现须修正的事实性或图示错误，本次未修改两篇页面和配图。
