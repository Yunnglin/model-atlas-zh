# GPT-5 页面及配图独立复核

2026-10-28 对照 OpenAI 的 [2025 年发布说明](https://openai.com/index/introducing-gpt-5/)、[开发者发布说明](https://openai.com/index/introducing-gpt-5-for-developers/)及 [系统卡](https://openai.com/index/gpt-5-system-card/)，审阅模型页和原创流程图。

- **系统与 API**：官方将发布时的 ChatGPT 描述为快速模型、较深推理模型和实时路由器构成的系统；开发者文章区分 API 中的推理模型、`gpt-5-chat-latest` 非推理模型，并说明 minimal 推理不等于 ChatGPT 非推理模型。正文和图均明确针对发布时的系统，并不把这个路由器当作每个 API 调用自带的组件。
- **工具边界**：原文仅称请求是结构化请求、由外部系统或应用执行，表述过窄。开发者说明也介绍接收纯文本的 custom tools 与平台内建工具；现改为工具请求可以使用结构化参数，具体格式依工具类型，工具由应用或平台执行并返回结果。SVG 同步调整，避免误解所有工具只能由用户应用执行。流程图仍是概念示意，非内部网络结构。
- **模态和未知**：官方说明含图像相关理解与评测；本文不把视频评测等同于产品所有接口都原生输入视频或输出音频，也未对未公开层数、权重、专家结构做推断。
- **评测**：开发者文章列 GPT-5 high 的 AIME 2025 无工具 94.6%、SWE-bench Verified 74.9%、MMMU 84.2%；发布文章说明 SWE-bench 使用 n=477，开发者说明排除 23 个无法在其基础设施可靠通过的题，并对 GPT-5 使用强调充分验证的简短提示。正文已补充后两项，避免把结果当作全量统一协议。官方 45% 相对事实错误下降基于启用网页搜索及代表 ChatGPT 生产流量的匿名提示，正文保留其条件。
- **上下文**：发布时开发者页面列 272,000 输入、128,000 推理与输出、合计 400,000 token；页面限定为发布时 API 条件，没有外推至所有接口或当前版本。

核查是阅读官方公开资料与审阅图文，没有运行模型或复现评测。未修改共享资料表。
