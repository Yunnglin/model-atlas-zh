# Qwen2.5-1M 社区资料补查

核查日期：2026-10-28。本轮依据知乎检索技能使用独立有界面会话；既有站内搜索会话遇到安全验证。下面对知乎资料的阅读范围仅限搜索引擎缓存及其注明的公开原文，不能当作已阅读知乎原网页或验证了互动数。

## 可用于延伸评测的邻近资料

- [知乎：RHELM 长期记忆基准介绍](https://zhuanlan.zhihu.com/p/2045931027961586329)的搜索缓存提及在全上下文组使用 Qwen2.5-14B-Instruct-1M。原页面直接访问返回 403，作者、赞同与收藏数不可核验；缓存不是全文，不是该模型的架构或训练专篇，不能计为完整知乎交叉验证。
- [Microsoft Research 的同标题公开文章](https://www.microsoft.com/en-us/research/articles/%E5%BC%80%E6%BA%90%E4%B8%8A%E6%96%B0-%E5%A4%A7%E6%A8%A1%E5%9E%8B%E6%98%AF%E5%90%A6%E8%BF%98%E5%9C%A8%E9%87%91%E9%B1%BC%E8%AE%B0%E5%BF%86%EF%BC%9F%E5%85%A8%E6%96%B0%E5%9F%BA%E5%87%86-rhelm/)可读，列出 Qwen2.5-14B-Instruct-1M；与 [RHELM 论文 v2](https://arxiv.org/html/2605.31086v2)第 6.1 节和表 1 交叉核对，该模型确实是指定的长上下文评测模型之一。报告结果受数据集、模型、推理和评分协议限制；实验数据包含合成过程，不等同真实用户的完整业务表现。
- 文章把模型称为“原生支持百万级上下文”，这不足以说明百万 token 都用于训练。[Qwen 官方发布介绍](https://qwenlm.github.io/blog/qwen2.5-1m/)明确其最长训练序列为 256K，利用 Dual Chunk Attention 进行长度外推以处理更长上下文。知识库[对应正文](../../src/content/docs/nlp/qwen25-1m-model.md)已区分训练长度和推理外推，无需把模糊说法写成 1M 原生训练。
- 官方博客提供百万 token 上下文的特定推理框架加速结果及设备条件；不能以个别找针测试结果概括所有长文理解任务。RHELM 提供一个更偏跨时间、跨来源的后续评测线索，不证明每种长上下文部署方案或现实业务都达到该基准成绩。

## 结论与未完成范围

本次仍未核实模型对应知乎专篇的作者、赞同和收藏，也未验证原文配图；因此不改变[社区覆盖盘点](community-coverage.md)中的缺口分类。无法访问不代表相关知乎文章不存在。
