# Wan 视频生成图示核对（2026-10-29）

本次范围是 Wan2.1 文生视频和 Wan2.2 A14B / TI2V-5B 两张教学图的主要推理数据流及图文一致性；不代表对全部视频模型图逐项审校，也未运行模型。

- 对照 [Wan 论文第 4.2 节](https://arxiv.org/html/2503.20314)和正文，Wan2.1 使用 umT5 文本条件、流匹配形式的 DiT 与视频 VAE；推理从噪声出发反复更新潜变量，完成后解码。原图写了“多次更新”却只有一条向前箭头，现补充循环箭头和图内说明。
- 对照 [Wan2.2 官方仓库](https://github.com/Wan-Video/Wan2.2#introduction-of-wan22)，A14B 在高噪声和低噪声阶段分别使用专家，TI2V-5B 是独立模型。原图没有展示每个阶段的重复更新，现补充两个循环箭头；输出标签由“需要复核”改成“连续画面”。图示省略采样器和层内结构，箭头不表示 Transformer 本身单独执行数值求解。
