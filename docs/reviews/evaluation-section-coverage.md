# 评测章节覆盖与薄弱项检查

核查日期：2026-10-28。按时间线所引用的 96 篇独立文章检查，以二级标题包含“评测、评价、测试、比较、结果、指标或检验”为线索；96 篇均能匹配到至少一个相关章节。这是关键词筛查，不证明章节的内容一定充分、数字一定属于目标型号，也不能代替逐篇查证。

进一步检查了筛查中未出现数字的两个薄弱候选：

- [Stable Diffusion v1-4](../../src/content/docs/cv/stable-diffusion.md)原先说明 FID、CLIP 和自拟评测，但缺少本版本公开比较的具体条件。对照[v1-4 官方模型卡的 Evaluation Results](https://huggingface.co/CompVis/stable-diffusion-v1-4)，补充 COCO 2017 验证提示、样本量、分辨率、PLMS 步数及引导强度的边界。模型卡的比较未针对 FID 优化；不把这些条件泛化为所有场景，也不补猜数值。
- [初代 Claude](../../src/content/docs/nlp/claude.md)的“怎样检验对齐有没有帮上忙”说明了人类比较和相对 Elo，并区分论文的 52B 研究模型和首代 Claude；该章节原先未被仅搜索“评测”等词的规则识别。对照[Constitutional AI 论文](https://arxiv.org/abs/2212.08073)，保留研究与产品的边界，不能把论文研究模型的指标当作首代 Claude 产品成绩。

本轮没有逐一复算其余 94 篇的评测数据，也未运行模型；各版本的来源核对范围见已有系列审校记录。
