# 量化与蒸馏示例补充审校（2026-10-29）

范围：[量化](../../src/content/docs/training/quantization.md)的 GPTQ 新算例和[知识蒸馏](../../src/content/docs/training/distillation.md)的 Qwen3 新对照；本次不是全篇逐条重审，也未运行量化或训练。

- [GPTQ 论文第 3、4 节](https://arxiv.org/html/2210.17323)用校准输入衡量层输出的重建误差，通过二阶信息与分块更新补偿量化误差。正文新增的是人为构造的两个权重示例，验证 0.26+0.66=0.92，独立取整为 1.0，先补偿再取整为 0.9；此例不声称等同完整 GPTQ 算法，也不证明对所有输入更优。
- [Qwen3 技术报告表 21](https://arxiv.org/html/2505.09388)以相同离线蒸馏 Qwen3-8B 检查点作为起点，AIME 2024 为 55.0，继续在线蒸馏为 74.4；括号中的 pass@64 为 90.0 和 93.3。正文增补共同起点与多次采样指标说明，19.4 个百分点为算术差；报告的 GPU 小时仅对应该比较设置，不推断其他任务的成本。
