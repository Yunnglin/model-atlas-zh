# Qwen2.5-Omni 与 Qwen3-Omni 专项复核（2026-10-29）

本次对照两篇正文的主要结构、训练阶段与所引评测；官方报告分别为 [Qwen2.5-Omni v1](https://arxiv.org/html/2503.20215v1) 和 [Qwen3-Omni v1](https://arxiv.org/html/2509.17765v1)。未运行模型或复现论文结果。

- **结构**：2.5 的音视频按两秒分块交错，音频约 40 ms 一个表示，流匹配 DiT 结合 BigVGAN 输出声音；3 的时间位置按 80 ms 对齐，Talker 主骨干预测首个码本、MTP 自回归补齐余下码本、因果 ConvNet 输出波形。相关说法分别核对两篇报告 2.2–2.5 节。官方图和浏览器渲染检查沿用此前独立记录，见 [2.5 审校](qwen25-omni-full-review-20261029.md)与 [3 审校](qwen3-omni-full-review-20261029.md)，本次未重新截图。
- **训练**：对照 Qwen3 报告 4.1 节，正文新增离策略教师回答与在策略学生回答的区别：后者在学生生成的上下文中对齐师生预测分布（KL），随后才是 GSPO 奖励优化。红杯子的例子是教学构造，不是论文实验。
- **评测**：对照 Qwen2.5 表 2，增加 LibriSpeech test-clean/test-other 的词错误率，Qwen2.5-Omni-7B 为 1.8%/3.4%，Whisper-large-v3 为 1.8%/3.6%；这是识别指标，不代表语义理解或其他数据集表现。Qwen3 表 11 的 WorldSense 54.0/45.4 及表 2 的理论首包延迟与正文一致。
- **社区材料**：沿用上述两篇记录中的知乎实读与官方对照，本轮未重复读取或将教学例子归于社区作者。

验证：两篇正文的 Prettier 检查、内容测试（7 项）与 `git diff --check` 通过。
