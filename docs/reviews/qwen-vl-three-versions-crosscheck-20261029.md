# Qwen-VL 三代训练与评测核对（2026-10-29）

范围：[Qwen-VL 初代](../../src/content/docs/omni/qwen-vl-first-model.md)、[Qwen2-VL](../../src/content/docs/omni/qwen2-vl-model.md)和 [Qwen2.5-VL](../../src/content/docs/omni/qwen-vl.md) 的模型卡、训练及部分评测口径。本次未运行模型、复现评测或重新实读知乎。

- 对照[初代论文第 3 节与附录 C、E.1](https://arxiv.org/html/2308.12966v3)：第一阶段冻结 LLM、训练视觉编码器和适配器，图文对批量 30,720、50,000 步；来源表的 14 亿与训练消耗约 15 亿均为近似值。附录 E.1 称图片只训练一遍，因此修正了正文中可能暗示重复训练的描述，不能仅凭两个取整数值之差推断重复。
- 对照 [Qwen2-VL 报告第 2.2 节](https://arxiv.org/html/2409.12191v2)：报告列出两个预训练阶段约 6000 亿与 8000 亿 token、累计约 1.4 万亿；统计包括视觉 token，监督为文本 token，正文与其一致。三阶段的冻结和解冻对象也与报告一致。
- 对照 [Qwen2.5-VL 报告 2.3 和表 5](https://arxiv.org/html/2502.13923v1)：SFT 样本约 200 万条，按条数分为一半纯文本、一半多模态；多模态样本的 token 消耗可更大。DPO 阶段为图文与纯文本偏好数据，ViT 在两阶段冻结。正文补充这些差别。DocVQA 与 OCRBench 的三种规格数字与表 5 一致，不将不同基准分数直接比较。
- 本次仅复核以上具体项目，不意味着逐项验证全部模型卡字段或所有评测。历史社区参考与配图审校见各模型此前的专项记录。
