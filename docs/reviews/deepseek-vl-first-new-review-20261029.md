# DeepSeek-VL 初代新增核查（2026-10-29）

对象是 2024 年 3 月 11 日发布的 DeepSeek-VL，而非后续的 DeepSeek-VL2。正文为 [deepseek-vl-first-model.md](../../src/content/docs/omni/deepseek-vl-first-model.md)，教学图为 [overview.svg](../../public/figures/deepseek-vl-first/overview.svg)。

- **结构**：根据 [论文 v2 的 3.1 节和表 4](https://arxiv.org/html/2403.05525v2)，7B 使用 SigLIP-L 与 SAM-B，融合对齐后的 576 个位置，每位置沿特征维拼接；1.3B 只使用 SigLIP。图和正文都明确此版本区别，图为原创教学示意，省略内部层次。
- **训练**：对照论文 3.2 节：第一阶段冻结视觉编码器和语言模型，仅训适配器；第二阶段冻结视觉编码器，优化语言模型和适配器；第三阶段 7B 训练 SigLIP、适配器和语言模型，SAM-B 冻结。第一阶段是 125 万图文对与 250 万 OCR 对；联合训练最终语言∶多模态比例约 7∶3。正文的商品问题、验证集和错误分析为构造例子。
- **评测**：论文表 5、6 的 7B/1.3B MMBench 开发集分别 73.2/64.6、OCRBench 分别 456/409；表 7 的 HellaSwag 68.4/68.5、GSM8K 55.0/63.0 是论文对 VL-7B Chat 与 DeepSeek-LLM-7B Chat 的对比。区分生成解析和候选困惑度评测，未实际复现。
- **社区**：2026-10-29 登录知乎检索“DeepSeek-VL 架构”，搜索结果比较了不同版本，实读[深度眸的初代解析](https://zhuanlan.zhihu.com/p/686852476)，页面显示 50 赞、62 收藏。文章准确描述 SigLIP 与 SAM 特征按通道拼接及三阶段训练；其将 ShareGPT4V 第一阶段数据写成 1.25 亿有误，论文 3.2.1 节是 125 万，评论亦指出数量问题，正文采用论文数字。文章“无损语言能力”的概括过强，论文表 7 的 GSM8K 有下降，因此正文列出相应对照。
