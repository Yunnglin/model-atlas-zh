# GLM-4.5、4.6、4.7 版本口径复核（2026-10-29）

范围：对照 [GLM-4.5 技术报告 v1](https://arxiv.org/html/2508.06471v1)、[4.6 官方模型卡](https://huggingface.co/zai-org/GLM-4.6)与 [4.7 官方模型卡](https://huggingface.co/zai-org/GLM-4.7)，核对三篇正文中的版本、训练信息与代表性评测。本次没有运行模型、复现评测或重新阅读知乎内容。

- **4.5**：报告摘要及表 1 对应 355B 总参数、32B 激活参数及 23T 多阶段训练；355B 参数统计包含 MTP，不包含词嵌入和输出层。报告所列 91.0 AIME 2024、64.2 SWE-bench Verified、70.1 TAU-Bench 与正文一致；这些信息没有迁移成 4.6 或 4.7 的新增训练配方。
- **4.6**：官方模型卡列出 200K 上下文、与 4.5 相同的推理方法，并给出通用评测 temperature 1.0、部分代码任务 top-p 0.95 和 top-k 40 的建议。卡片引用 4.5 报告，不能因此认定 4.6 的新增训练数据或阶段配比相同。
- **4.7**：模型卡主表中 SWE-bench Verified 为 73.8、Multilingual 为 66.7、Terminal Bench 2.0 为 41.0，4.6 分别为 68.0、53.8、24.5；表中 τ²-Bench 为 87.4 与 75.2。本轮增加 τ²-Bench 的任务与协议说明：卡片建议 temperature 0、最大新 token 16,384，并说明零售和电信领域的用户提示调整、航空领域的环境修正。上述 41.0 是模型卡正文主表数值，不将页面自动汇总的其他测评项视为相同实验。
- **图示与社区**：沿用各自的既有专项记录；本轮未重新核验图示或社区文章，也不把一般训练示例写成 4.6/4.7 的官方新增配方。
