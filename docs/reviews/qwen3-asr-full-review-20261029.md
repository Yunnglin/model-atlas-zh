# Qwen3-ASR 全维度审阅

审阅日期：2026-10-29。范围为 `src/content/docs/audio/qwen-asr.md` 中 Qwen3-ASR 0.6B、1.7B 和有关 ForcedAligner 的介绍；不代替对 ForcedAligner 独立页面的审阅。没有运行模型或复现基准。

## 结构与模型卡

- [官方报告 v1 第 2 节及表 1](https://arxiv.org/html/2601.21337v1)：128 维 Fbank、8 倍下采样与 12.5Hz，AuT 输出经投影接 Qwen3；1.7B 与 0.6B 分别使用约 300M 和 180M AuT。支持离线、流式及单条最长 1200 秒音频。图左为 AuT 编码器—解码器预训练，右为识别模型；原图右侧未单独展示投影层，正文写出。
- 模型卡链接的 [0.6B](https://huggingface.co/Qwen/Qwen3-ASR-0.6B) 和 [1.7B](https://huggingface.co/Qwen/Qwen3-ASR-1.7B) 开放权重，均标注 Apache 2.0。任务输出与音频理解、语音生成以及对齐器区分。

## 训练

- 报告第 2.2 节：AuT 预训练、Omni 预训练、ASR SFT、GSPO 强化学习；ASR 模型以转写为目标，支持提供上下文。报告第 3 节：对齐器用 MFA 伪标签及时间槽训练，伪标签存在噪声；正文没有把其时间步长当作保证误差。
- 专名偏置、静音及背景噪声测试是业务教学例子；未声称实际跑过。

## 评测

- 报告表 5 列 Fleurs†† Qwen3-ASR-1.7B 12.60、Whisper-large-v3 8.16，第 4.1 节说明按语言选 WER / CER 并按语言宏平均。按报告附录表 A.2 所列 30 个 1.7B 数字直接求平均为约 12.2417%，而表 5 写 12.60%；两处不能直接复算一致，原因未在报告解释，正文已指出表来源及差异。
- 表 8 的 1.7B 英文离线／流式 3.35／4.02、中文 2.41／2.84；流式条件为 2 秒分块、5 token fallback 和最近 4 块未固定。表 2 0.6B 在线并发 1／128 的首 token 均值 92／3210 ms、P95 105／6195 ms、吞吐 106.38／2000；报告仅描述单个常见计算资源，未给型号。正文区分吞吐、首 token 与最终稳定延迟。
- `打开客厅灯` 五字漏一字 CER 20%；假设专名偏置对 100 条正例和 100 条负例的召回与误插算例也已核算。以上是教学数据而非实测。

### 2026-10-29 评测数字逐项复核

- 对照 [Qwen3-ASR Technical Report 表 5 和附录 A.2](https://arxiv.org/html/2601.21337)：Fleurs 30 语言的表 5 汇总值为 1.7B 12.60%、Whisper-large-v3 8.16%；正文保留了其与附录 30 个逐语言数值直接平均约 12.24% 不一致的说明，不能把两项视为同一已核实结果。
- 对照[表 8](https://arxiv.org/html/2601.21337#S4.T8)：1.7B 的英文离线／流式为 3.35／4.02，中文为 2.41／2.84；已补入 2 秒分块、回退 5 个 token 和最后四块未固定的流式设置。
- 对照[表 2](https://arxiv.org/html/2601.21337#S2.T2)：0.6B 在线异步并发 1 的首 token 均值／P95 为 92／105 毫秒、吞吐 106.38；并发 128 为 3210／6195 毫秒、吞吐 2000。约两分钟音频、vLLM 0.14.0、BF16、CUDA Graph 均见报告；报告未给出表中硬件具体型号。
- 范围为正文评测和性能数字及其协议；未重跑模型，未解释报告内部平均值差异的成因。
