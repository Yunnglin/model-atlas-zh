# DiT 专项审校

审校日期：2026-10-29。范围为[原始 DiT 正文](../../src/content/docs/cv/dit.md)；完整通读并对照原论文和官方代码，未训练模型或复现评测。犬种生成和错误分析为教学方案。

- **结构**：对照[论文第 3 节及表 1](https://arxiv.org/html/2212.09748)和[官方代码](https://github.com/facebookresearch/DiT/blob/main/models.py)，核对潜空间 patch、时间及类别条件、adaLN-Zero 残差初始化和 XL/2 的 28 层。论文表 4 的 675M 为骨干参数，VAE 编解码器另计 84M；图像类别条件不等于任意文本提示。
- **训练**：核对论文第 4 节、附录 A 及官方代码的类别丢弃、AdamW 与 ImageNet 设置；本次补充实现默认 10% 类别丢弃和 CFG 的直观说明。潜空间加噪公式是简化示意，原模型另预测方差且含相应损失。官方仓库的代码及模型许可为 CC-BY-NC，VAE 另有许可。
- **评测**：论文表 4 的 40 万步、无引导、ft-MSE 解码器下 XL/4 和 XL/2 的 Gflops/FID 数值经核对；表 2 的 700 万步 256×256、250 步采样、ft-EMA 和 CFG 1.5 的 2.27 与无引导 9.62 口径经核对。正文补充训练步数差异、对应 Recall 0.67/0.57，避免把 40 万步与 700 万步指标当成仅引导不同的对照；FID 是集合统计量。
- **配图**：查看[图示登记](../../src/content/data/figures.yaml)及[原创教学图](../../public/figures/dit/overview.svg)；随机潜噪声、分块、条件去噪、采样循环和解码方向与论文简化流程一致，注明来源、CC BY 4.0 和非官方图。Chromium 本地正文滚动至图片后确认解码成功、1060×260、替代文本存在，并截图检查标签和连线。
- **社区**：2026-10-29 在已登录浏览器实读大师兄的 [DiT 详解](https://zhuanlan.zhihu.com/p/683612528)，显示 425 赞同、739 收藏。文章结合源码解释 patchify、时间与类别条件和 adaLN-Zero：时间与类别向量相加后产生归一化和残差门控参数；官方 `models.py` 的 `c = t + y` 与零初始化实现支持这一流程。文章称 FID 为零意味着两组图片完全相同，这一解释过强：FID 比较特征统计，不能证明图片逐张一致；正文按集合统计解释。文章开头关联 Sora，也不能据此推断未公开的具体实现。另补充 2×2 与 4×4 patch 的具体位置数对照，说明注意力位置对与整网 FLOPs 的区别。
