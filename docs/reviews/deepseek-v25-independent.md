# DeepSeek-V2.5 正文及配图复核

复核日期：2026-10-28。范围为独立模型页和原创示意图；依据官方模型卡、配置、仓库提交和 V2 论文。未重跑模型或独立复现评测。

- **时间与定位**：[官方仓库提交](https://huggingface.co/deepseek-ai/DeepSeek-V2.5/commits/main)显示 2024-09-05 上传；[模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V2.5)说明结合 V2-Chat 与 Coder-V2-Instruct 的能力，并未披露权重合并算法，正文保留此边界。
- **结构**：[配置](https://huggingface.co/deepseek-ai/DeepSeek-V2.5/blob/main/config.json)列出 60 层、5120 隐藏维度、128 注意力头、首层稠密、160 路由专家、2 共享专家、每 token 选 6 个、163840 最大位置。V2 [论文](https://arxiv.org/html/2405.04434)第 2 节及 3.1.2 节解释 MLA、MoE 和初代规模；不能从位置配置直接证明任意部署达到同等有效上下文。正文对这些边界的描述与资料一致。
- **训练**：V2 论文第 1、3、4 节介绍初代 8.1T 预训练 token、SFT 与 RL；V2.5 模型卡未给出完整的更新训练配方。正文已将初代结果与 V2.5 区分，没有把案例当作训练记录。
- **评测**：模型卡中的 HumanEval Python 84.5/87.2/89、LiveCodeBench 36.6/39.7/41.8，以及 SWE-verified Coder V2 19 对 V2.5 16.8 与正文一致。模型卡未逐项完整披露采样预算，故正文不声称独立复现或跨报告可直接比较。
- **许可**：模型卡说明代码仓库为 MIT、模型使用受 Model License 约束，V2 系列支持商业使用。正文模型卡此前只说两者不同，现补充具体许可与商业使用说明，仍需以许可原文为准。
- **配图**：原图用顺序箭头将“回答 / 代码 / 工具请求”全部导向外部执行，可能让读者误以为普通回答也需要工具运行。现标明外部执行可选，并明确回答可直接交给用户；保留“原创教学示意”和省略架构细节的标识。图是任务流程，不能作为逐层架构图或官方原图。
