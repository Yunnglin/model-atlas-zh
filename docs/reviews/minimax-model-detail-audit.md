# MiniMax 模型正文核对

核对日期：2026-10-28。本轮按时间线中的六个独立型号，检查模型卡、代表性的结构和评测数字以及公开训练信息；并非逐句核实全文，也未运行模型或复现评测。参数、版本和实验条件以相应官方模型卡或配置为准。

| 页面                                                                 | 核对范围与官方依据                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [M2](../../src/content/docs/nlp/minimax-m2-model.md)                 | [模型卡](https://huggingface.co/MiniMaxAI/MiniMax-M2)给出 SWE-bench Verified 69.4 和 Terminal-Bench 46.3，前者使用指定 OpenHands 脚手架、128K 和最多 100 步，后者为 8 次平均；模型卡许可标记 modified-MIT。                                                                                                             |
| [M2.1](../../src/content/docs/nlp/minimax-m21-model.md)              | [配置](https://huggingface.co/MiniMaxAI/MiniMax-M2.1/raw/main/config.json)列出 62 层、256 专家选 8、48 个查询头和 8 个 KV 头；[模型卡](https://huggingface.co/MiniMaxAI/MiniMax-M2.1)给出 SWE-bench Verified 74.0 和官方 VIBE 平均 88.6，已注明评测方法。                                                               |
| [M2.5](../../src/content/docs/nlp/minimax-m25-model.md)              | [模型卡](https://huggingface.co/MiniMaxAI/MiniMax-M2.5)给出 SWE-bench Verified 80.2、Multi-SWE-Bench 51.3、带上下文管理的 BrowseComp 76.3；官方报告平均耗时从 31.3 分钟降至 22.8 分钟。正文已补充：时间降低约 27%，速度按耗时比的倒数提高约 37%，分母不同。                                                             |
| [M2.7](../../src/content/docs/nlp/minimax-m27-model.md)              | [模型卡](https://huggingface.co/MiniMaxAI/MiniMax-M2.7)列出 SWE-Pro 56.22、VIBE-Pro 55.6、Terminal Bench 2 57.0；[发布说明](https://www.minimax.io/news/minimax-m27-en)称 22 项 MLE Bench Lite 任务进行三次、每次 24 小时，平均获奖率 66.6%。该数字依赖其运行条件。                                                     |
| [M3](../../src/content/docs/omni/minimax-m3-model.md)                | [模型卡](https://huggingface.co/MiniMaxAI/MiniMax-M3)列约 428B 总参数、23B 激活和 1M 上下文；[官方配置](https://huggingface.co/MiniMaxAI/MiniMax-M3/raw/main/config.json)列 60 层、128 专家选 4 和 1 个共享专家；[发布说明](https://www.minimax.io/blog/minimax-m3)给出 SWE-Bench Pro 59.0%、Terminal-Bench 2.1 66.0%。 |
| [M3.1 Flash](../../src/content/docs/omni/minimax-m31-flash-model.md) | [模型卡](https://huggingface.co/MiniMaxAI/MiniMax-M3.1-Flash)说明所有层稀疏注意力、部分路径量化感知训练、DSpark，以及 DeepSWE 73.7 和指定脚手架；公开结果不是独立复测。模型卡称该权重基于 428B／23B 模型，未据页面自动张量统计自行推断完整参数。                                                                        |

上述官方评测结果不是统一条件下的横向排行榜；使用不同数据集、工具脚手架和上下文限制时不能直接比较。未覆盖模型训练数据的完整来源与各项超参数，公开资料没有给出的内容不予猜测。
