# ViT 分类图数据流补充核查（2026-10-29）

对照 [ViT 原论文第 3.1 节](https://arxiv.org/html/2010.11929#S3.SS1)：模型在图块序列前加入可学习的分类 token，编码器输出中取该 token 对应的表示，再送入分类头。原教学图把编码器直接连到分类头，省略了读取分类 token 这一关键步骤，容易让读者以为分类头直接处理完整图块序列。

已在 `public/figures/vit/overview.svg` 标出“取分类 token”，并同步更新图内说明和 `src/content/data/figures.yaml` 的替代文本。配图仍为简化图，不展示位置编码及层内每个操作的全部细节。

使用 Chromium 加载更新后的 SVG 并检查截图，文字和箭头均可见。图示相关单元测试 2 个文件、7 项通过；未训练模型或复现评测。
