# 原始 Transformer 全维度审阅

审阅日期：2026-10-29。对象为 `src/content/docs/foundations/transformer.md` 和 `transformer-teaching`，限定 2017 年原始编码器—解码器架构；没有运行训练或复现翻译分数。

## 结构

- [原论文第 3 节及表 3](https://arxiv.org/html/1706.03762)：base 编码器与解码器各 6 层、宽度 512、8 头、前馈中间宽度 2048；表 3 为 base 65M、big 213M 参数。输入、掩码自注意力、交叉注意力和词表投影的顺序与正文一致。Q、K、V 加权算例和 `16 / sqrt(64) = 2` 核算正确。
- 论文第 3.2.3 节：交叉注意力的查询来自解码器，键和值来自编码器输出。正文明确解码器块中自注意力先于交叉注意力，避免将最后词表投影误写为每层输出。

## 训练

- 论文第 5 节：WMT 2014 英德约 450 万对句子；模型训练为目标序列右移及掩码下预测，使用标签平滑；base 8 块 P100 约 12 小时、big 约 3.5 天。两句翻译、教师强制和标签右移是教学例子，不是论文运行。
- 检查训练与生成的区别、padding 与因果 mask 的职责、长度和算力范围；正文没有将这些设置套用到后续所有模型。

## 评测和应用

- 论文第 6.1 节和表 2：英德 newstest2014 大模型 BLEU 28.4；大模型平均最后 20 个检查点，束宽 4、长度惩罚 0.6。正文没有把 BLEU 当作句子正确率，也没有把参数平均说成 20 个模型分别推理。
- 客服翻译中 16/20、15/20 分别为 80%、75%；样本是说明方法的假设。主客体和否定的分析属于补充检查，不能由 BLEU 数值直接推出。
