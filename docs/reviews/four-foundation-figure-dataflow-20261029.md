# 四张基础模型图的数据流抽查（2026-10-29）

本次阅读四张教学 SVG 的图中文字、箭头和无障碍描述，按各自原论文核对指定的数据流；这不代表对其对应正文逐句终审，也未运行模型。

- **BERT**：[论文第 3 节](https://arxiv.org/html/1810.04805)说明双向编码器、`[CLS]` 用于分类及逐 token 表示用于标注或问答，原图对应该概括；图下注明原始预训练的遮盖预测和下一句预测。
- **CLIP**：[论文 2.3 节](https://arxiv.org/html/2103.00020)的图像与文本双编码器、批内相似度及双向对比损失，与图示相符；图中一对猫图文是简化展示，图下注明训练还比较批内其他配对。
- **ViT**：[论文 3.1 节](https://arxiv.org/html/2010.11929)描述图块投影、位置嵌入、分类 token 和编码器；图中的 224×224 图片与 16×16 图块得到 196 块，连同分类 token 为 197，算术正确。
- **wav2vec 2.0**：[论文第 2、3 节](https://arxiv.org/html/2006.11477)区分遮盖上下文分支与未遮盖特征的量化目标分支；识别微调在上下文网络上添加线性分类层，以 CTC 损失训练。原图将识别过程简写为“CTC 输出文字”，现补上线性层及解码过程，以免把训练损失当作直接出字的网络层。Chromium 实际渲染更新后的 SVG 并检查文字未截断；前三图本次检查 SVG 内容和箭头，未重新截图。
