# Llama 3 与 Llama 4 独立复核

2026-10-28 对照 [Llama 3 发布说明](https://ai.meta.com/blog/meta-llama-3/)、[Llama 3 模型卡](https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct)、[Llama 4 发布说明](https://ai.meta.com/blog/llama-4-multimodal-intelligence/)及 [Llama 4 模型卡](https://huggingface.co/meta-llama/Llama-4-Scout-17B-16E-Instruct)，审阅正文和原创示意图。

- **Llama 3 首版**：8B/70B、8,192 token、两种规格使用 GQA、128K 词表及超过 15T 的预训练 token 与首发说明一致。发布说明指出非英语数据覆盖 30 多种语言但不保证与英语表现相当；模型卡将英语列为支持语言。正文没有将后来的 3.1 405B 和 128K 算进首版。模型卡的 MMLU 5-shot 基础版 66.6/79.5、指令版 68.4/82.0，HumanEval 0-shot 指令版 62.2/81.7 与正文一致。
- **Llama 4 模型与模态**：官方列 Scout 16 专家、Maverick 128 专家、均约 17B 激活；模型卡列预训练 40T/22T token、最大窗口 10M/1M、图像与文本输入、文本输出，并仅在最多 5 张图上测试图像理解。正文区分能力上限、服务实际配置及有效检索质量，没有推断图像输出或音频能力。
- **中文边界修正**：官方模型卡的 12 种支持语言不含中文，并将超出明确支持范围的语言或能力使用列为范围外；另明确允许开发者在遵守许可和使用政策的条件下针对其他语言微调，并承担安全责任。原文仅说自行评估，容易弱化官方范围限定；现补充这两条并保留中文需独立测试的说明。
- **评测与许可**：模型卡的指令版 ChartQA 88.8/90.0 和 DocVQA 94.4/94.4 与正文一致，不能同预训练版数字混用。官方注明相关模型卡评测以 BF16 为准，Scout INT4 单 H100 与 Maverick FP8 单 H100 DGX 主机是限定设备与量化条件。两代各自使用社区许可，不等于 Apache 2.0。
- **配图**：Llama 3 图明确分组头数量为示意；Llama 4 图标明仅展示图文输入与专家路由概念而非逐层结构，外部核验不属于模型内部。两幅 SVG XML 解析通过。

本次是公开资料和静态图文复核，没有运行模型、测中文效果或复现基准；未修改共享数据表。
