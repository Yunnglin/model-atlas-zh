# Wan2.2 独立复核

核查日期：2026-10-28。对照 [Wan2.2 官方仓库](https://github.com/Wan-Video/Wan2.2)、[T2V-A14B 模型卡](https://huggingface.co/Wan-AI/Wan2.2-T2V-A14B)与 [TI2V-5B 模型卡](https://huggingface.co/Wan-AI/Wan2.2-TI2V-5B)复核正文与教学图。

- **专家与参数**：官方称高噪声阶段使用高噪声专家、后期使用低噪声专家，切换由去噪时间阈值决定；每位约 14B，合计约 27B，每步约 14B 激活。文中将两者描述成处理同一状态的顺序过程，与官方描述一致，且提醒整体布局与细节分工是概括而非严格隔离。SVG 明确是简图，不宣称展示内部层。
- **独立 5B**：官方称 TI2V 为 5B 稠密模型，VAE 压缩为 4×16×16，叠加 patchification 后为 4×32×32，支持同一模型的文字或图像条件；720P/24fps 为输出规格。正文未把它误写成 A14B 的专家或实际生成吞吐。
- **训练**：仓库给出相对 Wan2.1 图像与视频训练数据增长率及美学标注方向，但没有在上述材料提供足以复现全部训练的细节；本文保留该限制。仓库引用的 2503.20314 是先前 Wan 技术报告，不能当作专门的 Wan2.2 完整训练报告。
- **评测**：模型卡展示四组专家验证损失及 Wan-Bench 2.0 的官方比较，公开摘要不足以支持对任意场景效果作结论；正文明确验证损失不是人类偏好分数，也不将早期 Wan 论文 VBench 数值移用到 2.2。
- **补充范围**：官方仓库还列有 S2V-14B 与 Animate-14B；原文的重点是 A14B 和 TI2V-5B，已在开头补充其他分支及本篇范围，避免读者以为这三个检查点穷尽整个系列。
- **许可与验证**：本页指向的两个模型卡和仓库显示 Apache 2.0；具体依赖及其他检查点仍需分别核对。本次只检查公开资料与图文，不表示执行了生成、性能测试或视觉质量评估。
