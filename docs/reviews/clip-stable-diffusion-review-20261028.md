# CLIP 与 Stable Diffusion 资料核查

核查时间：2026-10-28。本轮检查模型卡、文章中的特定结构与评测数据，并在 Chromium 中渲染检查两个本地教学图；不等于全文逐句审校或实际运行模型。

## CLIP

- 对照 [CLIP 原论文](https://arxiv.org/html/2103.00020)第 2.5 节及附录表 11、20：32,768 图文对批量、32 轮训练，以及 ViT-B/32 和 ViT-L/14-336px 的 ImageNet 零样本 top-1 分别为 63.2% 和 76.2%。两种模型的骨干和输入大小不同；对照用于说明型号差异，不进行单因素归因。
- 对照[官方配置](https://huggingface.co/openai/clip-vit-base-patch32/blob/main/config.json)，确认 ViT-B/32 的 224 像素输入、32 像素图块、512 维投影和 77 文本位置。教学图只画一对图文，并标注训练需要同批其他配对；渲染时文字和连线可辨。
- 本轮未重新核查所有中文社区文章、资产之外的许可或各数据集完整指标。

## Stable Diffusion v1-4

- 对照 [v1-4 模型卡](https://huggingface.co/CompVis/stable-diffusion-v1-4)：v1-4 从 v1-2 继续训练 225,000 步，图像为 512×512，10% 训练条件丢弃；模型卡的对照评测使用 COCO 2017 验证集 10,000 条提示、50 步 PLMS 和多个引导尺度。
- 对照模型卡及 [LDM 论文](https://arxiv.org/abs/2112.10752)：文本编码器提供条件，去噪在潜空间进行，最终由解码器得到图片。本地教学图展示生成流程，训练端加噪未展开；在 Chromium 中检查了文字与连线。
- 新增的 786,432 与 16,384 数值个数是按 512×512×3 和 64×64×4 所作的算术例子，并非文件压缩率或性能实测。未进行训练、推理、FID 重算或设备性能验证。
