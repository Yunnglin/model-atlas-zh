# Qwen-VLA 专项审校

审校日期：2026-10-29。通读 [Qwen-VLA 正文](../../src/content/docs/omni/qwen-vla-model.md)，范围为技术报告 v2；没有运行机器人、训练或复现评测。

- **结构**：对照[报告第 2 节](https://arxiv.org/html/2605.30280v2)核对 Qwen3.5-4B 骨干、约 1.15B/16 块动作专家、视觉文本条件、连续动作及 16 步操作片段。动作通道、填零与有效掩码按控制约定区别；补充每通道先按有效时间求平均、再按通道平均的损失计算。抓杯例子为教学构造。
- **训练**：对照报告第 3、4 节及表 1 核对预训练数据混合、T2A/CPT/SFT/RL 阶段及多任务损失权重。PPO、GAE 和流匹配去噪步骤加噪的解释依报告，不能把它当作语言模型的偏好训练；真实平台示范微调与仿真训练分开。
- **评测**：核对报告表 4、6、11 的仿真成功率、SFT/RL 阶段与 ALOHA 真机 OOD 76.9；真机使用 Base 加 ALOHA 示范微调，不把结果当成 Instruct 零样本。任务成功率、轨迹误差和未见条件分别说明。
- **配图**：对照[图示登记](../../src/content/data/figures.yaml)与[原创教学图](../../public/figures/qwen-vla/overview.svg)，视觉语言骨干、动作专家和外部机器人执行、再次观察的方向一致，图明确非逐层网络图，来源和 CC BY 4.0 已登记。Chromium 本地正文滚动后图片解码成功、宽 1200，替代文本存在；截图检查中文和箭头。
- **社区**：2026-10-29 主审通过已登录 Chrome 实读周熙钦的 [Qwen-VLA 回答](https://www.zhihu.com/question/1957266460750620169/answer/2045631592522163735)，当时 134 赞、283 收藏。文章讲 Qwen3.5-4B 视觉语言骨干、DiT 动作解码、本体提示与分阶段训练；对照论文第 2–4 节核查这些概念，文中“保证物理合理性”的说法过强，正文依据具体仿真与真机实验描述。回答标有 AI 辅助创作，不作为独立复现实验。

- **补充核对**：对照[报告第 4.2 节](https://arxiv.org/html/2605.30280v2)，正文解释 16 步动作片段级优势估计以及价值头入口的梯度截断；这不意味着整个骨干被冻结。抓杯过程为教学例子，未运行策略。
