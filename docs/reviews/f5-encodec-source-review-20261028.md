# F5-TTS 与 EnCodec 重点核查

核对日期：2026-10-28。本次核查模型卡、部分结构描述、训练和评测的具体事实；并用 Chromium 渲染两张教学图，检查信息流与可读性。未运行模型或重新实读知乎文章。

- **F5-TTS**：按[原论文第 4 节及表 1](https://arxiv.org/html/2410.06885)补充 base 335.8M 与 small 158M 参数、base 使用的约 9.5 万小时英语和中文数据、24 kHz / 256 hop 的声学帧算例，以及 LibriSpeech-PC test-clean 的 16 / 32 NFE 结果。前者是论文实验设置，不代表所有仓库版本。图中说明参考文本与待合成文本、参考梅尔谱共同为 DiT 提供条件，并标注积分多次调用模型；按论文图 1 和第 3 节检查。
- **EnCodec**：对照[原论文第 3–4 节和表 1](https://arxiv.org/html/2210.13438)区分 24 kHz 多领域单声道与 48 kHz 音乐立体声训练数据，补充多目标损失平衡器不包含量化承诺损失，并给出 6 kbps 的 MUSHRA 对照及听测样本设置。图中编码、残差量化、解码及可选熵编码的关系与论文一致。
- 权利声明按 F5-TTS [代码仓库](https://github.com/SWivid/F5-TTS)与[权重页](https://huggingface.co/SWivid/F5-TTS)分别说明。EnCodec 的 24 kHz 模型页面未显示明确许可元数据，正文保留代码与权重条款分别检查的表述。

本次未验证所有训练超参数、所有语言及全部外链，也未对任何主观分数或推理速度进行复现实验。
