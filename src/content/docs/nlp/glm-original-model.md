## 它要解决什么问题？

想象一句话：“小林带了伞，因为天气预报说今天会下雨。”如果把“天气预报说”挖掉，让模型补上，模型需要同时利用前面的“带了伞”和后面的“今天会下雨”。但缺失部分可能不止一个词，也不能事先假设空格一定有多长。

原始 GLM 的思路是：先把文本中若干连续片段挖掉，再让模型利用保留下来的上下文，像写句子一样逐个 token 填回每个空。研究者希望同一个预训练框架能服务自然语言理解与文本生成。它是训练框架及一组模型的研究，不能等同于后来面向聊天的 ChatGLM 产品或最新 GLM 系列模型。下文例子为教学构造，并非论文原始数据。

## 结构与数据流：一张试卷分两部分

原句可以挖成：“小林带了伞，因为 [MASK] 今天会下雨。”保留下来的文字和空位标记组成 **Part A**。被挖掉的内容放到 **Part B** 作为生成目标，模型从对应空位的开始标记出发，依次生成“天气”“预报”“说”，并在适当位置结束。实际 token 切分由分词器决定，这里用词语帮助理解，不是宣称每个词恰好是一个 token。

如果有两个空，训练时可以把空白片段的生成顺序打乱。例如原文中第一个空在“伞”的附近，第二个空在“天气”的附近；模型这次可能先恢复第二个空，再恢复第一个。每次填空时，它可以参考已保留的上下文和按当前顺序已经生成的片段，而不能偷看后续还未生成的答案。空之间的顺序可随机改变，**每个空内部仍按顺序逐 token 生成**。

### 混合注意力：谁可以看谁？

GLM 使用一个共享参数的 Transformer，通过[注意力掩码](/foundations/attention/)控制不同位置能看到哪些信息：Part A 的保留内容相互可见，但不能看 Part B 的答案；Part B 的当前位置能看 Part A 和此前已生成的内容，不能看到未来的目标 token。训练时有完整答案用于计算损失，但掩码保证预测当前位置时不能提前读取后面的答案。

这不等同于把两个独立网络简单拼起来。单一骨干配合不同可见性，让上下文部分具备双向读取能力，让答案部分按自回归方式生成。也不意味着模型能看到空白本身的真实答案：双向可见的是保留的上下文。关于基础结构，可先看 [Transformer](/foundations/transformer/) 和[编码器与解码器](/foundations/encoder-decoder/)。

### 二维位置编码：知道填哪个空，也知道填到第几步

填空顺序被打乱后，仅知道生成序列中的位置不够：模型还需要知道当前答案属于原文里的哪个空。GLM 为 token 使用两个位置编号：第一维对应挖空后文本中的位置；生成的片段对应它所在的 `[MASK]` 位置。第二维标记片段内部的步数；Part A 的这一维为 0，Part B 的位置在片段内部递增。

比如一个空在挖空后文本的位置 5，那么从该空开始生成的片段会共享第一维位置 5；片段内后续输入的第二维按 1、2、3 等变化。这样可以区分“这是哪个空”和“填到这个空的哪一步”。这里的数字是示意，特殊标记和位置起点应以论文及具体实现为准。一个空位只用一个掩码标记，不会直接暴露原片段有几个 token；真实生成也可以在输出结束标记前逐步决定长度。

这两个编号不是直接拿数字相加：论文分别用两张可学习的位置向量表查出对应向量，再与 token 的向量相加。可以把第一张表理解为“找到原文的哪一道题”，第二张表理解为“这道题写到第几步”；它们随着训练一起更新。

## 数据与训练：同一种填空，不同空的长度

论文中的 GLM-Base 和 GLM-Large 采用与 BERT 对照相近的英文 Wikipedia、BookCorpus 数据与词表；为对比其他模型，还训练了采用较大语料的 GLM-RoBERTa。论文附录介绍该设置使用约 158GB 未压缩文本，并解释数据来源与替代；**158GB 对应这个设置，不是所有 GLM 版本的数据规模**。官方仓库另外列出中文、2B 和 10B 等权重，不能将英文论文实验配方直接套给它们。

预训练时先从文本抽取连续片段，用一个 `[MASK]` 代替每个片段，按随机空白顺序训练模型恢复正确文本。训练目标提高正确片段在上下文及之前已生成片段条件下的概率；[下一 token 预测](/foundations/next-token/)解释了逐 token 的基本计算。随机顺序指每次训练选择一种片段顺序，并不是一次生成时所有空同时互相读取未来答案。

论文的短片段设置按一种称为泊松分布的规则随机决定片段长度：有的短、有的长，平均约 3 个 token；不断抽取，直到遮住原文至少 15% 的 token。文档级设置则使用覆盖原文长度 50%—100% 的单个片段。这里的比例是论文实验设置，不是所有 GLM 后续版本的固定配置。

除了短片段，论文还研究不同遮盖方式：文档级目标使用较长的单个片段，面向较长文本生成；句子级目标选取完整句子，适配条件生成。它们可以与短片段目标混合训练，但不同组合会带来任务取舍，论文并未证明增加某一种目标一定使所有任务同时变好。

具体来说，论文的 GLM-Doc 和 GLM-Sent 分别把短片段目标与文档级或句子级目标混合；其多任务实验以相等概率采样两种目标。句子级设置抽取完整句子，直到覆盖原文约 15% 的 token。这个 50:50 是论文实验中的选择，不是使用 GLM 的通用规定。

## 从填空到分类和生成

对情感分类，可以把“这个商品很好用”改写成“这个商品很好用。评价是 [MASK]”，再把正面和负面的标签映射成“好”与“坏”等候选答案。模型比较候选填空的概率，并可用标注数据对任务微调。这个改写叫任务模板；标签到具体词的映射会影响结果，例如不同表达是否自然、分词长度是否不同，都需要验证。

对摘要等条件生成，输入文章作为上下文，在指定空位逐步生成摘要；对续写，可以把空位放在已有文本末尾。这样的任务组织帮助同一模型复用预训练能力，但并不意味着它可以不经适配就胜任任意任务，也不等同于后来的指令微调或人类反馈训练。

## 评测：怎么判断它真的有用？

论文在 SuperGLUE 开发集上评估多个语言理解任务，并对各任务微调。论文报告，在其控制训练数据和相近训练条件的 BERT 对照中，GLM-Base 和 GLM-Large 的平均分分别高约 **4.6 和 5.0 个百分点**；同时也指出 WiC 不属于多数任务的提升情况。这个结果针对论文的具体模型、任务和模板，不表示 GLM 在任何数据上都领先 BERT。

以 Base 为例，表中的 BERT 平均分为 66.1，GLM 为 70.7；对照中的 BERT 使用分类头，GLM 使用人工设计的填空模板，因此这比较的是论文中整套任务设置，不能只归因于注意力掩码。

论文还测试摘要、文本填空和语言建模。不同任务使用不同指标：分类看标签预测，摘要常报告 ROUGE，填空可用 BLEU 等文本匹配指标；这些分数无法完全衡量事实是否正确。比较时要核对模型规模、数据、微调方式、测试划分、模板和生成参数，而不能仅凭某一项分数断言理解或写作全面更强。

例如，在论文的 Gigaword 摘要实验中，GLM-Large 的 ROUGE-1 / 2 / L 分别是 38.6 / 19.7 / 36.0，GLM-Sent 是 38.9 / 20.0 / 36.3。这里的分数衡量生成摘要和参考摘要的文字重合，不能直接解释成事实正确的比例；论文也报告 GLM-Doc 在该任务上略低于 GLM-Large，说明擅长长文本续写的训练目标不一定更适合摘要。

假设用 GLM 做商品评论分类，评测时应保留独立的评论及标签，检查不同商品类别、否定句和讽刺表达；同一评论改几个词不能分别进入训练和测试。若总体准确率很高但否定句常错，要查看模板和训练数据是否覆盖“虽然外观好，但根本不能用”等情况，再补充开发数据并用独立样本复测。这是建议的实践方案，不是论文已执行的结果。

## 与 BERT、T5、ChatGLM 的区别

[BERT](/nlp/bert/) 以掩码语言建模学习双向上下文表示，原始 GLM 用自回归方式生成空白片段；两者都是训练思路，不应把 BERT 说成完全无法被改造成生成系统。[T5](/nlp/t5/) 也做过片段去噪，但采用编码器—解码器结构，原始 GLM 采用单一 Transformer 与混合注意力，并在论文中研究打乱空白顺序和二维位置编码。

ChatGLM-6B 是后来基于 GLM 框架、针对中文问答与对话优化的模型；GLM-130B 也是后续更大规模的双语预训练模型。它们在规模、数据、训练与实际用途上不同，不能把 ChatGLM 的聊天能力、参数和许可自动归到 2021 年原论文。更新的 GLM 家族结构和训练目标也需要逐版本核查。

## 面试追问

**空白两边都能看，为什么它还叫自回归？** 因为它利用保留下来的双向上下文作为条件，但空白内的答案仍逐 token 按顺序生成；能看上下文不等于能看到未来答案。

**二维位置编码中的两个维度分别是什么？** 一个标记空在挖空后文本中的位置，另一个标记当前片段内部的生成位置；它们不是图片的横纵坐标。

**它与 T5 最大的区别是什么？** 两者都能学习填空，原论文中的 GLM 使用单一骨干和混合注意力，T5 使用编码器—解码器；比较结果仍取决于任务、数据和模型规模。
