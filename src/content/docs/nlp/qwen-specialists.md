## 要解决什么问题

知识库问答不只要会回答，还要先找对材料；安全检查则要判断输入输出是否符合规则。同属 Qwen，不表示输出形式或训练目标相同。[返回主线](/nlp/qwen/)。

## 结构与数据流

| 分支                         | 做什么                                   | 典型输出与学习重点                   |
| ---------------------------- | ---------------------------------------- | ------------------------------------ |
| Qwen2-Math／Qwen2.5-Math     | 数学专用模型，2.5 包括推理与工具辅助路线 | 解题文本；看数学数据、推理与结果验证 |
| QwQ-32B-Preview → QwQ-32B    | 早于统一 Qwen3 主线的推理探索            | 较长思考；不是所有 Qwen3 的别名      |
| Qwen3-Embedding              | 将文本变成检索用向量                     | 向量；不是直接给答案                 |
| Qwen3-Reranker               | 进一步比较问题与候选材料的相关性         | 排序分数；开销与一次向量检索不同     |
| Qwen3-VL-Embedding／Reranker | 对文字、图片等多模态材料检索与排序       | 多模态表示／相关性判断               |
| Qwen3Guard Gen／Stream       | 生成式内容判断与流式检测                 | 安全类别等判别信息，按具体型号接口   |

Embedding 先从很多材料里召回，Reranker 再精排小批候选。Guard 检查风险，生成模型组织答案，它们可以在同一系统中合作，但各自需要独立评测。

### 退款问题走过三个不同模型

教学问题是“拆封后还能退吗？”Embedding 把问题和政策段落各变成向量，像给内容建立便于查找的坐标；向量相近表示模型认为相关，不是两段话逻辑上必然一致。库中的材料可预先编码，问题来时快速找候选。

Reranker 再把问题与每条候选一起比较。它有机会区分“可以退”和“拆封不能退”这类词很像、结论却不同的段落，但每个问题—候选对都要计算，不适合无代价地扫过全库。Qwen3-Reranker 的评分需按官方模板与输出 token 概率规则处理，不能把任意聊天分数当成等价接口。

生成模型读证据写答复，Guard 按安全规则检查输入或输出。Guard 不是退款规则数据库，也不会因为判定安全就证明退款结论正确。VL 检索把截图、扫描页纳入材料，新增的是视觉表示和相应数据问题，不只是把扩展名改为图片。

## 数据与训练

数学分支关注解题与验证信号；检索需要问题、正例和难负例等相关性数据；安全模型需要明确规则和分类标注。某个分支的训练方法不能直接套给另外一条分支。开放程度、许可证和规格按各官方仓库与权重卡查看。

### 难负例为什么比随便找一段无关文本有用

问题问拆封退款，正例解释拆封条件；难负例可以讲未拆封退款、同品牌保修或其他品类。只拿天气预报当负例，模型很容易分开主题，却学不到条件差别。具体对比损失和蒸馏细节以该分支官方实现为准。

Math／QwQ 则是生成答案的路线。例如看 3 箱乘 4 瓶：数学示范可以写出计算过程，工具路线可以请求执行计算，可验证反馈可以核对最终 12。结果正确、工具用法正确和解释可靠是不同目标；不能把 Embedding 的相关性负例训练搬来解释数学 RL。

## 评测怎么看

数学看答案正确与工具预算；召回看 Recall@K，排序看 nDCG、MRR 等排序指标；安全检测分别统计漏报与误报，并检查语言、场景和规则切片。只报综合准确率会隐藏代价很高的错误。

### 召回、排序和安全，各算一道小题

构造一个问题只有一条关键证据，若它没进前 5 条，Recall@5 对这题就是 0；进了则为 1。若关键证据排第 4，倒数排名贡献为 1/4；Reranker 将它提到第 1，排序改善，但答案模型是否正确还要另测。真实多相关文档时，应按相应指标定义统计，而非沿用这个单相关简例。

安全检测再看混淆矩阵：把正常问题拦住是误报，把风险问题放过是漏报。在固定评测集上调阈值有取舍，阈值选择在开发集完成，测试集不能被反复用来挑参数。这里的数字都是指标算例，不是这些模型的成绩。

## 应用与错例

[RAG](/applications/rag/)没找到材料，先看召回；找到了但排序低，检查难负例；引用正确却回答错，才进入生成分析。安全误杀正常问题，则补贴近边界的正反例，不能只看误报下降，而忽略漏报是否上升。

## 比较与面试追问

**Embedding 和 Reranker 为什么常一起用？** 前者快速覆盖大量候选，后者更细地比较少量候选，交换速度与精度。

**Guard 判了安全就一定没有风险吗？** 判别能力受规则、训练与场景分布限制，需要独立切片验证。
