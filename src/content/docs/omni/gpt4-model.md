## 为什么值得学

如果只问“请写一封请假邮件”，不同大语言模型可能都答得像模像样。但当任务变成“看一张设备截图，结合报警信息写一份排查步骤，并说明哪些地方需要现场确认”，难度就不止是把句子接下去：模型还要把不同输入的信息联系起来，遵守格式要求，并面对图片看不清或资料缺失的情况。

GPT-4 是这条发展线上的重要节点。OpenAI 的报告介绍它既能接收文字，也能接收图像并输出文字。不过，**能处理图片，不等于首发当天所有人都能直接上传图片**。2023 年 3 月的发布说明称，文字输入首先通过 ChatGPT 和 API 提供，图片输入则先与一家合作伙伴探索。2023 年 9 月的 GPT-4V 系统卡介绍了面向更广泛使用的视觉能力。模型研究能力、产品功能和具体账号可用时间是三个问题，不能混为一谈。[首发说明](https://openai.com/index/gpt-4-research/)、[GPT-4V 系统卡](https://openai.com/index/gpt-4v-system-card/)

一个经常被误会的地方是名字：GPT-4、GPT-4V、后来不同 API 快照和 GPT-4o 不是可以随意互换的标签。这里主要讲 2023 年技术报告及 GPT-4V 的公开材料；产品后来怎么调整，要以当时所用产品和版本的记录为准。

## 结构：知道输入输出，但不要虚构内部零件

阅读器中的图是教学用的**输入输出示意图**，不是官方架构图。报告明确说明 GPT-4 基于 Transformer，预训练任务是预测文档中的下一个 token。你可以把 token 粗略想成模型处理的文字片段：给它“今天下雨，记得带”，它会根据前文为后续片段分配概率，再按解码方式选择接下来的内容。词语如何切分取决于 tokenizer，不是一字必然等于一个 token。

生成长回答时，这个过程会反复执行：选择一段输出，把它接回上下文，再预测下一段。我们看到的是连贯的一句话，模型处理的是一连串预测。这样的训练能让模型学习文本里的语言、知识和常见推理模式，但“能预测后面的字”并不自动意味着事实总是正确，或者模型真的理解了所有外部世界的状态。

Transformer 的注意力机制让每个位置的信息可以参考上下文中的其他相关位置。理解这一通用机制时，可从 [Transformer](/foundations/transformer/) 入手。不过，**原始 Transformer 的示意图不是 GPT-4 的内部工程蓝图**。OpenAI 没在技术报告中公布具体层数、隐藏维度、参数量、是否采用某种专家混合结构，也没有公开视觉输入究竟通过哪些具体模块连接。网上的详细架构图如果没有可靠依据，只能算推测。

图片理解也类似。报告确认模型能接收图像和文字，但没有把视觉编码器、切图策略和连接层的具体实现完整公开。我们可以把图片输入想象成把视觉信息交给模型处理，却不能据此宣称它一定使用某一种特定视觉编码器，更不能根据能力倒推出参数量。闭源模型的学习重点，是把**公开事实、合理的通用解释与未知实现**分开。

## 训练：先学续写，再学按要求回答

预训练像让学生读大量材料并不断练习填空。模型看到上下文，要预测后续 token；每次预测错误，训练算法就调整参数，让类似上下文下的预测逐步改善。训练数据中既有公开数据也有授权数据，但报告没有给出可供复现的完整语料清单、筛选比例与训练细节，因此无法从论文重建数据集，也不能断言某本书一定在训练集中。

只会续写还不够。例如用户问“如何安全保存密码”，原始续写模型可能续出风格各异的网页内容，包括过时建议。对齐阶段会用人类反馈等方法，让模型更倾向于给出有帮助、符合要求的回答。可以把预训练看作学习语言和模式，对齐看作进一步练习“在具体对话中怎样回答”。这个类比只帮助理解目标，不能证明任何特定训练样本被使用过。

技术报告讨论了 RLHF 对能力与行为的影响，但没有披露完整的标注流程、奖励模型结构、训练超参数或每一个数据来源。可以学习 [SFT](/training/sft/) 和 [RLHF](/training/rlhf/) 的一般做法，但不要把常见流程画成 GPT-4 已公开的精确配方；SFT、偏好数据、奖励模型、强化学习在不同系统中可以有不同实现。也不要把某个社区猜测直接当作官方训练配方。

报告还讨论了可预测的规模扩展：团队用较小训练计算量的模型，预测更大运行的部分损失或能力趋势。这类似先在小型样机上研究材料和性能关系，再推算大型设备的某些指标；它并不表示能提前准确预言模型所有能力、安全风险或具体用户体验。预测成立也依赖所测指标、拟合条件和计算范围。[技术报告](https://arxiv.org/abs/2303.08774)

## 评测：高分是证据，不是万能保证

报告列举了多种考试与基准，其中模拟律师资格考试结果约处于考生前 10%，而官方对比中的 GPT-3.5 约处于后 10%。这个数字常被传播为“模型通过了律师考试”，但评测是特定模拟考试、特定提示、计分和模型快照下的实验；它不意味着模型拥有职业资格，也不能替代真实法律服务。考试题、评分方式和真实工作的沟通、取证、责任体系本来就不同。

代码任务也要看协议。比如 HumanEval 通常让模型补全函数，再执行测试判断正确性；一段程序通过公开测试，并不意味着它能安全地修改大型仓库。报告中不同任务可能采用不同的提示和采样设置，比较数字前要看测试集、是否允许多次尝试、采用基础模型还是对齐后的版本。换一道题、换一套提示或换一次模型更新，都可能改变结果。

技术报告表 2 中，GPT-4 在 HumanEval 的零样例结果为 67.0%，报告中的 GPT-3.5 对照为 48.1%；附录的数据污染分析还报告，排除检测出潜在重合的题目后，GPT-4 在剩余题上的结果为 65.58%。这两个数字来自不同的题目集合，不能将差额简单解释为“记住答案带来的提升”。实际比较时，除了分数，还要保存题集、提示、采样和测试运行方式。

还要区分**标准题成绩**和**自己的任务质量**。假设你让模型解释设备照片中的报警：先准备没有参与提示调优的图片，每张记录真实状态、是否能从图片判断，以及正确答案。再分别统计识别正确率、看不清时能否承认不确定、给出危险步骤的比例以及人工复核时间。例子中的指标是评测设计，并非 GPT-4 的实测结果。

数据污染同样值得注意。模型若在预训练时见过测试题或近似题，就可能获得虚高分数。报告分析了部分考试与基准的污染风险，但对外部使用者来说，很难独立验证全部训练数据。报告也披露训练中混入了部分 MATH 和 GSM8K 训练集数据，并建议把其 GSM8K 结果理解为介于纯少样本迁移与针对基准专门微调之间；这不等同于说其测试集被用于训练。最好的实践是记录版本与数据来源，使用保留集或更新的数据，并对容易记忆的公开题目保持谨慎；这能降低风险，不能自动证明完全没有重合。

## 视觉与应用：一张图片也可能让模型自信地看错

试想用户发来一张保险丝盒照片，问“哪个开关控制厨房？”图片可能反光、标签太小，甚至没有厨房标识。模型可以帮助描述可见内容、整理排查清单，但如果它把模糊字样猜成了明确答案，用户可能据此做出错误操作。较好的交互应允许它说“照片看不清，请拍近一点”，同时把高风险操作留给有资质的人。

评测图像输入时不能只挑清晰截图。可以加入模糊、遮挡、旋转、小字、图表坐标轴不完整等样本，查看错误集中在哪一类。比较结果时记录图片尺寸、预处理、问题、模型快照和输出；同一张图片先裁剪再输入，得到的结果也可能不同。视觉系统卡讨论的风险与缓解措施是对应当时系统的工作记录，不是保证每张图都安全可靠。

在检索增强问答中，可以先检索并展示原始资料，再让模型基于资料回答和引用。若用户问“这个设备的安全电压是多少”，系统应先检查手册的设备型号与版本；找不到对应条目时，明确说不知道，比编一个看似合理的数更有用。模型给出的引用也需要检查是否真的支持结论，不能因为答案带了链接就认定它正确。

## 从 bad case 回到改进

假设模型把一张仪表盘图片里的 18.6 读成 13.6。先保存可合规留存的图片、用户问题、模型版本、图像预处理方式、实际输出与人工核对结果。然后判断错在何处：原图是否模糊？缩放是否丢失小数点？问题有没有指明要读哪一列？人工标注是否也存在争议？不同原因对应不同改法。

如果图片本来清楚，但上传时被压得过小，可以先调整裁剪或分辨率；如果表格密集，可以先用可核查的 OCR 或人工复核，再交给模型解释；如果问题含糊，就让用户圈出目标区域。对闭源模型，使用者通常无法修改原始预训练数据，但可以改提示、检索、输入处理与系统校验，并保留独立测试集复测。

做完改动后，不仅要看这张图片是否读对，还要检查其他字号、语言、表格和仪表盘是否退化，记录延迟与成本。这个闭环是可复现的实践方案，不是本文已经运行过 GPT-4 的测试。涉及个人信息的图片和日志还需遵循使用场景的数据权限与保留约定。

## 面试追问

**GPT-4 是多模态，为什么输出仍然是文字？** 多模态可以体现在输入端；技术报告描述的是文字和图像输入、文字输出。不能因为会看图片，就推断原始模型一定能生成图片或原生输出音频。

**为什么不能照着常见 GPT 图说清 GPT-4 的全部结构？** 通用 Transformer 和下一 token 预测有公开依据，但 GPT-4 的具体层数、参数规模、视觉连接方式没有在报告中公布。把常见实现当成特定闭源模型的实物结构，会把猜测误当事实。

**RLHF 解决了幻觉吗？** 没有。它可以改善某些人类评价的行为，但模型依然可能给出错误或编造的答案。需要可靠资料、可复核引用、拒答机制和针对实际场景的评测共同配合。

**考试分数很高，能直接用于专业决策吗？** 不能。模拟考试与真实工作中的事实核查、责任、时效和错误代价不同。先明确使用边界，再在真实但独立的任务样本上评测并安排适当的人类复核。
