## 要解决什么问题

一张长发票上有“金额 108 元”和“价税合计 114.48 元”。如果把整张长图强行压成很小的方图，文字可能糊掉；但如果无条件把所有图片放到很大，视觉 token 和计算量都会增加。Qwen2-VL 尝试根据图片大小与比例处理视觉信息，并将图片或视频与文字问题一起交给语言模型。

本页聚焦 2024 年 Qwen2-VL 系列。它理解图片和视频，主要输出文字；下面用发票和视频的例子解释它的工作过程。

## 结构与数据流

从下方教学简图看：图片或视频帧经过尺寸处理和视觉编码器，相邻视觉特征合并后形成可变数量的视觉 token；这些表示与文字输入进入 Qwen2 语言模型。M-RoPE 给多模态输入安排时间、高度和宽度的位置信息。图省略了标记 token、视觉层和视频管块的细节；[官方报告](https://arxiv.org/html/2409.12191v2)介绍了完整结构。

论文列出 2B、7B 和 72B 三种型号；视觉编码器和语言骨干的规模分别列在模型卡中。运行时的显存还受图像 token 数、精度和上下文长度影响。

### 一张长发票会产生多少视觉 token

Qwen2-VL 使用动态分辨率：图片可根据实际尺寸和配置的像素上下限调整，视觉 token 数量随处理后的大小变化。处理器会根据像素预算缩放图片，因此实际送入模型的尺寸决定视觉 token 数量。

举一个静态图简化算例：处理后图片为 448×280 像素，按 14×14 的空间 patch 划分，得到 32×20＝640 个视觉块。视觉编码后将相邻 2×2 个特征合并，得到 16×10＝160 个视觉 token；图片边界标记与文字 token 要另算。

论文还给出一个便于核对的小图例子：224×224 的图片先分成 16×16＝256 个 patch，经过 2×2 合并后得到 64 个视觉 token。加上表示视觉内容开始和结束的两个特殊标记，共占 66 个位置。这样就能区分视觉内容本身的数量与送给语言模型的总位置数。

如果宽、高各翻倍，视觉块和合并后的视觉 token 数量约变为四倍。提高分辨率可能保住小字，但会增加视觉计算与语言模型上下文成本；最合适的尺寸需要在具体任务上测试。

这里的合并不是简单地把四个 patch 当作四个独立词交给语言模型：论文在视觉编码器之后使用一个 MLP，把相邻的 2×2 个视觉特征组合成一个视觉 token。视觉编码器处理合并前的块，语言模型看到的是合并后的序列；因此计算成本不能只看最后输入语言模型的 token 数。图片缩放、边界标记与多个图片的排列，也都要在估算时单独计入。

### M-RoPE 在记什么位置

发票最上方有“金额”，底部有“价税合计”。模型不仅需要识别字，还需要保留字在图上的相对位置。传统一维位置编码适合描述文字序列的先后；M-RoPE 把旋转位置编码分成时间、高度和宽度三个部分。纯文字中三部分使用相同位置编号；图片中的视觉 token 共享时间编号，并根据二维位置分配高、宽编号。

视频多了时间维：画面中按钮先出现再消失，帧组的位置需要携带先后信息。M-RoPE 是帮助模型组织位置的机制，不是一个“自动找正确框”的模块；如果处理过程丢掉某一帧，位置编码也不能把内容找回来。[位置编码](/foundations/position-encoding/) 可作为基础阅读。

### 图片和视频如何统一

论文描述训练中以每秒两帧抽取视频，并用时间深度为二的 3D 卷积处理视频管块；静态图片通过复制成相同的两帧，使输入形式一致。训练时论文为每段视频设置了 16,384 个 token 的上限；帧数和分辨率需要共同使用这份预算。

沿用前面的 448×280 像素算例，假设每一对相邻采样帧经过时间深度为二的卷积后，形成一组 160 个视觉 token：一分钟视频按每秒两帧采样约 120 帧，即约 60 组、9600 个视觉 token；两分钟约 19200 个，会超过论文训练时的单视频预算。实际处理还受抽帧、缩放、帧数取整等影响，这只是帮助理解预算的算例；16,384 也不是所有部署方式的固定推理上限。

假设错误提示只出现 0.2 秒，而抽帧间隔为 0.5 秒，这段提示可能完全落在两帧之间。即使模型推理再好，没有收到提示内容也无法可靠判断；应检查真实输入帧，而不是只查看原视频。

## 数据与训练

论文沿用三阶段思路：第一阶段只训练视觉编码器，利用图文材料建立视觉语义；第二阶段解冻全部参数，用更丰富的图文、OCR、视觉问答和其他材料联合训练；最后固定视觉编码器，用指令数据微调语言模型。三个阶段分别侧重视觉语义、跨模态联合学习和按指令作答。

预训练中混合图文对、图文交错文章、OCR、视觉问答、视频对话和纯文本等。报告统计的预训练 token 包含文字和图像 token，但训练监督施加于文本 token；学习目标是根据视觉和文本上下文预测文本。后续指令微调加入文档解析、多图比较、视频和智能体交互等例子，使模型更能按问题组织回答。

用一条教学样本理解“只监督文本”：输入发票图和问题“价税合计是多少”，目标答案是“114.48 元”。训练时模型根据图像特征与上下文预测答案的文字，并用预测误差调整当前阶段允许训练的参数；不需要为每个视觉 token 准备一个对应的文字标签。第一阶段语言模型参数冻结，误差信号仍可经过语言模型传回可训练的视觉编码器；第三阶段则固定视觉编码器、调整语言模型。这里的发票是示意，并非论文公开的具体训练样本。

报告称初始预训练阶段使用约 6000 亿 token，第二阶段另用约 8000 亿，合计约 1.4 万亿；语言模型从 Qwen2 初始化，视觉编码器从 DFN 的 ViT 初始化并把原先固定位置编码替换为二维 RoPE。这些数字按报告的统计口径同时包含文字和图像 token。

做发票任务时，训练样本至少要有图片、问题、正确字段、答案以及可核对的证据。把“金额”和“价税合计”一起出现的困难样本纳入，比只给简单票据更能检查模型是否学会字段对应。扫描模糊、缺少字段和无法辨认的例子也应保留，防止模型被迫编出数字。

## 评测怎么看

### 从读字到字段对应

同一张发票问三次：“图上有哪些数字？”检查文字读取；“价税合计是多少？”检查字段对应；“请指出证据位置”再检查定位。若识别出了 108 和 114.48，却回答 108，问题可能是字段关联而非完全看不见文字。

评测应记录原图与实际输入分辨率、像素预算、问题模板、输出格式、模型规格和推理设置。可以统计精确金额正确率、无法辨认时的拒答，以及证据框质量；对数字统一小数点和货币格式。定位的交并比需要先约定坐标转换和阈值，不能只因为输出是合法 JSON 就算答对。

论文的定位训练把框坐标归一化到 [0, 1000) 表示，并用标记区分被指物体和框。比如输出的右下角坐标是 750，含义是所在方向约为图片边长的四分之三，并不是 750 像素。实际映射回原图时，还要确认坐标对应的是哪张图以及预处理时的缩放；框格式正确不代表框真的圈中了目标。

### 分辨率消融如何阅读

论文表 7 比较 Qwen2-VL-7B 的固定与动态视觉 token 策略：固定 576 token 时 InfoVQA 验证集为 65.72；动态策略平均约 1924 个图像 token，InfoVQA 为 75.89。它们的 token 预算并不相同，因此不能把差距全归因于“动态”本身。论文同时指出过度放大小图可能损害 OCRBench；更多 token 不保证所有指标单调上升。这些结果来自论文中的通用视觉评测。

视频评测要保存实际抽帧、帧率、图像尺寸及上下文预算，再按事件时长和事件位置切片。一个短弹窗没有进入任何帧时，失败原因与“看见弹窗但理解错误”不同，改进方案也不同。

### M-RoPE 的视频对照

论文表 8 用 Qwen2-1.5B 与 ViT-L 组成的预训练模型比较一维 RoPE 和 M-RoPE。NextQA 分数从 43.9 升至 46.0，STAR 从 55.5 升至 57.9；同一张表中的 InfoVQA 则从 50.8 降至 50.3。位置编码改善了这组视频测试中的表现，各任务的变化并不完全相同。

把测试换成“按钮出现后发生了什么”这样的题目，模型需要把画面内容和时间顺序联系起来。评测时可以准备顺序颠倒的两个短视频，分别提问并检查答案是否随事件顺序变化；同时保存实际抽取的帧，方便判断模型有没有看到关键画面。

## 应用与错例

假设模型答成 108 元。先核对图片是否完整、目标字段在缩放后是否仍可读；再比较整图与包含目标行的裁剪图，确保问题和评分规则不变。若裁剪后读数正确，输入细节或干扰可能是线索；若字段清楚仍答错，继续排查字段关联与训练数据。不要一次同时更换模型、提示和分辨率，否则很难归因。

收集下一轮样本时，按票据来源或模板分组，避免同一模板的轻微变体泄漏到测试集；增加近似字段、模糊扫描和缺失字段等反例。独立测试集分别记录金额正确率、拒答和成本，回归普通图片问答与纯文本任务。这套方案可以用于组织下一轮对照实验。

## 比较与面试追问

**动态分辨率与固定 256 视觉表示有何差别？** [第一代 Qwen-VL](/omni/qwen-vl-first-model/) 用查询式适配器输出固定长度；Qwen2-VL 合并相邻视觉特征后，token 数仍随输入尺寸变化。

**M-RoPE 等于视频时间戳吗？** 它为时间、空间位置安排编码；更具体的绝对时间处理还需看相应代际的机制与预处理，不能从名字推断能读出所有真实时刻。

**为什么更高分辨率不一定更好？** 输入细节、token 成本、模型训练分布和任务性质共同影响结果。实验需固定其他条件，不能只凭图片更大下结论。
