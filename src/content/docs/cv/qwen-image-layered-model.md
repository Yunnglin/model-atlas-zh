## 要解决什么问题

想象你接到一张已经导出的咖啡海报：蓝色背景上有一只杯子、一行标题和几片装饰叶子。客户说，杯子向右移动，标题换到上面，叶子颜色也要改。原始设计文件如果还在，你可以选中不同图层分别操作；但手里只有一张 PNG 时，背景、杯子和文字早已压成同一张平面图，移动杯子就会把杯子背后的背景也留下一个洞。

Qwen-Image-Layered 学的就是把这种平面图重新拆成多个透明图层。理想情况下，底层是背景，中间是杯子，上面是文字；你可以在普通图像编辑软件中移动其中一层，再按顺序叠回去。它更像把一张已经压扁的三明治重新拆开，而不是直接根据一句话改完整张图。[Qwen-Image-Edit](/cv/qwen-image-edit-model/)侧重按指令修改图像；Layered 的直接产物是多个图层，之后还需要编辑和合成工具。

这里有一个重要的不确定性：原图中杯子挡住的背景究竟长什么样，单凭这一张图往往不知道。模型只能根据上下文生成看起来合理的内容，而不能找回从未看到过的真实细节。拆出的文字通常也只是透明图片上的像素，并不是能够直接修改字体的文字对象；同样，杯子图层不等于完整三维杯子。

## 结构与数据流：从一张图到多个透明图层

模型继承了 [Qwen-Image](/cv/qwen-image/) 的图像生成基础，论文围绕分层任务改造了三个环节：能同时处理普通图片和透明图片的 RGBA-VAE、可以处理不同层数的 VLD-MMDiT，以及逐步训练的任务安排。实际推理里，原图和描述作为条件，模型生成多个图层的压缩表示，再由解码器还原成透明图片。

先看透明度。普通 RGB 给每个像素记录红、绿、蓝；RGBA 多一条 Alpha，表示这个像素有多不透明。Alpha 为零的位置透出下层，完全不透明的位置遮住下层，中间值可以表达玻璃杯边缘、阴影等半透明区域。分层结果按从下到上的顺序合成：一层的新颜色和下面已有画面的颜色，按这一层的透明度混合。图层顺序一变，杯子可能压在标题前面，也可能被标题盖住。

VAE 好比图片的压缩与解压工具：先把大图转换成更小的潜表示，让生成模型处理更省空间；最后把潜表示还原为图片。这个任务的输入常是 RGB，输出却是 RGBA。论文通过训练 RGBA-VAE 同时处理这两类图片，让输入和输出更容易在共享的潜空间里交流。共享空间是为了减少表示上的差异，不意味着透明边缘一定不会出错。

具体怎么让原本只认识 RGB 的压缩器学会透明度？论文把编码器的第一层和解码器的最后一层从三个颜色通道扩到四个通道，原有 RGB 部分沿用预训练参数，新加的 Alpha 通道从特定初值开始，再使用 RGB 与 RGBA 图片一起训练。普通 RGB 图片在这里会补一个全为 1 的 Alpha 通道，也就是先当作完全不透明来处理。初始化时，新加的编码器 Alpha 通道权重设为 0，解码器新加的 Alpha 通道权重也设为 0、偏置设为 1；这样一开始不会让新增输入通道扰乱原有 RGB 特征，并为不透明输出提供初始值。随后使用 RGB 和 RGBA 数据一起训练，同一个 VAE 才能既编码原始海报，又学会玻璃边缘、阴影等不同透明度。

VLD-MMDiT 可以把多个图层的潜变量放在同一次生成过程中联合处理。它不是先把第一层完整画好、再孤立地画第二层；各层的信息可以在模型内部交互，有助于它们形成相互配合的结果。模型也需要知道每份表示属于哪一层，论文为此引入 Layer3D RoPE：除了图片里的横、纵位置，还引入图层位置。可以类比给每张透明胶片同时标注“画面上的坐标”和“叠放顺序”。它解决的是位置区分，不是保证模型自动理解所有真实的图层语义。

推理过程使用生成模型的迭代方法：从噪声出发，在原图和文字条件的帮助下逐步得到结果。请求更多图层，可能让元素拆得更细，也可能多出碎片或近似空白层；同一张图合理的拆法本来就不止一种。官方还展示了递归分解：先拆成几层，再选中某一层继续拆。每次分解都是新的预测，误差和虚构的遮挡内容可能随之累积。

## 读懂官方结构图

左边从下往上看：文字由 Qwen2.5-VL 编码；输入图片和目标透明图层分别进入同一个 RGBA-VAE，压缩后切成小块，与文字表示一起交给 VLD-MMDiT。图中的雪花表示这些编码器在此训练阶段被冻结。训练时，目标图层先加噪声，模型学习从带噪状态恢复目标；实际使用时，我们并没有目标图层，模型从噪声开始生成。

右边把图像块排成“宽、高、图层”三个方向。假设一张海报拆成四层，每层先分别压缩和切块，再把各层的小块沿序列拼在一起参与注意力计算；并非先把四层压成一层。Layer3D RoPE 给参考图使用图层坐标 −1，给输出图层依次使用 0、1、2、3，同一位置的杯子与背景因此有不同的图层坐标。

再看叠图：白色背景上放一层红色，若这一层 Alpha 为 0.25，合成颜色就是 25% 红色加 75% 白色，即 RGB `(1, 0.75, 0.75)`。换成完全不透明的红色层，背景就被遮住。这个简单算例解释了为什么半透明阴影和边缘也要评价，而不能只检查主体轮廓。

## 数据与训练：怎样教模型理解一叠胶片

要训练分层，只有“最终海报”不够，还需要它对应的一叠图层。论文从 PSD 设计文件中提取图层，移除不影响最终合成的层，过滤异常内容，并合并空间上不重叠的图层，降低某些设计文件动辄几百层的复杂度。团队还用 Qwen2.5-VL 为合成图生成整体文字描述。值得注意的是，合并后的一层可能包含多个不相交元素，所以训练目标不必然是“每个物体恰好一层”。

论文把训练分为三段。第一段从文本生成普通 RGB，过渡到生成单张 RGBA，让模型适应透明图；第二段学习根据文本同时生成合成图和多个透明图层，开始理解多层之间的关系；第三段再加入输入图片，训练从图像生成多个 RGBA 图层，也就是发布模型主要面向的图像分解任务。这种安排像先学画一张透明贴纸，再学画一套能叠起来的贴纸，最后学着把现成海报拆开。

论文报告三阶段分别进行了 50 万、40 万、40 万次优化，采用 Adam，学习率为 0.00001；多层训练的最大层数设为 20。它还说明单图任务使用内部数据，多层任务使用处理后的 PSD 数据。论文没有完整公开训练样本来源、筛选清单、混合比例和全部工程配置，不能据此说已经能够原样复现官方训练。

训练目标沿用 Qwen-Image 的流匹配思想。简单地说，训练时在噪声与目标表示之间构造中间状态，教模型判断下一步应朝哪个方向调整；推理时从噪声一步步走向结果。这不是把训练图层机械地复制出来：模型是在条件下生成预测，因此生成内容和透明边缘都需要检查。

## 评测：拆得像，不一定拆得对

假如生成的三层叠回去看着像原海报，还不能断定分层成功。模型可能把杯子和标题放在同一层，整图看起来正确，但用户无法只移动杯子。评测至少要分别检查合成后的整体相似度、图层是否可独立操作、各层透明边缘是否正确，以及原来被遮住的部分是否合理。

论文使用 Crello 数据集和 LayerD 的评测协议。因为同一张图可能有多种合理拆法，协议按顺序对齐图层，并允许合并相邻图层后比较；允许合并多少层会改变结果。RGB L1 衡量 RGB 颜色差异，按真实图层的 Alpha 加权，越低越好；Alpha soft IoU 衡量预测透明度与真值的重合程度，越高越好。在不允许合并的设置下，论文表 1 中本模型分别为 0.0594 和 0.8705，而 LayerD 分别为 0.0709 和 0.7520。这是特定数据集、协议和模型设置下的结果，不应当成所有真实海报上的准确率。

为什么要允许合并相邻层？假设参考设计把标题和旁边的小图标分成两层，模型却将二者放在同一层；这两种结果叠回后可能一样，但逐层一对一比较会将它们判成错位。论文使用考虑顺序的动态时间规整方法对齐图层，并设定最多允许合并多少相邻层。允许合并能容纳不同拆法，却也可能掩盖无法独立编辑的问题，所以仍应结合实际操作检查图标和标题能否分别移动。

尤其要注意，论文明确指出 Crello 与其训练数据分布不同，因此在 Crello 训练集上对模型做了微调；表中的分数不能当成下载的公开权重在所有任务上的零样本成绩。论文也在 AIM-500 上测试 RGBA-VAE 的重建能力，那是在考压缩与还原组件，不等于完整分层模型的业务成功率。

如果评估咖啡海报，可以准备未用于调参的测试图，覆盖纯色与复杂背景、不同文字大小、阴影、半透明杯子和重叠物体。记录输入、模型版本、种子、尺寸、采样设置与层数；由人工检查文字是否完整、杯子是否能单独移动，并在深色和浅色背景上观察白边。用相同输入分别试三层和八层，比较可编辑性、冗余图层和耗时，而不是只选视觉上最漂亮的一次结果。

## 应用与错例：动手体验与改进

可以从官方仓库的推理示例或在线演示开始。准备一张自己有权使用的海报，描述整张图，指定四个图层；保存原图、生成的每个透明图层、随机种子与推理参数。先按顺序叠回，检查文字是否错字，再只移动杯子图层，观察背景是否留下杯子的残影。改变层数重复一次，比较哪一版更适合编辑。官方提示词描述的是整体图像，包括可能被遮挡的内容；并不提供对每一层精确指定内容的可靠控制。

如果移动杯子后发现背景残留杯柄，先判断杯柄是否被错误地分到了背景层；如果移走杯子后出现不自然的桌面纹理，则可能是遮挡区域补全不准确。前者可以尝试调整层数或换一张元素边界更清晰的图，后者需要人工修图，不能把想象出的纹理当作真实背景。将这两类失败分开记录，再收集带复杂遮挡和透明边缘的例子组成独立测试集，检验下一次调整是否真的改善。

## 比较与面试追问

**为什么分层后移动一个物体更容易保持其他内容？** 因为编辑软件只改目标图层，其余图层的像素可以保持原样；但如果初始拆分就不准确，或者补全了错误背景，最终画面仍然会出错。

**为什么不能仅用整图重建误差评价？** 多种图层组合可能叠成相似画面；全放在一层也可能重建得很好，却不能满足单独编辑。需要同时评价图层匹配、透明度及实际编辑任务。

**RGBA-VAE 与 Layer3D RoPE 各解决什么问题？** 前者帮助普通图和透明图使用一致的压缩表示；后者让模型区分空间位置和图层位置。它们作用在不同环节，不能互相替代。
