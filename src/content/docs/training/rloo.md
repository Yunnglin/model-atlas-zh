## 先用大白话理解

模型答题有时答对、有时答错。**REINFORCE** 的基本想法是：把回答当成一次采样，根据奖励与基线的差调整生成概率：高于基线的回答倾向被强化，低于基线的倾向被抑制。训练需要许多样本来估计方向；一次幸运的高分不代表模型真的掌握了题目。奖励可能来自规则，也可能来自人类偏好训练出来的模型；算法本身不指定奖励的来源。

但直接按绝对分数更新容易抖动。例如一道题大家都能得 90 分，另一道题大家只能得 30 分，不能因此认为前一道题的每个回答都值得大幅强化。**基线**相当于提供一条比较线：奖励减去基线，得到比预期好多少。合适的基线可以降低梯度估计的方差；它不是把奖励改成绝对正确与错误的判决。

## 一个具体例子：留出自己再比较

给同一道题独立采样三份回答 A、B、C，奖励分别为 1、0、0。RLOO（REINFORCE Leave-One-Out，留一法）的做法是：评价某份回答时，只用**其他回答**的平均奖励作为它的基线。

![RLOO 留一基线算例：同题三份回答的奖励为 1、0、0，分别得到优势 1、负 0.5、负 0.5。](/figures/training/rloo-baseline.svg)

图为原创教学示意，留一基线的定义参照 [RLOO 论文](https://arxiv.org/abs/2402.14740)。

| 回答 | 奖励 | 其他回答平均奖励  | 奖励减基线 |
| ---- | ---- | ----------------- | ---------- |
| A    | 1    | (0 + 0) / 2 = 0   | +1         |
| B    | 0    | (1 + 0) / 2 = 0.5 | -0.5       |
| C    | 0    | (1 + 0) / 2 = 0.5 | -0.5       |

因此这批样本鼓励 A 相对于 B、C 的生成方向。它只说明**一次更新的训练信号**：共享参数、学习率和其他样本都会影响最终概率，不能保证每个 token 均独立朝某个方向变化。如果验证器把错误答案误判为正确，方法同样会强化错误。

## 公式里的量

令同一提示 $x$ 的 $k$ 条独立回答为 $y_i$，奖励为 $R_i$。留一基线和优势可以写为：

$$
b_i=\frac{1}{k-1}\sum_{j\ne i}R_j,\qquad A_i=R_i-b_i
$$

在简单的序列级 REINFORCE 形式中，平均更新方向与 $A_i\nabla_\theta\log\pi_\theta(y_i\mid x)$ 的平均值有关。$\pi_\theta$ 是模型产生整条回答的概率；对自回归模型，序列对数概率可以展开为各 token 条件对数概率之和。实际训练会使用等价的损失最小化形式，并可能加入参考模型 KL 惩罚等约束。

为什么排除自己？在独立同分布采样等假设下，其他回答构成的基线不依赖当前回答的采样动作，可用于保持相应估计的无偏性质；这一性质不能无条件套到任意相关采样、奖励处理或改动后的训练实现。计算策略梯度时基线通常作为不反向传播的数值处理；若奖励或基线本身依赖当前策略参数，还要按目标及实现正确处理其梯度。$k$ 至少为 2，更多样本会增加生成和评判成本。

## 为什么“自己不参与自己的基线”很关键？

继续使用 1、0、0 三份奖励。若直接把整组平均 1/3 当成每份答案的基线，得到的差是 +2/3、−1/3、−1/3；RLOO 则得到 +1、−1/2、−1/2。这个例子中两者方向一致，比例恰好是 3/2。一般地，组大小为 $k$ 时，留一差值是整组均值差值的 $k/(k-1)$ 倍。

排除当前回答的作用不只是让数字放大：在同题回答独立采样、奖励按既定规则计算等条件下，其他回答的基线不依赖当前采样动作，因此相应的基线项不会改变期望策略梯度。把当前答案也放入基线，则基线和自身动作相关；上面所示固定比例就是差别。有限批次、相关采样、标准差归一化或裁剪等都会改变这个简单结论的适用范围。

## 和 PPO、GRPO 的区别

[PPO](/training/ppo/)常用价值估计与裁剪代理目标；RLOO 用其他同题样本估计基线，基本形式不要求单独价值模型。具体系统仍可能有其他稳定机制。RLOO 和 [GRPO](/training/grpo/)都利用同题多答，但前者使用留一平均；原始 GRPO 的常见写法用整组均值与标准差构造相对优势，并结合 PPO 风格的 token 级裁剪。二者实际实现可能有变化，不能只靠名字判断公式。

对同一组奖励，留一优势等于 $(r_i-\bar r)\,k/(k-1)$；如果不做标准差归一化，两者方向相同，但尺度不同。GRPO 的标准差、裁剪粒度、长度归一化和 KL 设置会进一步改变更新，不能因此把完整算法视为相同。

## 换一条比较线：ReMax 和 REINFORCE++

留一法不是唯一的比较方法。假设同一道题随机采样出的答案得 7 分，另外两个答案得 5 分和 8 分，RLOO 给它的基线是 `(5 + 8) ÷ 2 = 6.5`，优势是 `+0.5`。如果组里三份答案都被同一个错误的评分规则打高分，彼此比较并不能自动发现这个错误。

[ReMax 论文](https://arxiv.org/abs/2310.10505)采用另一条线：同一提示下，先随机采样一份回答，再用贪心解码得到一份参考回答；把随机回答的奖励减去贪心回答的奖励，作为更新信号。例如随机回答得 7 分、贪心回答得 6 分，差值就是 +1。贪心回答提供比较基线，算法并不是从一堆随机答案中只挑最高分答案训练。

[REINFORCE++ 论文](https://arxiv.org/abs/2501.03262)讨论不使用单独价值模型、在更大训练批次上归一化优势的做法，也介绍了结合组内基线的变体。比较这些方法时，除了基线，还要看奖励、归一化、KL 项、裁剪和采样预算；不能只凭一个方法名断言谁更省算力或效果更好。

## 论文里怎样比较 RLOO 和 PPO？

[原论文](https://arxiv.org/abs/2402.14740)用 Pythia-6.9B 做 Reddit TL;DR 摘要任务，也在 Anthropic 的有帮助、无害对话数据上比较 Pythia-6.9B 和 Llama-7B。研究者先训练监督微调模型和奖励模型，再让不同方法在相同任务上学习；RLOO 每道题会生成多份回答，分别利用它们与留一基线的差值。

论文用 1000 条测试提示比较回答，并让 GPT-4 按给定规则判断：新摘要与参考 SFT 模型生成的摘要，哪个更好。对于 TL;DR 任务，表 1 报告 RLOO（训练时每题采样 4 份回答）的胜率为 77.9%，PPO 为 67.6%。这些是相对 SFT 摘要的模型评审胜率，可以帮助理解论文的比较结果；它衡量的不是人工评审通过率或事实正确率。

这里的训练奖励也不只是奖励模型给出的分数。论文先从奖励模型分数中减去参考模型的 KL 相关项，再将得到的整条回答奖励用于留一比较。例如奖励模型给某条回答 2 分，假设系数为 0.1，当前模型与参考模型对这条回答的对数概率之差为 3，则这条回答用于计算的组合奖励为 `2 − 0.1 × 3 = 1.7`。另一条回答也要先算出自己的组合奖励，才能参与留一基线。这里的数字是教学假设；单条回答的对数概率差可能为负，不能把它当成一定非负的 KL 散度。两者的关系是：在当前策略生成的回答上取期望时，论文中的对数概率差对应策略到参考模型的 KL 散度。

评测过程还有一个值得留意的细节：论文报告的是测试奖励最高的检查点。若自己设计对照实验，可以用独立验证集选择检查点，再用保留的测试集做最后比较。论文同时查看摘要长度、多样性和流畅度，让读者了解奖励上升时回答风格怎样变化。

## 怎样评测与排错

固定基座、训练题目和验证器，记录每题采样数、采样温度、奖励版本、参考模型、生成长度与算力预算；在独立测试题上比较正确率、格式、输出长度以及训练时间。结合任务分别检查规则反馈或偏好评分的质量。

全组同分时，留一优势都为零，无法靠这组奖励区分答案。应检查题目是否过易或过难、采样是否缺少多样性、答案提取器是否出错，再决定调整数据或验证器。注意留出隐藏测试，并记录失败原因，避免模型通过记住公开样例获得高分。

## 面试追问

**RLOO 一定比 PPO 便宜吗？** 不一定。没有单独价值模型可能省下训练开销，但每题多个回答需要额外生成和打分，实际比较应包含总资源预算。

**它能修正错误的奖励吗？** 不能。基线处理的是估计波动，奖励错误仍会把更新引向错误目标。
