## 先看它解决什么问题

做强化学习时，模型先回答一批问题，评测器给出反馈，再根据反馈调整参数。更新以后，同一批回答是由“旧模型”写的，而正在训练的模型已经变了。继续使用这些回答时，就需要考虑两个模型给同一个 token 的概率有多大差别。

CISPO 的做法是给这个差别算一个**重要性权重**，再限制权重的范围。MiniMax-M1 在长推理强化学习中采用了这种策略优化方法。可以把权重想成样本参与更新的音量旋钮：音量太大就调低，但这段声音仍会参与合唱。

## 研究者为什么想保留这些更新

MiniMax-M1 报告提到，部分表达反思或修正的 token，例如“等一下”，在基础模型里出现的概率较低。训练中一旦它们的新旧概率比变化很大，PPO／GRPO 裁剪可能使相应项停止贡献梯度；团队因此尝试限制权重大小，同时保留这些 token 的学习信号。

知乎作者炼熵师自述参与了 CISPO 的探索，在[回顾文章](https://zhuanlan.zhihu.com/p/1962307894105048283)中讲了观察这一现象的过程，并分享了早期版本的想法。阅读时可把这篇作为研究经历，最终目标函数以 MiniMax-M1 论文为准。

## 从一个 token 看权重

假设旧策略在某个位置给“12”的概率是 0.1，当前策略给它的概率是 0.3，新旧概率比就是 3。为了容易计算，假设权重上限设为 2：CISPO 将这个比值调整为 2，再把它作为该 token 更新信号的系数。

这个上限只用于说明计算方法。最终更新还取决于回答的优势值、学习率和其他样本；权重上限不是模型参数变化的绝对上限。MiniMax-M1 论文给出上下界的一般公式，实验中主要调节上界。

![CISPO 示例：新旧概率之比为 3，经过上限为 2 的裁剪后得到权重 2，再与优势值相乘。](/figures/training/cispo-weight.svg)

## 和 PPO、GRPO 有什么不同

[PPO](/training/ppo/) 的裁剪目标会根据优势的正负和概率比选择分支。在某些超出裁剪范围的情形，目标对该 token 的梯度为零；这让更新不再继续朝同一方向扩大。

CISPO 将裁剪后的权重作为停止梯度的系数，乘以该 token 的对数概率和优势值。即使概率比超过上限，系数仍可为正，token 依然可以贡献梯度；如果优势为零，该项也就没有更新信号。[GRPO](/training/grpo/) 提供组内相对优势的思路，CISPO 的论文实现采用这种优势估计并以 token 汇总损失。

举例来说，优势为正、概率比为 3，裁剪上限为 2：在 PPO 对应的饱和分支中，该项不再继续增加梯度；CISPO 则把 2 用作系数，继续沿着提高该 token 概率的方向提供信号。优势为负时，鼓励方向相反，需要结合具体分支判断。

<details>
<summary>展开公式：裁剪发生在哪里</summary>

对采样回答的第 $t$ 个 token，重要性比率为

$$
r_t=\frac{\pi_\theta(y_t\mid x,y_{<t})}{\pi_{\mathrm{old}}(y_t\mid x,y_{<t})},\qquad
\hat r_t=\operatorname{clip}(r_t,1-\epsilon_{\rm low},1+\epsilon_{\rm high}).
$$

用 $\operatorname{sg}$ 表示停止梯度，单个 token 的目标项写作

$$
\operatorname{sg}(\hat r_t)\,\hat A_t\,\log\pi_\theta(y_t\mid x,y_{<t}).
$$

停止梯度表示计算导数时把裁剪权重当作系数，梯度通过对数概率项传播。论文对一组回答的 token 项求和并按总 token 数归一化。

如果同一 token 的优势为 $-0.5$，裁剪后的权重仍为 $2$，那么乘在对数概率梯度上的系数是 $2\times(-0.5)=-1$：这次信号会压低该 token 的概率，而不是因为权重为正就总是提高它。若优势为零，即使权重非零，这一项的系数也为零。裁剪会改变原本的重要性权重，因此论文也指出梯度会引入一定偏差。

不要只比较目标函数输出的数值来判断 CISPO 与 PPO 哪个更新更强：它们的目标写法不同。要比较同一批样本在具体实现下的梯度方向、裁剪比例、训练表现与成本。

</details>

## 如何评测

MiniMax-M1 论文用 Qwen2.5-32B-Base 和数学推理数据比较 CISPO、GRPO、DAPO，并在 AIME 2024 上观察不同训练步数的表现。论文讨论了每批生成数据进行 16 轮离策略更新的设置，并搭配动态采样与长度惩罚；其 CISPO 目标没有额外参考策略 KL 惩罚。论文报告在其设置下，CISPO 达到 DAPO 相近表现所需训练步数约为后者的一半。这是该组实验中的训练步数比较，实际训练成本还包括采样、奖励计算和硬件吞吐。

如果要比较自己的任务，可以固定基础模型、数据、奖励、采样数量和生成长度，分别记录任务准确率、生成 token 数、训练耗时与显存。长工具轨迹还要检查工具返回是否有效、是否超时，以及最终答案有没有利用到返回结果。评测用未参与调参的题目，更容易看清方法在新问题上的表现。

## 面试追问

**CISPO 是奖励模型吗？** 它是策略优化目标；答案由规则还是奖励模型评分，是另一项选择。

**CISPO 和 LoRA 可以一起用吗？** 两者处理不同问题：CISPO 定义策略更新信号，LoRA 限制以低秩适配器更新哪些参数。框架支持时可以组合。

**权重裁剪后训练一定稳定吗？** 训练还受到奖励设计、采样策略、优化器和实现精度影响，应该结合任务评测观察。
