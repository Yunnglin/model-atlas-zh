## 先看一个例子

同一道问题有两份回答：A 准确解释了什么是过拟合，B 错把训练成绩好当作一定能泛化。标注者选 A。SimPO 利用这样的同题优劣对调整模型，希望模型给 A 的平均 token 对数概率高于 B，并拉开一定差距。

![SimPO 用同题的优选和劣选回答计算平均 token 对数概率，再比较分差与目标间隔。](/figures/training/simpo-preference.svg)

它不需要在训练损失中运行参考模型，也不要求另训奖励模型。节省多少显存和时间取决于实现：例如 DPO 可以预先缓存固定参考模型的分数，实际对比应使用相同硬件、数据和批次。

“损失不需要奖励模型”不代表准备数据时绝不能使用评分器。论文的 Mistral 和 Llama 3 Instruct 实验先对每个问题采样五条回答，再用 PairRM 选出得分最高和最低的两条形成偏好对；后续 Gemma 2 实验使用 ArmoRM 标注偏好。SimPO 损失直接使用准备好的偏好对，不需要在每次更新时调用评分器。数据准备和策略训练是两步，二者的成本可以分别记录。

## 为什么要除以回答长度？

整条回答的对数概率是各 token 对数概率的和。每一项通常是负数，回答越长，加起来就容易越负。SimPO 把总和除以回答 token 数，得到每个 token 的平均值，减少直接用总和比较时的长度影响。

假设 A 有 4 个 token、对数概率总和为 -4，B 有 2 个 token、总和为 -3。直接比较总和，A 的 -4 比 B 的 -3 小；除以长度后，A 平均为 -1，B 为 -1.5，排序反转。这是一组教学数值，不代表 A 一定更正确。平均值也不能保证模型完全没有长度偏差，还要检查生成长度与质量。

<details>

把同题的优选与劣选回答记作 $y_w$、$y_l$，策略模型为 $\pi_\theta$。定义平均对数概率 $s_\theta(x,y)=\log\pi_\theta(y\mid x)/|y|$，其中 $|y|$ 是参与计分的回答 token 数。单条损失写成：

$$
L=-\log\sigma\left(\beta[s_\theta(x,y_w)-s_\theta(x,y_l)]-\gamma\right)
$$

$\beta$ 调整分数尺度，$\gamma$ 是目标间隔，$\sigma$ 是 sigmoid。若 $\beta=1$、$\gamma=0.2$，上面的分差为 0.5，括号为 0.3，损失约为 0.55。增大正向分差通常降低这条损失，但参数由所有样本共同更新；这不保证每条优选回答的绝对概率都会上升，也不保证实际生成一定正确。

论文观察到间隔增大时，偏好排序准确率可能继续提高，而生成胜率先升后降；因此 $\gamma$ 需要靠开发集选择，不能越大越好。

## 和 DPO、KTO 分别比较

[DPO](/training/dpo/)比较当前模型相对参考模型的优劣回答变化；经典 SimPO 直接比较当前模型的长度归一化分数，增加目标间隔。两者通常都使用同一问题下的优劣对。[KTO](/training/kto/)可以使用不成对的单条正负反馈，数据要求不同。[ORPO](/training/orpo/)也使用同题偏好对，在监督损失上加入赔率比损失。

举个单 token 的简化例子：参考模型给优选答案和劣选答案的对数概率分别是 -2 和 -1；训练后的模型分别给 -1.5 和 -0.9。优选答案相对参考模型提高了 0.5，劣选只提高了 0.1，因此 DPO 的相对分差偏向优选答案；但当前模型直接比较时，-0.9 仍高于 -1.5。SimPO 使用当前模型的长度平均分来比较，关注的是另一种排序。这个例子只说明两种评分可能不同，不意味着任一方法的生成结果必然更好。

把 SimPO 简化成“把 DPO 参考模型删掉”会漏掉长度归一化和目标间隔。它也不是某种在线强化学习算法：标准训练用已有偏好对计算损失，没有规定必须在线采样或调用奖励模型。实际项目可增加 SFT 损失或选择不同数据，但要与论文默认目标区分。

标准 SimPO 目标也没有显式的参考模型 KL 约束。论文在其部分实验中观察到模型偏离参考模型的程度仍较小，但这不是对任意数据和超参数的保证：如果偏好标签只奖励华丽措辞，模型可能越来越会迎合评分，却遗漏事实。除了观察损失，还应在独立题目上检查事实、长度和回答质量，必要时再考虑其他训练约束。

## 训练、评测与错例

准备同一问题下的两条回答与标注，记录来源、评审标准和模型版本；两条都错误或难分高下时，应允许弃用或平局。按问题来源或语义模板分离训练、开发和测试，再核查近重复。训练时固定模板、回答截断与结束标记，确认长度统计只包含要计分的回答 token。

论文表 4 在 Mistral-Instruct 7B 设置下，报告 AlpacaEval 2 长度控制胜率：DPO 为 26.8%，SimPO 为 32.1%；论文表 5 中，移除 SimPO 的长度归一化后为 19.1%。这项评测用 GPT-4 Turbo 对 805 个问题的候选回答与 GPT-4 Turbo 基准回答进行两两比较，再计算长度控制胜率，以减轻对冗长回答的偏好。它是模型评审下的偏好指标，不等于事实正确率；换成其他模型、数据和提示，结果可能不同。[原论文](https://arxiv.org/html/2405.14734v3)列出了基座、数据和其他评测。

同一个 Mistral-Instruct 实验也能看出为什么要同时报告长度：SimPO 的原始胜率为 34.8%，长度控制胜率为 32.1%，平均回答长度为 2,193；去掉长度归一化时分别是 19.7%、19.1% 和 2,067。这里的长度是论文表 11 使用的回复长度统计，评测采用温度 0.5 的采样。长度控制让比较少受篇幅影响，不等于两种方法生成了一样长的回答；最终仍要看正确性和实际成本。

如果偏好排序指标上升、实际回答却变得更啰嗦或漏掉关键条件，先查标签是否奖励篇幅、截断是否偏向长回答，再检查不同长度分组的结果。可在开发集调整数据和超参数，最后使用未参与调参的新题检查正确性、长度、拒答和延迟；保存失败案例供下一轮分析。

## 面试追问

**没有参考模型就不需要 SFT 吗？** 不是。参考模型是损失中的比较项；是否先用示范数据训练基座是另一项选择。论文中的对照使用了不同来源的 SFT 检查点。

**长度归一化会不会让长答案一定吃亏？** 不会直接按总长度惩罚；它比较平均对数概率，但质量和长度关系仍取决于数据、模型及评测。

**目标间隔达到后训练就会停止吗？** 不会自动停止。损失随分差变化逐渐趋小，实际梯度和停止条件还取决于样本、优化器与训练设置。
