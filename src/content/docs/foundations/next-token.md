## 用大白话理解

训练时让模型做很多次“接下来是什么”的练习。这里的 token 是模型切分文字后使用的小片段，可能是一个字、词的一部分或标点，并不总等于一个词。原文向后错开一位就能提供标准答案；模型给正确片段的概率越低，受到的惩罚越大。使用时把新生成的片段接回去，继续预测。

## 跟着例子走一遍

假设按字切分，“今天很”后面可能接“热”或“冷”。模型给候选片段分配概率，再根据生成规则选择。

> 今天很 → 预测下一片段 → 今天很热

## 训练时，答案怎样错开一位

假设分词器把短句切成三个 token：`今天`、`很`、`热`。模型在第一个位置读到 `今天`，目标是预测 `很`；在第二个位置读到 `今天 很`，目标是预测 `热`。训练数据中这三个 token 已经存在，因果掩码让每个位置只能使用当前和之前的输入，因此这些预测的损失可以并行计算。

| 模型可见的前缀 | 该位置的目标 |
| -------------- | ------------ |
| 今天           | 很           |
| 今天 很        | 热           |

![下一 token 预测：训练时将目标向左错位，生成时将新片段接回前缀再预测。](/figures/foundations/next-token.svg)

生成时没有后续标准答案。模型先为词表里的候选计算概率，再按解码方式选一个：贪心解码每步取概率最高的候选；采样则按设置从候选分布中抽取，常用温度或 top-p 调整候选分布。选出 `热` 后，把它接到前缀末尾，再生成下一个 token。

## 损失怎样衡量一次预测

假设正确的下一个 token 是 `热`。模型给它的概率为 0.8 时，负对数损失约为 0.223；如果概率只有 0.2，损失约为 1.609。训练会对有标签的位置计算这些损失，再利用梯度调整参数，让模型更倾向于预测训练数据中的目标。

训练目标使用已有文本提供答案，但模型能否在新问题上完成任务，还需要在未参与训练的数据上评估。内容如何切成 token 取决于分词器；`今天`、`很`、`热` 是这里为了说明而设定的切分。

## 与 SFT 的关系

常见生成式 [SFT](/training/sft/) 仍然使用这个目标，变化主要在指令与示范答案等训练材料，以及哪些位置计分。

## 和相近概念比一比

训练时通常能并行计算多个位置的预测误差，但每个位置仍不能偷看它要预测的未来。生成时则需要逐步把新结果接回输入。

## 什么时候要小心

token 不一定是一个汉字或单词。训练时可以并行算多个位置的损失；推理时依赖前一步输出。概率高也不保证陈述真实。
